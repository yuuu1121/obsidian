# Cycloidal Gear — 자료 인덱스

> [!abstract] 이 폴더는 무엇인가
> 사이클로이드 기어(감속기) 논문 2편의 상세 정리와, 그 논문들을 읽는 데 필요한 개념 정리 7편입니다. **이 분야를 처음 접하는 사람이 순서대로 읽으면 이해되도록** 구성했습니다.

---

## 읽는 순서 (처음 접하는 경우)

```
1. 사이클로이드 감속기 구조        ← 여기서 시작. 부품과 감속 원리
2. 사이클로이드 치형 방정식        ← 꽃잎 곡선을 수식으로
3. Nachimowicz(2016) 논문          ← 짧고 쉬운 튜토리얼 논문 (4쪽)
4. 공액 치형과 등거리 곡선          ← 왜 오프셋이 필요한가
5. 치형 수정 modification          ← 이론 곡선을 실용화하기
6. 전달오차와 백래시               ← 성능을 어떻게 측정하나
7. TCA 치접촉해석                  ← 전달오차 계산 방법 (어려움)
8. 헤르츠 접촉과 접촉응력           ← 하중이 걸린 상태 (어려움)
9. 파레토 최적과 다목적 최적화       ← 최적화 도구
10. Song(2023) 논문                ← 종합 논문 (20쪽)
11. RV 감속기                      ← 실제 산업 응용
```

> [!tip] 시간이 없다면
> **최단 경로**: 1 → 2 → 3 (사이클로이드가 뭔지, 곡선을 어떻게 그리는지)
> **핵심만**: 1 → 5 → 6 → 10 (왜 수정하고, 무엇을 측정하고, 논문이 뭘 했나)

| [[Nachimowicz2016 - 사이클로이드 기어 맞물림 모델링]] | Nachimowicz & Rafałowski, 2016 | 4쪽 | 입문 | 치형 곡선을 Excel로 그리는 실무 튜토리얼 |
| [[Song2023 - 다목적 최적화 치형수정]] | Song, Chen & Yang, 2023 | 20쪽 | 중급~상급 | 성능을 직접 목표로 삼아 GA로 수정계수 최적화 |

### 두 논문의 관계

| | Nachimowicz(2016) | Song(2023) |
|:---|:---|:---|
| 다루는 것 | **표준(공액) 치형 그리기** | **수정 치형 최적화** |
| 도구 | Excel | MATLAB + GA + ANSYS |
| 검증 | 없음 (그림만) | TCA + 이론 접촉력 + 정적/동적 FEM |
| 클리어런스 | 다루지 않음 | **핵심 주제** |
| 하중 | 다루지 않음 | 접촉력·응력 계산 |
| 학술적 기여 | 낮음 (교육적 가치 높음) | 중간~높음 |
| 기호 | $r, q, e, N, z_1$ | $r_p, r_{rp}, a, z_p, z_c$ |

> [!important] 두 논문은 순서대로 읽어야 한다
> Song(2023)은 표준 치형 방정식을 **한 줄로 던지고** 바로 수정으로 넘어갑니다. Nachimowicz(2016)를 먼저 읽어 기호와 기하를 잡아두지 않으면 따라가기 어렵습니다.
>
> 반대로 Nachimowicz만 읽으면 "그래서 이 곡선을 어떻게 쓰나?"에 답을 얻지 못합니다. 두 논문이 서로를 보완합니다.

## 핵심 개념 3줄 요약

> [!check] 이 분야를 한 문단으로
> **① 감속 원리**: 꽃잎 원판의 이빨을 핀보다 1개 적게 만들면, 한 바퀴 굴렀을 때 핀 1칸만큼 어긋나며 그것이 감속이 된다. 감속비 = 이빨 수.
>
> **② 근본 딜레마**: 이론적으로 완벽한(틈새 0인 공액) 치형은 조립·윤활·오차 보상 때문에 실제로 쓸 수 없다. 틈을 만들어야 하는데, 틈은 백래시를 늘리고 접촉 이빨 수를 줄인다.
>
> **③ 연구의 방향**: 필요한 최소 틈새를 **어떻게 분배**할지가 성능을 결정한다. 기존에는 "이상 곡선에 얼마나 닮았나"를 목표로 삼았지만, Song(2023)은 **성능을 직접 목표로 삼는 것이 더 낫다**는 것을 보였다.

> [!bug] 논문의 오류·불일치 (발견 목록)
> **Nachimowicz(2016)**
> - Fig. 5·6의 축 스케일이 본문 Fig. 3의 파라미터와 맞지 않음 (계산상 반경 37.64~41.64 mm인데 그래프는 ±30 mm)
> - Tab. 2 Excel 수식이 $\Psi$ 대신 다음 행 $\varphi$를 참조 (`COS(B19+B20)` → `COS(B19+C19)`가 맞음)
> - 수식에 상수 하드코딩 (파라미터 변경 시 전부 수정 필요 — 논문 결론과 모순)
>
> **Song(2023)**
> - **Table 2 Case b가 제약 위반**: $-0.0014+0.0073 = 0.0059 \ne 0.005$ mm (18% 초과). 결론 (4)의 "제약이 동일하다"는 주장과 모순
> - 식 (5) $y_1$의 $\cos \to \sin$ 오타
> - 식 (5) 분모 $r_p+\Delta r_{rp} \to r_p+\Delta r_p$로 보임
> - 4.4절이 $f_2$를 "식 (30)"이라 참조 (실제로는 식 17)
> - $E = 2.06\times10^{11}$ **MPa** → Pa여야 함 ($10^6$배 오류). 식 (27)에서는 올바르게 $2.06\times10^5$ MPa
> - Fig. 10 수렴조건 $0.1F_{\max}$ → 본문은 $0.1\%$ (100배 차이)
> - Table 3 vs 본문 백래시 불일치 (본문 $1.92'/1.15'$, 표 $2.30'/1.92'$ — 한 칸 밀림)
> - Table 3 vs 본문 무부하 최소 전달오차 불일치 (본문 $0.2936'/0.2374'$, 표 $0.25'/0.18'$)
> - 식 (21)의 $\varphi_0$ 정의 없음
> - 식 (27) $\nu$ vs 식 (28) $\mu$ 표기 혼용
> - 파레토 프론트에서 Case b를 고른 기준 미제시

> [!warning] 두 논문의 방정식은 호환되지 않는다 (중요)
> 두 논문의 $\varphi$가 **다른 각**입니다:
> - Nachimowicz: $\varphi$ 1바퀴 → 전체 곡선 (꽃잎 11개)
> - Song: $\varphi$ 1바퀴 → **꽃잎 1개만**. $z_c$바퀴 돌려야 전체
>
> 게다가 같은 파라미터를 넣어도 반경 범위가 다릅니다 (37.64~41.64 vs 32.75~43.06). 오프셋 처리 방식이 실제로 다릅니다.
>
> **재현 시 반드시 한 논문의 식과 그 논문의 $\varphi$ 정의를 함께 쓰세요.** 개념적 기호 대응(치형 방정식 노트 2절)은 유효하지만 수식은 섞을 수 없습니다.
