# Koopman 이론으로 여러 로봇을 똑똑하게 움직이기 (Part 1)

> [!abstract] 한 줄 요약
> **"휘어진(비선형) 문제를, 차원을 늘려서 곧게 펴진(선형) 문제로 바꿔 푸는 방법"** 을 여러 대의 로봇을 동시에 제어하는 데 적용한 논문이다. 핵심 도구는 **Koopman(쿠프만) 연산자**이고, 최종 목표는 "풀기 어려운 비선형 문제"를 "컴퓨터가 순식간에 푸는 선형 문제(선형계획법)"로 바꾸는 것이다.

이 노트는 원 논문을 **수학을 잘 몰라도 흐름과 아이디어를 이해할 수 있도록** 비유 중심으로 풀어 쓴 것이다. 뒤로 갈수록 조금씩 깊어지니, 앞부분만 읽어도 큰 그림은 잡힌다.

---

## 1. 이 논문은 무슨 문제를 풀려고 하나?

상황을 먼저 상상해 보자. **로봇 5대**가 평면 위를 돌아다닌다. 각 로봇은 위치(x, y)와 속도를 갖고, 우리가 조종할 수 있는 것은 **가속도(밟는 힘, 방향)** 뿐이다. 우리는 로봇들을 원하는 자리로, 서로 부딪히지 않게, "가장 좋은 방식으로" 몰고 가고 싶다.

여기서 두 가지 어려움이 생긴다.

**어려움 1 — 세상은 "선형"이 아니다.**
학교에서 배우는 가장 쉬운 방정식은 `y = ax + b` 같은 **1차식(선형)** 이다. 입력을 2배 하면 출력도 2배가 되는, 예측이 쉬운 세계다. 그런데 현실의 로봇 시스템, 특히 "얼마나 좋은가"를 평가하는 **성능 점수 함수**는 대개 구불구불한 **비선형** 함수다. 비선형 문제는 최적의 답을 찾기가 매우 느리고 어렵다.

**어려움 2 — "가장 좋은 조종"을 찾는 계산이 무겁다.**
"어떤 가속도를 줘야 점수가 최대가 될까?"를 찾는 것을 **최적제어(optimal control)** 라고 한다. 비선형 점수 함수를 최대로 만드는 문제는 **비선형 계획법(nonlinear programming)** 인데, 이건 컴퓨터에게도 벅찬 계산이다.

> [!question] 그래서 이 논문의 목표는?
> **비선형이라 어려운 문제를, 선형이라 쉬운 문제로 "변신"시키자.** 그 변신 마법의 이름이 바로 **Koopman(쿠프만) 시스템**이다.

## 2. 핵심 아이디어: Koopman 연산자란 무엇인가?

### 2.1 비유로 먼저 — "관점을 바꾸면 곧게 펴진다"

종이 위에 **나선형(소용돌이) 곡선**을 그렸다고 하자. 평면(2차원)에서 보면 빙글빙글 도는 복잡한 비선형 곡선이다. 그런데 이 종이를 원기둥에 감아서 **3차원 공간의 나선(스프링)** 으로 만들고 위에서 옆으로 보면? 그냥 **비스듬한 직선**처럼 보인다.

**차원을 하나 늘렸더니 곡선이 직선이 되었다.** 이것이 Koopman의 핵심 직관이다.

> [!tip] Koopman의 한 문장
> **"원래 변수(위치·속도)로는 비선형이지만, 잘 고른 여러 개의 '관측값'을 새로운 좌표로 삼으면 그 세계에서는 (거의) 선형으로 움직인다."**

### 2.2 "관측함수(observable)"라는 새 주인공

원래 시스템의 상태를 $x$ 라고 하자 (로봇의 위치·속도 묶음). 시간이 흐르면 상태가 변한다:

$$x(k+1) = f(x(k),\, u(k))$$

여기서 $k$ 는 시간 단계(1초, 2초…), $u$ 는 우리가 주는 조종 입력(가속도), $f$ 는 "다음 상태를 알려주는 규칙"인데 **비선형**이라 다루기 힘들다.

이제 상태 $x$ 를 직접 보지 말고, 그것을 재료로 만든 **관측함수** $\psi(x)$ 를 보자. 관측함수란 "상태를 넣으면 어떤 숫자를 뱉는 함수"다. 예를 들어:
- $\psi_1(x) = x$ (위치 그 자체)
- $\psi_2(x) = x^2$ (위치의 제곱)
- $\psi_3(x) = $ 성능 점수 함수

이렇게 관측함수를 여러 개 골라서 벡터로 묶은 것을 **Koopman 변수** $z$ 라고 부른다:

$$z(k) = \psi(x(k)) = [\psi_1(x),\ \psi_2(x),\ \dots,\ \psi_N(x)]^\top$$

### 2.3 Koopman 연산자 $\mathcal{K}$ 의 정의

Koopman 연산자 $\mathcal{K}$ 는 딱 한 가지 일을 한다: **"관측값을 한 시간 단계 미래로 밀어준다."**

$$\mathcal{K}[\psi(x(k))] = \psi(x(k+1)) = \psi(f(x(k), u(k)))$$

말로 풀면: *"지금의 관측값을 넣으면, 다음 시각의 관측값을 돌려준다."* 세 가지 중요한 성질이 있다 (논문 식 2.3).
1. **합성 연산** — 시스템 규칙 $f$ 와 관측함수 $\psi$ 를 합친 것이다.
2. **시간 전진** — 현재($k$)를 미래($k+1$)로 옮긴다.
3. **새로운 동역학** — $k$ 와 $k+1$ 두 시각을 잇는 새 관계식이 생긴다.

> [!warning] 여기 함정이 하나 있다 (논문의 진짜 기여 포인트)
> $\psi(x(k+1)) = \psi(f(x(k),u(k)))$ 는 아직 **진짜 "방정식"이 아니다.** 왜냐하면 오른쪽이 아직 옛날 변수 $x$ 에 의존하기 때문이다. 우리가 원하는 것은 오른쪽도 **새 변수 $z$ 로만** 표현된 깔끔한 식이다:
> $$z(k+1) = \xi(z(k),\, u(k))$$
> 이렇게 "새 변수만으로 닫힌" 형태로 만드는 작업을 **함수 변환(functional transformation)** 이라 하고, 이게 이 논문 2장의 핵심 수학이다.

### 2.4 함수 변환 — 어떻게 $z$ 만의 식으로 닫는가

아이디어는 의외로 단순하다. 만약 관측함수 묶음 $\psi$ 가 **되돌릴 수 있는(역함수가 있는)** 관계라면, 즉 $z$ 를 알면 원래 $x$ 를 복원할 수 있다면 ($x = \psi^{-1}(z)$), 오른쪽의 $x$ 를 전부 $z$ 로 갈아끼울 수 있다. 그러면 논문 식 (2.16)처럼:

$$z(k+1) = \xi(z(k),\, u(k))$$

라는 **완전히 새로운, $z$ 만의 동적 시스템**이 탄생한다. 이것을 **Koopman 시스템**이라 부른다. 논문은 이게 항상 존재함을 **명제 2.1(Proposition 2.1)** 로 보증한다.

> [!note] 관측함수 개수 $N$ 과 원래 차원 $n$
> - $N = n$ 이고 $\psi$ 가 뒤집을 수 있으면 → 깔끔하게 좌표만 바꾼 것.
> - $N > n$ (관측함수를 더 많이 씀) → 차원을 늘려 표현력을 키운 것. §2.1의 나선 비유처럼 **차원을 늘려 펴는** 전략. 대신 어떤 부분집합이 뒤집을 수 있으면 여전히 변환이 성립한다 (Remark 2.1).

## 3. 선형 근사 vs. 쌍선형 근사 — 얼마나 곧게 펼까?

Koopman 시스템 $z(k+1) = \xi(z(k), u(k))$ 가 생겼지만, $\xi$ 는 여전히 복잡할 수 있다. 그래서 **더 다루기 쉬운 모양으로 "근사"** 한다. 두 가지 선택지가 있다.

| 구분 | 선형 모델 | 쌍선형(bilinear) 모델 |
|---|---|---|
| 식 (개념) | $z(k+1) = Az(k) + Bu(k) + \eta$ | $z(k+1) = Az + Bu + D(z,u) + \eta_b$ |
| 비유 | 곡선을 **직선 한 개**로 근사 | 곡선을 **직선 + 살짝 휜 보정항**으로 근사 |
| 근거 | 테일러 전개의 **1차항**까지만 사용 (식 2.42) | 테일러 전개의 **2차항(휘어짐)까지** 사용 (식 2.38) |
| 오차 $\eta$ | 상대적으로 큼 | 더 작음 → 더 정확 |
| 계산 난이도 | 가장 쉬움 | 조금 더 복잡하지만 여전히 감당 가능 |

> [!info] 테일러 전개가 여기서 왜 나오나?
> "곡선을 그 점 근처에서 직선으로 근사"(접선)가 바로 테일러 전개의 1차 버전이다. 여기에 곡률(2차 미분, **헤세 행렬** $H$)을 한 항 더 붙이면 근사가 훨씬 정확해진다. 선형 모델 = 접선까지, 쌍선형 모델 = 곡률까지. 논문은 "휨"을 담는 2차항 덕분에 쌍선형이 더 세다고 강조한다.

**핵심 트릭:** 쌍선형 모델에서도 조종 입력 $u$ 에 대해서만큼은 **1차(선형/아핀)** 이 되도록 일부러 어떤 항($U^\top H_{33} U$)을 버린다 (식 3.64). 이렇게 하면 나중에 "최적의 $u$ 찾기"가 선형 문제로 쉬워진다. $u$ 는 어차피 목표점에서 0으로 수렴하니 그 항은 작아서 버려도 된다는 논리다.

## 4. 실제 다중로봇 시스템에 적용하기 (3장)

### 4.1 로봇 5대의 상태와 조종

각 로봇은 뉴턴 운동법칙(등가속도 운동)을 따른다 (식 3.1):
- **속도 갱신:** $v(k+1) = v(k) + a(k)\,\Delta t$
- **위치 갱신:** $r(k+1) = r(k) + v(k)\,\Delta t + \tfrac{1}{2}a(k)(\Delta t)^2$

(고등학교 물리의 $v = v_0 + at$, $s = s_0 + v_0 t + \tfrac12 a t^2$ 와 **똑같다!**)

5대를 모두 묶으면:
- **전체 상태** $X$ = 위치 10개(5대 × x,y) + 속도 10개 = **20차원** 벡터
- **전체 조종** $U$ = 가속도 10개(5대 × x,y) = **10차원** 벡터
- 이 로봇 운동 자체는 이미 선형이다: $X(k+1) = AX(k) + BU(k)$

### 4.2 "성능 점수 함수(utility function)"가 진짜 골칫거리

로봇을 얼마나 잘 몰고 있는지 평가하는 점수 $u_i(k)$ 는 **비선형** 함수다 (식 3.5, Ford 보고서에서 가져옴). 목표 지점까지의 거리, 충돌 회피 등을 종합한 게임이론 기반 점수라서 구불구불하다. **우리는 이 점수를 최대로 만들고 싶은데, 비선형이라 최대화가 어렵다.**

### 4.3 영리한 선택 — "점수 함수 자체를 Koopman 변수로 삼자"

이 논문의 실용적 핵심이다. Koopman 변수 $z$ 를 두 묶음으로 구성한다.

- **$z_{(1)}$ = 로봇의 원래 상태 20개** (위치·속도) — 이미 선형이라 그대로 씀.
- **$z_{(2)}$ = 비선형 점수 함수의 부품 30개** (5대 × 6개 성분) — 이걸 새 변수로 승격!

이렇게 하면 전체 점수가 **새 변수 $z_{(2)}$ 의 선형 결합**으로 표현된다 (식 3.13, 3.18):

$$u(k) = \omega^\top z_{(2)}(k)$$

> [!success] 무슨 일이 일어났나?
> 원래 "비선형 함수 $\phi(X)$" 였던 점수가, 그것을 **변수 이름 $z$ 로 바꿔 부르는 순간** 겉보기에 선형($\omega^\top z$)이 되었다. 물론 공짜는 아니다 — 대신 "$z_{(2)}$ 가 시간에 따라 어떻게 변하는가"라는 새 방정식을 풀어야 하고, 그게 여전히 비선형이라 §3의 선형/쌍선형 근사가 필요하다. **어려움을 한 곳(변수의 동역학)으로 몰아넣고, 그 부분만 근사로 처리하는 전략.**

## 5. 모델의 계수를 "스스로 배우는" 알고리즘 (온라인 학습)

근사 모델 $z(k+1) = Az + Bu$ 에서 행렬 $A, B$ (모델의 계수)를 어떻게 정할까? 논문은 **세 가지 방법**을 제시한다.

| 방법 | 방식 | 특징 |
|---|---|---|
| Method I | 순간 오차 최소화 | 가장 단순 |
| Method II | 구간 누적 오차 최소화 (배치) | 데이터 늘 때마다 처음부터 다시 계산 → 무거움 |
| **Method III** | **반복(적응) 알고리즘** | 새 데이터가 올 때마다 **계수를 조금씩 갱신** → 실시간 학습 |

논문이 미는 것은 **Method III**, 즉 **온라인 적응 알고리즘**이다 (식 3.37~3.40). 이건 통계·머신러닝의 **재귀 최소제곱법(Recursive Least Squares)** 과 같은 계열로, 큰 흐름은 이렇다.

$$\hat{\Theta}(k+1) = \hat{\Theta}(k) - \frac{P(k-1)\,\zeta(k)\,\epsilon^\top(k)}{m^2(k)}$$

- $\hat{\Theta}$ : 지금까지 배운 모델 계수(추정값)
- $\epsilon(k)$ : **예측 오차** (모델이 예측한 값 − 실제 값)
- $P(k)$ : 학습 속도를 조절하는 **이득 행렬**
- 매 순간 "예측이 틀린 만큼(오차) 계수를 살짝 수정" → **경사하강법의 사촌**

> [!tip] 비유 — 다트를 던지며 조준을 배우는 것
> 다트를 던지고(예측), 얼마나 빗나갔는지 보고(오차 $\epsilon$), 다음엔 그만큼 손을 보정한다(계수 갱신). 던질수록 정확해진다. 이 알고리즘도 데이터가 쌓일수록 로봇 모델을 점점 정확히 학습한다.

논문은 안정성을 위한 두 가지 실전 장치도 언급한다: **이득 재설정(gain resetting)** 으로 계산이 발산하는 것을 막고, **파라미터 투영(projection)** 으로 추정값이 말이 되는 범위 안에 머물게 한다.

### 모델 검증(validation)
배운 모델이 진짜인지 확인하려면, **훈련에 안 쓴 새 조종 신호**로 (1) 실제 비선형 시스템과 (2) 학습된 선형 모델을 둘 다 돌려서 결과 차이(검증 오차 $\tilde{z}$, 식 3.53)를 본다. 차이가 작으면 모델이 믿을 만하다. 논문은 "훈련 데이터와 검증 데이터는 반드시 달라야 한다"고 강조하는데, 이는 머신러닝의 **train/test 분리** 원칙과 정확히 같다.

## 6. 대망의 결승선 — 비선형 문제를 선형계획법으로 (4장)

이제 모든 준비가 끝났다. 원래 우리가 풀고 싶던 문제는:

> **"점수 $u$ 를 최대로 만드는 조종 입력 $U$ 를 찾아라"** (단, 가속도는 $-4 \le U_i \le 3$ 범위 안에서)

원래 이건 **비선형 계획법**이라 어려웠다. 그런데 §3~5를 거쳐 점수를 $u = \omega^\top z_{(2)}$ (선형)로, $z_{(2)}$ 의 변화를 선형/쌍선형 모델로 바꿔 놓았으니, 이제 문제는 이렇게 변한다 (식 4.10):

$$\text{Maximize}\quad \omega^\top\big(\hat{A}_{21}z_{(1)} + \hat{A}_{22}z_{(2)} + \hat{B}_2 U\big) \qquad \text{s.t.}\ -4 \le U_i \le 3$$

이것은 **선형계획법(Linear Programming, LP)** 이다! 목적함수도 제약조건도 모두 $U$ 에 대해 1차식이다.

> [!success] 왜 이게 대단한가
> 선형계획법은 **가장 잘 연구된, 가장 빠르게 풀리는** 최적화 문제 중 하나다. 논문도 대놓고 말한다 — *"Matlab의 `linprog` 함수 한 줄로 풀 수 있다."* 몇 시간 걸릴 비선형 최적화가, 순식간에 풀리는 선형 문제로 둔갑한 것이다. **이 "변신"이야말로 논문 전체의 목적지다.**

쌍선형 모델을 쓰면 더 정확한 근사 위에서 같은 LP를 풀 수 있다 (식 4.15~4.16). 조종 입력 $U$ 에 대해서는 여전히 선형(아핀)이 유지되도록 설계했기 때문에 가능하다.

```
[비선형 로봇 + 비선형 점수 함수]   ← 원래 풀기 어려운 문제
        │
        │  ① Koopman 연산자: 점수 함수를 '관측 변수 z'로 승격

        │
        │  ② 함수 변환 + 테일러 근사
        ▼

        ▼

        │
        │  ④ 점수 최대화 문제를 다시 씀
        ▼
[선형계획법 (LP)]  →  Matlab linprog로 순식간에 최적 조종 U* 계산 ✅
```

## 8. 이 논문의 의의와 한계

**의의 (기여점)**
- 그냥 "Koopman 쓰자"가 아니라, **아직 방정식이 아닌 Koopman 관계식을 진짜 동적 방정식으로 닫는 함수 변환**을 명확히 정리하고 존재성을 증명했다 (명제 2.1).
- **점수 함수 자체를 Koopman 변수로 삼는** 실용적 아이디어로, 비선형 최적제어를 선형계획법으로 환원했다.
- 오프라인 계산이 아니라 **실시간으로 모델을 학습하는 적응 알고리즘**을 제시했다.
- **쌍선형 모델**로 선형 모델의 부족한 표현력(특히 목표점에서의 오프셋 항)을 보완했다.

**한계 / 남은 것**
- 이 논문(Part I)은 **개념과 수식 유도(formulation)만** 다룬다. **실제로 잘 되는지 시뮬레이션 검증은 없다.**
- 실제 실험·평가는 **후속 논문 Part II** (참고문헌 [17], Zhao & Tao)에서 다룬다.
- "이상적인 선형화(오차 0)"는 아주 단순한 예제에서만 가능하다고 논문 스스로 인정한다 (Remark 2.2). 즉 근사 오차는 늘 존재한다.

## 9. 꼭 알아둘 용어 사전

| 용어 | 쉬운 뜻 |
|---|---|
| **선형 / 비선형** | 선형 = `y=ax+b`처럼 곧은 관계(예측 쉬움) / 비선형 = 구불구불(예측 어려움) |
| **Koopman 연산자 $\mathcal{K}$** | 관측값을 "한 시간 단계 미래"로 밀어주는 규칙 |
| **관측함수(observable) $\psi$** | 상태를 넣으면 숫자를 뱉는 함수. 이걸 새 좌표로 씀 |
| **Koopman 변수 $z$** | 관측함수들을 묶은 새로운 상태 벡터 |
| **함수 변환** | Koopman 관계식을 "$z$ 만의 방정식"으로 닫는 작업 |
| **성능 점수 함수(utility function)** | 로봇이 얼마나 잘 하고 있는지 매기는 (비선형) 점수 |
| **선형 / 쌍선형 근사** | 곡선을 직선으로 / 직선+휨으로 근사 (테일러 전개 1차/2차) |
| **테일러 전개** | 곡선을 어떤 점 근처에서 다항식으로 근사하는 방법(접선이 1차) |
| **헤세 행렬 $H$** | 2차 미분(곡률) 정보를 담은 행렬. 쌍선형 모델의 "휨"을 만듦 |
| **적응(온라인) 알고리즘** | 새 데이터가 올 때마다 모델 계수를 조금씩 갱신하며 학습 |
| **최적제어** | "가장 좋은 결과를 내는 조종 입력"을 찾는 문제 |
| **선형계획법(LP)** | 1차식 목적·제약으로 된 최적화. 매우 빨리 풀림(`linprog`) |
| **명제(Proposition)** | 논문에서 증명한 수학적 주장 |
