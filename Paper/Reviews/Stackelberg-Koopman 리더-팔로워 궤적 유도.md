# 리더가 "속마음 모르는" 팔로워를 목표까지 유도하기 — Stackelberg + Koopman

> [!abstract] 한 줄 요약
> **똑똑한 리더 로봇이, 감각·계획 능력이 부족한 팔로워 로봇을 장애물을 피해 목표까지 이끄는** 문제를 푼다. 문제는 리더가 팔로워의 **속마음(목적함수·동역학)을 모른다**는 것. 이를 **Stackelberg 게임**으로 정식화하고, 팔로워의 반응 방식을 **Koopman으로 선형 학습**해, 리더가 빠르게 충돌 없는 유도 궤적을 계산한다. 결과: 모델 기반 방법 대비 **계획 시간 절반**, 유도 성공.

이 노트는 [[수상선 3대 Koopman 다중제어 - 리딩 리스트|리딩 리스트]]의 **1순위** 논문 정리다. [[Koopman 다중로봇 최적제어 Part1 - 개념과 정식화|기반 논문(Zhao & Tao)]]과 "게임이론 + Koopman + 다중로봇"이라는 재료는 같지만, **요리법이 전혀 다르다.** 그 차이를 먼저 짚는다.

---

## 0. 기반 논문과 무엇이 다른가 (가장 중요)

| 항목 | 기반 논문 (Zhao & Tao) | **이 논문 (Zhao & Zhu)** |
|---|---|---|
| 협력 형태 | **대등한** 다중로봇이 각자 점수 최대화 | **리더-팔로워** (한쪽이 다른 쪽을 유도) |
| 게임 종류 | 게임이론 utility function | **Stackelberg 게임** (선-후 순서) |
| 무엇을 모르나 | (다 앎, 모델 주어짐) | 리더가 **팔로워의 속마음을 모름** |
| Koopman 대상 | 비선형 **점수 함수**를 변수로 승격 | 팔로워의 **반응 동역학**을 선형 학습 |
| 최적화 형태 | **선형계획법(LP)** 으로 환원 | **비선형 OCP** + receding horizon (LP 아님) |
| 학습 방식 | 온라인 [[재귀 최소제곱법과 공분산 리셋\|RLS 적응]] | **오프라인 NN + SGD** (데이터셋으로) |
| 로봇 수 | 3~5대 | **2대** (리더 1 + 팔로워 1) |

> [!tip] 한 문장 대비
> 기반 논문은 **"내 점수를 어떻게 선형으로 만들까"**, 이 논문은 **"상대가 어떻게 반응할지를 어떻게 선형으로 예측할까"** 를 푼다.

## 1. 문제 — 리더는 팔로워의 속마음을 모른다

상황: 지상 로봇(UGV) 2대. 한 대(**팔로워**)는 감각·계획 능력이 약해 혼자선 목표에 못 간다. 다른 한 대(**리더**)는 환경 전체를 보고 여러 스텝 앞을 계획할 수 있다. 리더가 팔로워를 **장애물을 피해 목표까지 유도**한다.

두 가지 어려움:

**어려움 1 — 팔로워의 속마음을 모른다.** 리더가 완벽하게 유도하려면 팔로워의 **목적함수와 동역학**을 알아야 하는데, 현실에선 **과거 움직임(궤적)만 관찰** 가능하다.

**어려움 2 — 안다 해도 계산이 무겁다.** 팔로워 모델을 안다 해도, 정확한 균형을 푸는 것(혼합정수계획 등)은 계산이 벅차다.

> [!question] 그래서 목표는?
> **관찰한 궤적만으로 팔로워의 "반응 방식"을 배우고(Koopman), 그걸 이용해 빠르게 유도 계획을 세우자.**

---

## 2. Stackelberg 게임으로 정식화 (§III)

→ 개념은 [[Stackelberg 게임과 균형]]

**Stackelberg 게임** = 한 명(리더)이 **먼저** 행동을 정해 발표하고, 다른 한 명(팔로워)이 그걸 보고 **나중에** 반응하는 선-후 게임. 매 순간 진행은:

1. 두 로봇이 현재 상태 $x_t$ 를 관찰
2. **리더**가 행동 $u^L_t$ 를 정해 팔로워에게 알림
3. **팔로워**가 그걸 보고 **근시안적으로(myopic)** 자기에게 가장 좋은 1스텝 행동 $u^{F*}_t$ 을 결정
4. 둘 다 움직여 새 상태 $x_{t+1}$ 로, 다음 라운드 반복

리더는 팔로워의 반응을 **예측하며** $T$ 스텝 앞을 계획해 충돌 없는 궤적을 만든다. 이상적 해가 **Stackelberg 균형(SE)** 이다.

> [!note] "근시안적(myopic) 팔로워"
> 팔로워는 능력이 약해서 **딱 한 스텝 앞만** 보고 최적 행동을 고른다. 이 "근시안" 가정이 뒤에서 문제를 크게 단순화하는 열쇠가 된다.

## 3. 핵심 트릭 — 팔로워 반응을 동역학에 "흡수"하기 (§III-C)

→ 개념은 [[근시안적 팔로워와 피드백 동역학]]

이게 이 논문의 진짜 기여다. Stackelberg 게임은 원래 **이중 레벨(bilevel)** — 리더 문제 안에 팔로워 최적화 문제가 중첩돼 있어 풀기 어렵다.

**해법:** 팔로워의 반응을 하나의 규칙 함수 **피드백 정책** $\rho^F$ 로 보고, 이를 팔로워 동역학에 대입해 버린다:

$$x^F_{t+1} = f^F(x^F_t,\ \rho^F(x_t, u^L_t)) =: \tilde f^F(x_t, u^L_t)$$

이제 팔로워의 "선택"이 동역학 $\tilde f^F$ 안에 **녹아들어**, 리더 입장에선 팔로워가 그냥 **정해진 규칙대로 움직이는 물체**가 된다. 그러면 이중 레벨 게임이 리더 혼자만의 **단일 레벨 최적제어(OCP)** 로 축소된다.

> [!success] 무슨 일이 일어났나
> "상대의 전략적 선택"이라는 골칫거리를, **하나의 (비선형) 반응 동역학** $\tilde f^F$ 로 바꿔치기했다. 남은 문제는 "이 비선형 $\tilde f^F$ 를 어떻게 다루나?" 인데 — 바로 여기서 **Koopman**이 등장한다.

---

## 4. Koopman으로 팔로워 반응 동역학 학습 (§IV)

→ 개념은 [[데이터로 Koopman 학습하기 - DMD·임베딩·S-step]] · [[Koopman 연산자와 관측함수]]

리더는 관찰 궤적 데이터로 비선형 반응 동역학 $\tilde f^F$ 를 **선형 모델**로 학습한다.

- **제어를 포함한 Koopman:** 임베딩 함수를 $g=[g_x,\ g_u]$ 로 나누고, 흔한 방식대로 $g_u(x,u)=u$ (선형 파라미터화)로 둔다. 그러면 제어 $u$ 가 학습 모델에 그대로 남아 예측·제어에 편리하다.
- **임베딩 함수 학습:** $g_x(x) = [x^T,\ h_\theta(x)^T]^T$ — 상태 자신 + 신경망 $h_\theta$. 상태를 고차원으로 "들어올려(lift)" 선형이 되게 한다.
- 최종 선형 모델 (식 9):
$$y_{t+1} = A y_t + B_1 x^L_t + B_2 u^L_t,\qquad x^F_t = C y_t$$
즉 **리더의 상태·행동 $(x^L,u^L)$ 을 넣으면 팔로워의 다음 상태를 예측**한다.
- **S-스텝 예측 손실**로 학습해 **장기 예측 정확도**를 높인다 (한 스텝만 맞추는 게 아니라 여러 스텝 앞까지 맞추도록).

---

## 5. Receding Horizon Planning + 시나리오 스위칭 (§IV-C, Alg. 1)

리더는 학습 모델로 **receding horizon planning**(MPC처럼 매 스텝 앞 $T$ 스텝을 다시 계획)을 돌려 유도한다. Koopman 근사 오차를 매 스텝 재계획으로 보정한다.

> [!info] 시나리오 기반 스위칭 (guidance threshold)
> 리더가 팔로워에서 **너무 멀어지면 유도가 무의미**해진다. 그래서 거리 임계값 $\lambda$ 를 둬서:
> - 거리 > $\lambda$ → 리더 목적함수를 **"팔로워에게 되돌아가기"** 로 전환
> - 거리 ≤ $\lambda$ → **"목표로 향하기"** 로 전환
>
> 목적함수를 상황에 따라 갈아끼우는 **적응적 유도** 전략이다.

## 6. 실험 결과 (§V)

**세팅:** $10\times10$ 공간에 장애물 4개, 이산 **unicycle 모델**(위치 $x,y$ + 방향각, 제어 = 선속도·각속도), 계획 지평 $T=5$. 세 방법 비교:

| 방법 | 정체 | 장기 예측 | 유도 성공 | 계획 시간 |
|---|---|---|---|---|
| 모델 기반 OCP | 팔로워 모델을 **안다고 가정**한 baseline | (정확) | 성공 | **가장 느림** |
| **Koopman (이 논문)** | 임베딩+S-step 선형 학습 | ✅ **최고** | ✅ **성공** | baseline의 **절반** |
| nn-approach | NN으로 1스텝 동역학 적합 | 단기만 좋음 | ❌ 1개 실패 | 느림(비선형) |
| dmd-approach | DMD 선형 모델 | 약함(비선형 못담음) | ❌ 2개 실패 | 빠름 |

핵심 발견:
- **Koopman이 장기(10스텝) 예측에서 최소 오차** — 임베딩 함수가 동역학 정보를 더 담고, S-step 손실이 장기 예측을 강화한 덕분.
- **nn-approach**는 1스텝 적합이라 단기(첫 3스텝)는 좋지만 장기는 나쁘고, 모델이 비선형이라 계획이 느리다.
- **dmd-approach**는 비선형성을 못 담아 장애물(다이아몬드) 근처에서 예측이 빗나가 유도 실패.
- Koopman은 **계획 시간을 절반**으로 줄이면서 유도 성공 (선형 모델 → 빠른 계획).

## 7. 의의와 한계

**의의**
- Koopman을 **게임이론·다중로봇**에 연결한 드문 시도 (저자들이 "이 간극을 메운다"고 명시).
- 팔로워 반응을 **피드백 동역학으로 흡수**해 이중 레벨 게임을 단일 OCP로 만든 정식화.
- 임베딩 + **S-step 손실**로 장기 예측 정확도를 확보, DMD·NN 대비 우수.
- 선형 모델 덕에 **계획 시간 절반** — 실용적 속도.

**한계**
- **2대(리더 1 + 팔로워 1)** 만 다룸 — 3대 이상 다중 팔로워로의 확장은 미해결.
- **오프라인 학습**(데이터셋 + SGD) — 기반 논문의 온라인 적응과 대비됨.
- **안전 보장(safety) 미흡** — 저자들이 오차 한계(error bounds)와 유효 작동 영역 규명을 미래 과제로 명시. Koopman 근사 오차가 장애물 근처에서 위험할 수 있음.

> [!note] 수상선 3대 프로젝트 관점
> 이 논문은 **2대**라서 3-USV에 직접 적용은 안 되지만, 두 가지를 준다: (1) **리더-팔로워 유도**라는 대안적 협력 구조 (예: 능력 좋은 USV 1대가 나머지 2대를 이끄는 편대), (2) **상대의 반응을 Koopman으로 예측**하는 아이디어 — 다중 USV 충돌 회피에서 "옆 배가 어떻게 움직일지" 예측에 쓸 수 있다. 다만 이 논문은 [[재귀 최소제곱법과 공분산 리셋\|온라인 적응]]이 아닌 오프라인 학습이라, USV 실시간 적용엔 온라인화가 과제.
