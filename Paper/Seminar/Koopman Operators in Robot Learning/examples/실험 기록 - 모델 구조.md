# 🔬 실험 기록 — 모델 구조가 전부를 결정한다

> [!abstract] 무엇을 실험했나
> [[Koopman 예제 코드|04번 스크립트]] "직접 해보기" ①번입니다.
> **`fit_bilinear`에서 `u_j * PhiX` 블록 한 줄을 지우면?**
>
> 결과: **`poly1+trig`의 오차가 3.5e-15 → 1.85e-02 로 13자릿수 무너집니다.** 코드 한 줄이 "정확한 모델"과 "쓸 수 없는 모델"을 가릅니다.

---

## 📖 먼저 — 두 모델 구조의 의미

리프팅한 뒤 **$\psi$ 와 $u$ 를 어떻게 결합할 것인가**의 차이입니다. 결합 방식이 곧 "표현할 수 있는 비선형성의 종류"를 결정합니다.

### Input-affine — 입력이 **더해지기만** 합니다

$$
\psi(x^+) \;=\; \underbrace{K\,\psi(x)}_{\text{상태만}} \;+\; \underbrace{B\,u}_{\text{입력만}}
$$

**"입력에 대해 아핀(affine)"** — $u$ 가 **1차항으로 한 번만**, 그것도 $\psi$ 와 곱해지지 않고 등장합니다. → [[Affine]]

| | |
|:---|:---|
| ✅ **장점** | $(\psi, u)$ 에 대해 완전한 **선형** 모델 → MPC가 **볼록 QP**가 됨 |
| ❌ **한계** | $\psi$ 와 $u$ 의 **곱을 표현 불가**. 두 항이 서로 만날 통로가 없음 |

> [!note] 왜 "곱을 표현 불가"가 문제인가
> $K\psi(x)$ 는 **$x$ 만** 보고, $Bu$ 는 **$u$ 만** 봅니다. 그래서 *"입력의 효과가 상태에 따라 달라진다"* 는 관계를 담을 수 없습니다.
>
> 이 로봇의 $v\cos\theta$ 가 정확히 그런 관계입니다 — $\theta=90°$ 면 $v$ 를 아무리 키워도 $x$ 는 안 움직여야 하는데, $Bu$ 항은 $\theta$ 를 모르니 $v$ 에 비례해 계속 값을 냅니다.

### Bilinear — 입력과 상태가 **곱해집니다**

$$
\psi(x^+) \;=\; K\,\psi(x) \;+\; B\,u \;+\; \underbrace{\sum_{j=1}^{N_u} u_j\,B_j\,\psi(x)}_{\textbf{입력}\times\textbf{상태함수}}
$$

**"쌍(bi)-선형"** — $\psi$ 를 고정하면 $u$ 에 대해 선형, $u$ 를 고정하면 $\psi$ 에 대해 선형인데, **둘을 동시에 보면 비선형**입니다(곱이 있으므로).

| | |
|:---|:---|
| ✅ **장점** | $u_j\psi$ 항이 곱셈 비선형성을 담음 → 이 시스템에서 **정확한 모델** |
| ❌ **대가** | $u$ 에 대해 비선형 → MPC가 **비볼록**, 국소 해만 |

> [!important] 학습은 여전히 선형 최소자승입니다
> 헷갈리기 쉬운 지점입니다. $u_j\psi(x)$ 는 **데이터에서 이미 값이 정해진 양**이므로, 미지수 $K, B, B_j$ 에 대해서는 여전히 **선형**입니다. 그래서 [[EDMD]]의 닫힌 형태 해가 그대로 쓰입니다.
>
> 비선형이 되는 것은 나중에 **$u$ 를 최적화 변수로 쓸 때**(MPC)입니다. → [[Koopman MPC]] 3번

### 한눈에 비교

| | **Input-affine** | **Bilinear** |
|:---|:---|:---|
| 형태 | $K\psi + Bu$ | $K\psi + Bu + \sum_j u_jB_j\psi$ |
| $u$ 와 $\psi$ | 각자 독립 | **곱으로 결합** |
| 표현 가능한 비선형성 | 상태만의 비선형 | **상태 × 입력** |
| 학습 | 선형 최소자승 | 선형 최소자승 (동일) |
| **MPC** | **볼록 QP** ✅ | 비볼록(SQP) ❌ |
| 이 시스템 오차 | 1.85e-02 | **3.5e-15** |

> [!success] 논문에서의 위치
> 둘 다 [[Koopman with Control Input|input-state separable form]] $\psi(x^+)=A(u)\psi(x)$ 의 특수 사례입니다.
> - **affine**: $A(u)$ 를 $u$ 의 **상수 + 1차항**으로 제한
> - **bilinear**: $A(u) = K + \sum_j u_jB_j$ 로 조금 더 일반화
>
> 즉 둘의 차이는 **$A(u)$ 를 얼마나 풍부하게 표현하느냐**의 문제로 환원됩니다.

## 수정한 것 — 딱 한 줄

```python
# 04_dictionary_study.py:88

# 변경 전 (bilinear)
blocks = [PhiX, U] + [U[j:j + 1, :] * PhiX for j in range(U.shape[0])]

# 변경 후 (뒤의 리스트 삭제 → affine과 동일해짐)
blocks = [PhiX, U]
```

이 한 줄이 회귀 행렬 $Z$ 에서 담당하던 부분은 다음 항입니다.

$$
\psi(x^+) = K\psi(x) + Bu + \underbrace{\sum_{j} u_j\,B_j\,\psi(x)}_{\text{이 항이 사라짐}}
$$

## 🔍 회귀 행렬 $Z$ 가 어떻게 달라지나

블록을 제거하면 $Z$ 의 행 수가 줄어듭니다.

| 딕셔너리 | $N_\psi$ | $Z$ 행 수 (bilinear) | $Z$ 행 수 (제거 후) |
|:---|---:|---:|---:|
| poly1 | 6 | $6+2+2\cdot6 = $ **20** | $6+2=$ **8** |
| poly1 + trig | 8 | $8+2+2\cdot8 = $ **26** | $8+2=$ **10** |
| poly3 | 25 | $25+2+2\cdot25=$ **77** | $25+2=$ **27** |

$$
Z_{\text{bilinear}} =
\begin{bmatrix} \Psi(X) \\ U \\ u_1\!\cdot\!\Psi(X) \\ u_2\!\cdot\!\Psi(X)\end{bmatrix}
\qquad\longrightarrow\qquad
Z_{\text{affine}} = \begin{bmatrix} \Psi(X) \\ U \end{bmatrix}
$$

> [!important] 사라진 두 블록이 하는 일
> $u_j\cdot\Psi(X)$ 는 각 열 $t$ 에서 $u_{t,j}\,\psi(x_t)$ 를 만듭니다 — **입력과 상태함수의 곱**입니다.
>
> 이 시스템의 비선형항이 정확히 $v\cos\theta$ 이므로, 이 블록이 있어야만 표현이 됩니다. 없으면 딕셔너리에 $\cos\theta$ 가 있어도 **거기에 $v$ 를 곱해줄 자리가 없습니다.**

## 💡 정리 — 이 실험이 증명하는 것

> [!success] "딕셔너리와 모델 구조는 서로를 대체할 수 없다"
> 이 시리즈의 실험들을 합치면 완전한 그림이 나옵니다.
>
> | 딕셔너리 | 모델 구조 | 결과 |
> |:---|:---|:---|
> | trig 있음 | bilinear | **3.5e-15** ✅ 정확 |
> | trig 있음 | affine (이번 실험) | 1.85e-02 ❌ |
> | trig 없음 | bilinear ([[실험 기록 - EDMD 학습]]) | 1.6e-02 ❌ |
> | trig 없음 | affine | 1.85e-02 ❌ |
>
> **둘 다 맞아야 정확해집니다.** 한쪽만으로는 어떤 조합도 $10^{-2}$ 벽을 넘지 못합니다.
>
> 이것이 $\mathrm{span}(\psi)$ 가 [[Koopman-Invariant Subspace|Koopman-불변]]이 되는 조건입니다 — 딕셔너리가 필요한 함수를 담고, **동시에** 모델이 그것들을 올바르게 결합할 수 있어야 합니다.

> [!note] 실무적 함의
> 모델 성능이 안 나올 때 흔히 딕셔너리부터 키웁니다. 그런데 [[실험 기록 - EDMD 학습]]에서 봤듯 **구조가 틀렸으면 딕셔너리를 아무리 늘려도 소용없습니다**(차원 6→25에서 변화 없음).
>
> **먼저 물어야 할 것**: "내 시스템의 비선형항이 입력과 얽혀 있는가?" 얽혀 있다면 bilinear가 필요하고, 아니라면 affine으로 충분하며 볼록성이라는 이점을 공짜로 얻습니다.

## 🔧 재현 방법

```python
# 04_dictionary_study.py:88 — 뒤의 리스트만 삭제
blocks = [PhiX, U]
```

되돌리기 편하게 하려면 줄을 나눠두는 것도 방법입니다.

```python
blocks = [PhiX, U]
blocks += [U[j:j + 1, :] * PhiX for j in range(U.shape[0])]   # ← 이 줄만 주석 토글
```
