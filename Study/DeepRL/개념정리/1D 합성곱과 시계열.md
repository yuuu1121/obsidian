# 1D 합성곱과 시계열

> [!abstract] 한 줄 요약
> **1D 합성곱(1D convolution)**은 이미지에 쓰는 2D 합성곱을 한 방향(시간축)으로만 슬라이딩하도록 단순화한 연산이다. 시간 순서대로 나열된 데이터(주가, 음성, 센서값 등)에서 "최근 몇 개 구간의 패턴"을 자동으로 뽑아내는 데 쓴다.

## 비유로 이해하기

2D 합성곱이 사진 위를 **작은 사각형 창(window)**으로 상하좌우 훑으며 "이 부분에 고양이 귀 같은 무늬가 있나?"를 찾는 것이라면, 1D 합성곱은 **줄 하나로 된 데이터 위**를 왼쪽에서 오른쪽으로만 창을 밀며 "최근 N개 구간에 상승 패턴이 있나?"를 찾는 것과 같다. 사진은 가로·세로 두 방향이 다 중요하지만, 주가 그래프는 시간이라는 **한 방향**만 있으면 되기 때문에 1D로 충분하다.

## 챕터 속 맥락 (10장)

`State1D` 클래스는 가격을 (고가 행, 저가 행, 종가 행, 거래량 행)으로 쌓은 **2D 행렬**로 인코딩한다. 이 행렬에서 각 행은 아타리 이미지의 R·G·B 색상 평면과 같은 역할을 하고, 열(가로축)은 시간이다.

```python
self.conv = nn.Sequential(
    nn.Conv1d(shape[0], 128, 5),   # 입력 채널 수 = 가격 성분 개수, 커널 크기 5
    nn.ReLU(),
    nn.Conv1d(128, 128, 5),
    nn.ReLU(),
    nn.Flatten(),
)
```

`nn.Conv1d(shape[0], 128, 5)`는 "입력 채널(고가·저가·종가·거래량 등)을 받아서, 크기 5짜리 시간 구간을 훑으며 128개의 서로 다른 패턴 필터를 학습하겠다"는 뜻이다. 커널 크기 5는 "연속된 5개 바(bar)를 한꺼번에 보고 하나의 특징을 뽑는다"는 의미이며, 이 필터가 시계열 전체를 슬라이딩하며 패턴(예: "5개 바 연속 상승" 같은 모양)을 찾아낸다.

> [!tip] 왜 완전연결 대신 합성곱을 쓸까?
> 완전연결(fully connected) 네트워크는 바 개수가 늘어날수록 파라미터 수가 급격히 늘어난다. 반면 합성곱은 **같은 필터를 시계열 전체에 재사용**하므로, 컨텍스트(과거를 얼마나 볼지)를 크게 늘려도(이 챕터에서는 50개 바) 네트워크 크기가 크게 늘지 않는다. 그래서 합성곱 모델이 완전연결 모델보다 더 넓은 시야로, 더 빠르게 수렴할 수 있었다.

## 세 줄 정리
- 1D 합성곱은 시간 방향으로만 슬라이딩하는 합성곱으로, 시계열 데이터의 국소 패턴을 뽑아낸다.
- 이 챕터에서는 고가·저가·종가·거래량을 채널처럼 쌓은 2D 행렬 위에 적용한다.
- 같은 필터를 재사용하므로 완전연결 네트워크보다 적은 파라미터로 더 긴 컨텍스트를 다룰 수 있다.
