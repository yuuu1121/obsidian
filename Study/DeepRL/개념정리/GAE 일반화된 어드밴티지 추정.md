# GAE (Generalized Advantage Estimation, 일반화된 어드밴티지 추정)

> [!abstract] 한 줄 요약
> **GAE**는 어드밴티지 $A(s,a)$를 추정할 때 "한 걸음만 보고 판단(분산은 크지만 편향 적음)"과 "끝까지 다 보고 판단(편향은 크지만 분산 적음)" 사이에서 **얼마나 멀리까지 내다볼지**를 파라미터 $\lambda$(람다) 하나로 부드럽게 조절하는 방법이다.

## 1. 왜 필요한가 — 어드밴티지 추정의 딜레마

[[액터-크리틱과 어드밴티지|어드밴티지]] $A_t$는 "이 행동이 평균보다 얼마나 더 좋았는가"를 나타내는 값이다. 문제는 **이걸 어떻게 계산하느냐**다.

- **한 스텝만 보고 계산** ($\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$): 딱 한 번의 관측만 쓰므로 **분산(들쭉날쭉함)은 작지만**, 크리틱 $V(s)$가 아직 부정확하면 그 오차가 그대로 섞여 들어와 **편향(치우침)이 크다.**
- **에피소드 끝까지 보고 계산** (몬테카를로식으로 실제 받은 보상을 끝까지 더함): 실제로 일어난 일을 그대로 쓰니 **편향은 작지만**, 게임 하나하나의 우연성이 고스란히 반영돼서 **분산이 매우 크다.**

> [!tip] 비유 — 시험 성적 예측
> 한 스텝 방식은 "오늘 본 쪽지시험 점수만 보고 이번 학기 성적을 예측"하는 것과 같다 — 정보가 적어 예측이 한쪽으로 치우칠 수 있지만(편향), 쪽지시험 하나라 결과가 안정적이다(분산 작음). 끝까지 보는 방식은 "학기 끝나고 실제 성적표를 보고 판단"하는 것 — 정확하긴 한데(편향 없음), 그 사이 운(쉬운 시험, 컨디션 난조 등)이 잔뜩 끼어들어 다음 학기 예측에는 들쭉날쭉하다(분산 큼).

## 2. GAE의 아이디어 — 두 극단을 지수가중평균으로 섞기

GAE는 1스텝, 2스텝, 3스텝, … 을 본 추정치들을 **$\lambda$의 거듭제곱으로 가중해 모두 더한다.**

$$A_t^{GAE(\gamma,\lambda)} = \sum_{k=0}^{\infty} (\gamma\lambda)^k \delta_{t+k}, \qquad \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$$

말로 풀면: *"바로 다음 스텝의 TD 오차 $\delta_t$를 기본으로 삼되, 그 뒤에 이어지는 미래의 TD 오차들도 $(\gamma\lambda)$의 거듭제곱만큼 깎아서 계속 더해준다."*

- **$\lambda = 0$**: 위 식이 $\delta_t$ 하나만 남는다 → **1스텝 추정**(분산 작음, 편향 있을 수 있음).
- **$\lambda = 1$**: 모든 미래 TD 오차를 동일 비중(할인율 $\gamma$만 적용)으로 다 더한다 → 몬테카를로식 **끝까지 보는 추정**(편향 없음, 분산 큼)과 같아진다.
- **$0 < \lambda < 1$** (PPO 논문은 $\lambda=0.95$ 사용): 두 극단 사이 어딘가로, 실전에서 가장 안정적인 절충점을 찾는다.

> [!important] 왜 하필 지수가중평균인가?
> 먼 미래로 갈수록 $(\gamma\lambda)^k$가 점점 작아지므로, **가까운 미래의 정보는 크게 반영하고 먼 미래의 불확실한 정보는 작게 반영**한다. 이렇게 하면 극단을 딱 자르지 않고 부드럽게 "많이 볼수록 신뢰도를 깎아서" 섞을 수 있다.

## 3. 실제 계산 — 역방향 재귀

무한 합을 매번 그대로 계산하면 비효율적이므로, 실제 코드에서는 **뒤에서부터 거꾸로** 재귀적으로 계산한다(Chapter 16 PPO 구현의 `calc_adv_ref` 함수).

```python
last_gae = 0.0
for val, next_val, exp in zip(reversed(values[:-1]), reversed(values[1:]), reversed(trajectory[:-1])):
    if exp.done_trunc:
        delta = exp.reward - val          # 에피소드 끝: 다음 상태 가치 없음
        last_gae = delta
    else:
        delta = exp.reward + gamma * next_val - val   # TD 오차
        last_gae = delta + gamma * gae_lambda * last_gae  # 이전(미래) GAE를 이어붙임
```

- `trajectory`를 뒤에서부터 훑으면서, 한 스텝 앞서 계산해둔 `last_gae`(더 미래 시점의 GAE 값)에 $\gamma\lambda$를 곱해 현재 TD 오차 `delta`에 더한다.
- 이렇게 하면 무한 합을 매 스텝 다시 계산할 필요 없이, **한 번의 역방향 순회**로 모든 시점의 GAE를 구할 수 있다.

## 4. PPO·TRPO에서의 역할

PPO와 TRPO 모두 어드밴티지 추정에 GAE를 사용한다. 원래 A2C(Chapter 16 도입부의 A2C 베이스라인)의 어드밴티지 공식

$$A_t = -V(s_t) + r_t + \gamma r_{t+1} + \dots + \gamma^{T-t+1}r_{T-1} + \gamma^{T-t}V(s_T)$$

은 사실 **GAE에서 $\lambda=1$인 특수한 경우**다. GAE는 이를 일반화해서, $\lambda$ 값을 조절함으로써 분산-편향 트레이드오프를 직접 튜닝할 수 있게 해준다.

## 세 줄 정리
- GAE는 어드밴티지를 "한 스텝만 보기"와 "끝까지 다 보기" 사이에서 $\lambda$로 절충하는 방법이다.
- $\lambda=0$은 분산은 작지만 편향 위험, $\lambda=1$은 편향은 없지만 분산이 큼 — PPO는 보통 $\lambda=0.95$를 사용한다.
- 실제 계산은 TD 오차들을 뒤에서부터 $\gamma\lambda$ 가중으로 누적하는 역방향 재귀로 효율적으로 수행한다.
