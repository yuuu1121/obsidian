# GAN — 생성적 적대 신경망 (Generative Adversarial Network)

> [!abstract] 한 줄 요약
> **GAN**은 신경망 두 개를 "사기꾼 대 탐정"처럼 서로 경쟁시켜서, 사기꾼(생성자)이 점점 더 진짜 같은 가짜 데이터를 만들어내게 훈련하는 방법이다.

> [!note] 왜 딥러닝 책에서 이걸 다루나?
> GAN 자체는 강화학습이 아니지만, "손실 함수 두 개, 옵티마이저 두 개를 동시에 굴리며 두 네트워크를 함께 학습시킨다"는 점에서 PyTorch의 유연성을 보여주는 좋은 예제다. 3장에서는 Atari 게임 화면을 흉내 내는 GAN을 직접 만들어보며 텐서·그래디언트·손실함수·옵티마이저를 총동원한다.

## 1. 두 명의 선수

| 이름 | 별명 | 역할 |
|---|---|---|
| **생성자(Generator)** | 사기꾼 | 무작위 숫자(잠재 벡터)를 받아 **가짜 데이터**(예: 이미지)를 만든다 |
| **판별자(Discriminator)** | 탐정 | 이미지를 보고 **진짜인지 가짜인지** 판정한다(0~1 확률로) |

> [!tip] 비유 — 위조지폐범과 감별사
> 생성자는 위조지폐를 만드는 범인, 판별자는 그 위조지폐를 감별하는 은행원이다. 처음엔 위조지폐가 허술해서 은행원이 쉽게 잡아낸다. 범인은 잡힐 때마다 기술을 더 정교하게 다듬고, 은행원도 그에 맞서 감별 실력을 키운다. 이 둘의 "군비 경쟁"이 오래 지속되면, 범인은 결국 진짜와 거의 구별 안 되는 위조지폐를 만들게 된다 — 이게 바로 GAN이 학습되는 원리다.

## 2. 학습 방식 — 왜 옵티마이저가 두 개인가?

GAN은 한 번의 학습 스텝에서 **두 단계**를 거친다.

1. **판별자 학습**: 진짜 이미지(라벨 1)와 생성자가 만든 가짜 이미지(라벨 0)를 둘 다 보여주고, 판별자만 갱신한다. (이때 생성자 쪽으로 그래디언트가 새지 않게 `detach()`로 끊어준다.)
2. **생성자 학습**: 생성자가 만든 이미지를 다시 판별자에 통과시키되, 이번엔 라벨을 전부 1(진짜)로 준다. 그러면 손실 함수가 "판별자를 속이는 방향"으로 **생성자만** 갱신하도록 만든다.

이렇게 두 네트워크가 **서로 다른 목표**로 갱신되어야 하므로, 각각을 위한 옵티마이저를 따로 둔다.

```python
gen_optimizer = optim.Adam(params=net_gener.parameters(), lr=LEARNING_RATE)
dis_optimizer = optim.Adam(params=net_discr.parameters(), lr=LEARNING_RATE)
```

## 3. `detach()`의 역할

```python
dis_output_fake_v = net_discr(gen_output_v.detach())
```

`detach()`는 텐서를 그것을 만든 계산 그래프에서 **떼어낸 복사본**을 만든다. 판별자를 학습시킬 때는 생성자의 가중치를 건드리면 안 되므로, 생성자의 출력을 판별자에 넣기 전에 `detach()`로 그래디언트가 생성자까지 흘러가지 않도록 막는다. 반대로 생성자를 학습시킬 땐 `detach()`를 쓰지 않아, 그래디언트가 생성자까지 그대로 전달되게 한다.

## 세 줄 정리
- GAN = 생성자(사기꾼)와 판별자(탐정)를 경쟁시켜 점점 더 진짜 같은 가짜를 만드는 방법
- 판별자 학습 땐 생성자 출력에 `detach()`를 써서 그래디언트를 끊는다
- 두 네트워크가 다른 목표를 가지므로 옵티마이저도 각자 따로 둔다
