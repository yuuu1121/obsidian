# GPU와 CUDA

> [!abstract] 한 줄 요약
> **GPU**(그래픽 처리 장치)는 원래 화면에 그림을 그리려고 만든 하드웨어인데, "똑같은 계산을 수천 개씩 동시에" 하는 데 특화돼 있어서 딥러닝의 행렬 연산에도 아주 잘 맞는다. **CUDA**는 엔비디아(NVIDIA) GPU를 프로그램에서 쓸 수 있게 해주는 인터페이스다.

> [!note] 왜 딥러닝에 GPU가 필요한가?
> 신경망 학습은 결국 **아주 많은 숫자를 곱하고 더하는** 작업(행렬 곱셈)의 반복이다. CPU는 "복잡한 일을 순서대로 잘"하는 데 강하고, GPU는 "단순한 일을 엄청 많이 동시에" 하는 데 강하다. 신경망 연산은 후자에 훨씬 가까워서, 같은 계산도 GPU에서 하면 수십~수백 배 빨라질 수 있다.

## 1. CPU vs GPU 비유

> [!tip] 비유 — 계산기 한 대 vs 계산기 수천 대
> CPU는 아주 똑똑한 계산기 몇 대가 어려운 문제를 하나씩 순서대로 푸는 것과 같다. GPU는 상대적으로 단순한 계산기 수천 대가 각자 자기 몫의 곱셈 하나씩을 **동시에** 처리하는 것과 같다. 신경망의 가중치 곱셈처럼 "똑같은 연산을 다른 숫자에 반복"하는 작업엔 후자가 압도적으로 유리하다.

## 2. CUDA란?

CUDA는 엔비디아가 만든, GPU에서 범용 계산을 돌릴 수 있게 해주는 플랫폼이다. PyTorch 같은 딥러닝 라이브러리는 내부적으로 CUDA를 이용해 GPU 연산을 수행한다.

## 3. PyTorch에서 GPU 쓰기

PyTorch의 모든 텐서 연산은 **CPU 버전과 GPU 버전이 둘 다 존재**하고, 어떤 텐서를 다루느냐에 따라 자동으로 선택된다. 텐서를 GPU로 옮기려면 `to(device)` 메서드를 쓴다.

```python
a = torch.FloatTensor([2, 3])      # CPU 텐서
ca = a.to('cuda')                   # GPU로 복사
```

GPU가 여러 장이면 `"cuda:0"`, `"cuda:1"`처럼 인덱스를 붙여 구분한다.

> [!note] backend라는 더 큰 개념
> PyTorch는 CPU·CUDA뿐 아니라 더 일반적인 **backend**(연산 장치) 개념을 가진다. 예를 들어 Apple 하드웨어에서는 `mps`라는 이름의 backend(Metal Performance Shaders)를 지원한다. 즉 코드를 크게 안 바꿔도 다양한 하드웨어에서 돌릴 수 있다.

## 세 줄 정리
- GPU = "단순 계산을 아주 많이 동시에" 하는 데 특화된 하드웨어
- CUDA = 엔비디아 GPU를 프로그램에서 쓰게 해주는 인터페이스
- PyTorch는 `to('cuda')` 한 줄로 텐서를 GPU로 옮겨 자동으로 빠르게 계산한다
