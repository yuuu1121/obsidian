# IID (독립 항등 분포)와 강화학습의 non-IID 문제

> [!abstract] 한 줄 요약
> **IID** = 데이터들이 ①서로 **독립**이고 ②같은 **분포**에서 뽑혔다는 뜻. 지도학습은 이걸 가정하지만, **강화학습은 이 가정이 깨진다**(non-IID). 이것이 RL을 어렵게 만드는 핵심 이유 중 하나다.

## 1. IID란? — 두 글자씩 풀기

**IID = Independent and Identically Distributed**

### (1) Independent (독립)
각 데이터가 **서로 영향을 주지 않는다.** 하나의 결과가 다음 결과를 바꾸지 않는다.
- 예: 동전을 던질 때, 이번에 앞면이 나왔다고 다음번 확률이 바뀌지 않는다.

### (2) Identically Distributed (항등 분포)
모든 데이터가 **같은 확률 분포**에서 나온다. 규칙이 중간에 안 바뀐다.
- 예: 계속 같은 (공정한) 동전을 쓴다. 도중에 다른 동전으로 바꾸지 않는다.

### 비유 — 항아리에서 공 꺼내기
공이 잔뜩 든 항아리에서 공을 하나 꺼내 **색을 보고 다시 넣는다.** 매번 조건이 똑같고(항등), 이전에 뭘 뽑았든 다음에 영향 없다(독립). 이것이 IID다.

## 2. 지도학습은 왜 IID를 가정하나?

사진 분류기를 학습할 때, 훈련 사진들을 **무작위 순서로 섞어서** 보여준다. 각 사진은 서로 독립이고, 같은 데이터셋(같은 분포)에서 뽑힌다. 이 IID 가정 덕분에 경사하강 같은 학습법이 **안정적으로 수렴**한다.

## 3. 강화학습은 왜 non-IID인가? (핵심!)

RL에서 에이전트가 보는 데이터(관측)는 **자기 행동의 결과**다. 그래서 IID가 두 가지 방식으로 깨진다.

### (1) 독립성 붕괴 — 데이터가 연속적으로 이어진다
게임에서 지금 화면은 **바로 전 화면과 거의 똑같다.** 연속된 프레임들은 강하게 **상관**되어 있어 독립이 아니다.

### (2) 항등성 붕괴 — 정책이 바뀌면 분포도 바뀐다
에이전트가 학습하며 **행동 방식(정책)을 바꾸면**, 방문하는 상태들의 분포 자체가 **계속 변한다.** 어제 보던 데이터와 오늘 보는 데이터가 다른 분포다.

> [!warning] 책의 핵심 경고 — "인생은 고통이야" 함정
> 에이전트가 **비효율적으로 행동하면**, 온통 나쁜 관측만 보게 된다. 그러면 *"여기선 더 큰 보상을 얻을 방법이 없구나"* 라는 **잘못된 결론**에 빠진다. 실제로는 다르게 행동하면 큰 보상이 있는데도! 이것이 non-IID가 만드는 위험이다. 에이전트가 보는 세계는 **자기 행동에 의해 편향**되어 있다.

## 4. RL은 이 문제를 어떻게 다루나? (미리보기)

뒤 챕터에서 배울 해결책들:
- **경험 재생(Experience Replay)**: 과거 경험을 큰 버퍼에 저장했다가 **무작위로 섞어** 꺼내 학습 → 연속성(상관관계)을 깨서 IID에 가깝게 만든다. (6장 DQN)
- **탐험(Exploration)**: 일부러 새로운 행동을 시도해 편향된 시야를 넓힌다.

## 세 줄 정리
- IID = 데이터가 **독립**이고 **같은 분포**에서 나옴
- 지도학습은 IID 가정, **RL은 non-IID**(행동이 데이터를 바꿈)
- 그래서 RL은 **경험 재생·탐험** 같은 특별한 장치가 필요하다
