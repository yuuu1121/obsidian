# REINFORCE 알고리즘

> [!abstract] 한 줄 요약
> **REINFORCE**는 [[정책 경사 Policy Gradient]]를 실제로 계산할 때, $Q(s,a)$ 자리에 **에피소드를 끝까지 플레이해서 실제로 얻은 할인 총보상**을 그대로 대입하는 가장 기본적인 정책 경사 알고리즘이다.

## 1. 아이디어 — 크로스 엔트로피 방법의 확장

[[교차 엔트로피 Cross-Entropy|크로스 엔트로피 방법]]은 좋은 에피소드(평균보다 총보상이 높은 에피소드)의 행동엔 "정답(1)"을, 나쁜 에피소드의 행동엔 "오답(0)"을 매겨 학습했다. REINFORCE는 이 0/1 대신 **실제 할인 총보상 값**을 써서 더 세밀하게 구분한다 — 총보상 10인 에피소드가 총보상 1인 에피소드보다 학습에 더 크게 기여하도록.

## 2. 절차

1. 네트워크를 무작위 가중치로 초기화.
2. $N$개의 완전한 에피소드를 플레이하며 $(s,a,r,s')$ 전이를 저장.
3. 각 스텝 $t$에서, 그 이후 보상들의 할인 합을 계산: $Q_{k,t} = \sum_{i=0}^{\infty}\gamma^i r_i$
4. 손실 계산: $\mathcal{L} = -\sum_{k,t} Q_{k,t}\log(\pi(s_{k,t},a_{k,t}))$
5. SGD로 손실을 최소화.
6. 2번부터 반복.

## 3. Q-러닝과 다른 점 세 가지

| 특징 | REINFORCE | Q-러닝(DQN) |
|---|---|---|
| 탐험 | 확률적 정책이 자동으로 탐험을 수행(엡실론-그리디 불필요) | [[엡실론-그리디 탐험]]으로 명시적 탐험 필요 |
| 학습 데이터 | 온폴리시 — 항상 현재 정책의 신선한 데이터만 사용 | 오프폴리시 — [[경험 재생 Experience Replay|리플레이 버퍼]]로 옛 데이터 재사용 가능 |
| 타깃 네트워크 | 불필요(가치를 근사하지 않고 직접 경험한 보상을 씀) | [[타깃 네트워크와 부트스트래핑|필요]](상관관계를 끊기 위해) |

## 4. 계산 트릭 — 할인 총보상을 뒤에서부터

```python
def calc_qvals(rewards):
    res = []
    sum_r = 0.0
    for r in reversed(rewards):
        sum_r *= GAMMA
        sum_r += r
        res.append(sum_r)
    return list(reversed(res))
```

에피소드 끝에서부터 거꾸로 훑으면, "이전까지의 총보상 × γ + 지금 보상"만으로 매 스텝의 총보상을 효율적으로 계산할 수 있다.

## 세 줄 정리
- REINFORCE는 정책 경사 공식의 $Q(s,a)$에 실제 플레이한 에피소드의 할인 총보상을 대입한 것이다.
- 탐험·리플레이버퍼·타깃네트워크가 모두 필요 없다는 점에서 DQN과 크게 다르다.
- 완전한 에피소드가 끝나야 학습할 수 있고, 그래디언트 분산이 크다는 한계가 있다.
