# 관측공간과 행동공간(Space)

> [!abstract] 한 줄 요약
> **행동공간(action space)** 은 "에이전트가 고를 수 있는 행동들의 목록"이고, **관측공간(observation space)** 은 "환경이 줄 수 있는 관측값의 형태·범위"다. Gym은 이 둘을 표현하기 위해 `Space`라는 **틀(클래스)** 을 만들고, 그 아래 `Discrete`(이산)와 `Box`(연속) 두 가지 대표 형태를 둔다. 자세한 [[API와 클래스·객체]] 개념을 먼저 보면 이해가 쉽다.

## 1. Space가 왜 필요한가?

에이전트를 짤 때 이런 질문에 항상 답할 수 있어야 한다.
- "내가 고를 수 있는 행동이 몇 가지지? 그중 아무거나 하나 뽑으려면?"
- "환경이 주는 관측값은 숫자가 몇 개고, 각 숫자의 최솟값·최댓값은 뭐지?"

이 질문에 **모든 환경에서 똑같은 방식**으로 답할 수 있게 만든 것이 `Space` 클래스다. `Discrete(2)`처럼 종류만 다를 뿐, 사용법은 항상 같다.

`Space` 클래스가 공통으로 갖는 기능:
- `shape`: 이 공간이 몇 차원, 몇 개의 숫자로 이루어졌는지.
- `sample()`: 이 공간에서 **무작위로 값 하나를 뽑는다.** (자세히는 아래 3번 참고)
- `contains(x)`: 값 `x`가 이 공간에 속하는지 확인.
- `seed()`: 난수 생성기의 씨앗값을 고정해, 같은 무작위 결과를 재현할 수 있게 함.

## 2. 대표적인 Space 하위 종류

### Discrete — 이산 공간 (버튼 고르기)

**서로 배타적인 유한 개의 선택지**를 0부터 n-1까지 번호로 표현한다. ([[이산 행동과 연속 행동]] 참고)

```python
Discrete(n=4)   # 0, 1, 2, 3 중 하나 → 예: 좌/우/상/하 이동
```

CartPole 환경의 행동공간은 `Discrete(2)` 다. 즉 행동은 **0(왼쪽으로 밀기)** 또는 **1(오른쪽으로 밀기)** 딱 두 가지뿐이다.

### Box — 연속 공간 (다이얼 돌리기)

**구간 [low, high] 안의 실수 값**으로 이루어진 n차원 텐서(숫자 덩어리)를 표현한다.

```python
Box(low=0.0, high=1.0, shape=(1,), dtype=np.float32)
# 예: 가속 페달 - 0.0(안 밟음) ~ 1.0(끝까지 밟음) 사이의 실수 하나
```

- `shape=(1,)`: 숫자 1개짜리 벡터.
- `shape=(210, 160, 3)`: Atari 화면 이미지처럼 (세로 210 × 가로 160 × 색상 3채널) 형태의 3차원 덩어리.
- `dtype`: 그 값들이 어떤 자료형인지 (`np.float32` = 32비트 실수, `np.uint8` = 0~255 정수 등).

CartPole의 관측공간은 `Box(4,)` — 카트 위치, 카트 속도, 막대 각도, 막대 각속도. 이 네 실수로 이루어진다.

### Tuple — 여러 Space를 묶기

`Discrete`나 `Box` 하나로는 부족할 때, **여러 Space를 하나로 묶는** 컨테이너다.

```python
Tuple(spaces=(
    Box(low=-1.0, high=1.0, shape=(3,), dtype=np.float32),  # 핸들, 브레이크, 가속페달
    Discrete(n=3),   # 방향지시등: 끔/좌/우
    Discrete(n=2),   # 경적: 끔/켬
))
```

자동차 조작을 예로 들면, "핸들 각도·브레이크·가속페달"(연속값 3개)과 "방향지시등"(이산 3가지), "경적"(이산 2가지)을 한꺼번에 하나의 행동공간으로 표현할 수 있다. 이 밖에도 가변 길이를 다루는 `Sequence`, 문자열을 다루는 `Text`, 그래프 구조를 다루는 `Graph` 등이 있지만 이 책에서는 대부분 `Box`와 `Discrete`만 사용한다.

## 3. sample() — 확률분포에서 무작위로 하나 뽑기

> [!note] "샘플링(sampling)"이란?
> 통계에서 **샘플링**은 "전체 가능한 값들 중에서 규칙에 따라 하나(또는 여러 개)를 무작위로 골라내는 것"을 말한다. 제비뽑기 상자에서 종이 한 장을 뽑는 것과 같다. `Space.sample()`은 "이 공간에 속한 값 중 하나를 균등하게(모두 같은 확률로) 무작위로 뽑아 달라"는 뜻이다.

- `Discrete(2).sample()` → 0 또는 1을 각각 50%의 확률로 무작위로 하나 반환.
- `Box(4,).sample()` → 정해진 범위 안의 실수 4개로 이루어진 벡터를 무작위로 하나 반환.

이 기능이 유용한 이유: 아직 똑똑한 정책(policy)을 만들기 전이라도, **일단 무작위로 행동해보는 에이전트**를 즉시 만들 수 있기 때문이다. 이것이 이 챕터에서 만드는 "랜덤 CartPole 에이전트"의 핵심 트릭이다.

## 4. Env 클래스와의 관계

모든 환경(`Env`)은 `action_space`와 `observation_space`라는 두 개의 `Space` 객체를 필드로 갖는다.

```python
env.action_space        # 이 환경에서 가능한 행동들의 형태
env.observation_space   # 이 환경이 주는 관측값의 형태
```

이 덕분에 에이전트 코드를 **환경에 상관없이 일반적으로** 짤 수 있다 — "행동공간에서 무작위로 하나 뽑아서 실행해봐" 같은 코드는 CartPole이든 다른 어떤 환경이든 그대로 작동한다.

## 세 줄 정리
- `Space` = 행동·관측이 "어떤 모양이고 어떤 범위인지"를 담는 공통 틀
- `Discrete` = 버튼(유한 개 중 하나), `Box` = 다이얼(구간 안의 실수), `Tuple` = 여러 개를 묶은 것
- `sample()` = 그 공간에서 값 하나를 무작위로 뽑는 것(균등 확률) — 정책 없이도 일단 움직여볼 수 있게 해준다
