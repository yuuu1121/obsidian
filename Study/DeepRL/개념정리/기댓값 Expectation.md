# 기댓값 (Expectation, $\mathbb{E}[\cdot]$)

> [!abstract] 한 줄 요약
> **기댓값**은 "확률적으로 벌어지는 일을 **아주 여러 번 반복했을 때의 평균값**"이다. RL에서 상태의 가치 $V(s) = \mathbb{E}[G_t]$ 처럼, 들쭉날쭉한 결과를 **하나의 대표값**으로 요약할 때 쓴다.

## 1. 기댓값이란?

주사위를 굴려서 나온 눈만큼 돈을 받는다고 하자. 한 번 굴리면 1~6 중 아무거나 나온다(들쭉날쭉). 하지만 **수천 번 굴려 평균**을 내면 항상 **3.5** 근처에 수렴한다. 이 3.5가 바로 **기댓값**이다.

$$\mathbb{E}[X] = \sum_{i} (\text{값}_i \times \text{그 값이 나올 확률}_i)$$

주사위: $\mathbb{E}[X] = 1\cdot\frac16 + 2\cdot\frac16 + 3\cdot\frac16 + 4\cdot\frac16 + 5\cdot\frac16 + 6\cdot\frac16 = 3.5$

> [!note] 기댓값은 "실제로 나오는 값"이 아닐 수 있다
> 주사위 눈에 3.5는 없다! 기댓값은 **평균적 경향**이지, 특정 결과가 아니다. "평균 자녀 수 1.8명" 같은 것과 같다.

## 2. 가중평균으로 이해하기

기댓값은 **확률로 가중치를 준 평균**이다. 확률이 높은 값일수록 평균에 더 크게 기여한다.

### 예 — 불공정한 게임
- 90% 확률로 +1점, 10% 확률로 −5점을 받는 게임.
- $\mathbb{E} = 0.9 \times (+1) + 0.1 \times (-5) = 0.9 - 0.5 = +0.4$
- → 평균적으로는 조금 이득인 게임이다.

## 3. RL에서의 기댓값 — 상태의 가치

RL에서 **리턴 $G_t$**(미래 보상의 할인 합)은 **에피소드마다 다르다.** 같은 상태에서 출발해도 어떤 날은 운이 좋고 어떤 날은 나쁘다. 그래서 **하나의 대표값**이 필요하다.

$$V(s) = \mathbb{E}[G_t \mid S_t = s]$$

읽는 법: *"상태 $s$ 에서 출발했을 때 얻을 리턴의 **평균(기댓값)**"*. 조건부 기호 $\mid S_t = s$ 는 "상태가 $s$ 라는 조건 하에서"를 뜻한다.

```
상태 s에서 출발 → 에피소드 A: 리턴 = 10
                → 에피소드 B: 리턴 = 4
                → 에피소드 C: 리턴 = 7
                → ... (수천 번)
                → 평균 ≈ V(s)  ← 이게 상태 s의 '가치'
```

> [!important] 왜 리턴 대신 기댓값(가치)을 쓰나?
> 리턴 하나는 **운에 따라 크게 흔들린다.** 반면 기댓값(가치)은 **안정적인 대표값**이라, "이 상태가 얼마나 좋은가"를 공정하게 비교할 수 있다. RL의 목표는 결국 이 **기대 리턴을 최대화**하는 것이다.

## 4. 왜 '평균'이 강력한가 — 큰 수의 법칙

**큰 수의 법칙(Law of Large Numbers)**: 시행을 많이 할수록, 실제 평균이 기댓값에 점점 가까워진다. 그래서 RL에서 에이전트가 **많은 경험**을 쌓으면, 각 상태의 진짜 가치를 점점 정확히 추정할 수 있다. (뒤 챕터의 몬테카를로 방법이 이 원리를 그대로 쓴다.)

## 세 줄 정리
- 기댓값 = **(값 × 확률)의 총합** = 무한 반복 시의 평균
- RL의 가치 $V(s)$ = 그 상태에서 출발한 **리턴의 기댓값**
- 경험이 많을수록 추정값이 **참 기댓값에 수렴**한다 (큰 수의 법칙)
