# 듀얼링 DQN (Dueling Architecture)

> [!abstract] 한 줄 요약
> 듀얼링 DQN은 Q값을 한 번에 예측하지 않고, **"이 상태 자체가 얼마나 좋은가(가치, Value)"**와 **"이 상태에서 이 행동이 다른 행동보다 얼마나 더 나은가(우위, Advantage)"**를 따로 예측한 뒤 합쳐서 Q값을 만드는 신경망 구조다.

## 비유로 이해하기

시험 점수를 예측한다고 하자. "이 반 전체의 평균 점수가 몇 점일까"(반 전체 수준 = 가치)를 먼저 가늠하고, 그 다음 "이 학생이 반 평균보다 몇 점 더 잘하거나 못할까"(개인차 = 우위)를 따로 계산하면, 두 정보를 더해서 그 학생의 최종 점수를 추정할 수 있다.

Q값도 마찬가지다. "이 상태가 원래 얼마나 좋은 상태인가"와 "이 상태에서 특정 행동을 골랐을 때 얼마나 이득인가"는 서로 다른 정보다. 이걸 분리해서 학습하면, 어떤 행동을 하든 결과가 비슷한 상태(예: 주식을 안 갖고 있어서 딱히 할 게 없는 상태)에서도 신경망이 더 안정적으로 학습할 수 있다.

## 수식으로 보기

$$Q(s, a) = V(s) + \left(A(s, a) - \frac{1}{|\mathcal{A}|}\sum_{a'} A(s, a')\right)$$

- $V(s)$: 상태 $s$ 자체의 가치(행동과 무관).
- $A(s, a)$: 상태 $s$에서 행동 $a$를 선택했을 때의 우위(advantage).
- 우위에서 **평균을 빼주는 이유**: 그냥 $Q = V + A$로만 정의하면, $V$와 $A$를 각각 얼마씩 나눠 가질지가 무한히 여러 방법으로 나올 수 있어(예: $V$에 10을 더하고 모든 $A$에서 10을 빼도 결과는 똑같음) 학습이 불안정해진다. 평균을 빼면 "우위들의 평균은 항상 0"이라는 제약이 생겨, $V$와 $A$의 역할이 명확히 갈라진다.

## 챕터 속 맥락 (10장)

```python
def forward(self, x: torch.Tensor) -> torch.Tensor:
    val = self.fc_val(x)   # 상태 가치 V(s), 숫자 1개
    adv = self.fc_adv(x)   # 각 행동의 우위 A(s,a), 행동 개수만큼
    return val + (adv - adv.mean(dim=1, keepdim=True))
```

트레이딩 환경에서는 `fc_val`(가치 예측 네트워크)과 `fc_adv`(우위 예측 네트워크)를 따로 두고, 마지막에 위 공식대로 합쳐서 최종 Q값을 만든다. 이는 8장에서 아타리 게임에 처음 적용했던 것과 동일한 구조를 그대로 재사용한 것이다.

## 세 줄 정리
- 듀얼링 DQN은 Q값을 "상태 가치"와 "행동별 우위"로 나눠서 따로 학습한 뒤 합친다.
- 우위에서 평균을 빼주는 이유는 가치와 우위의 역할을 유일하게 정하기 위해서다.
- 어떤 행동을 하든 결과가 비슷한 상태에서 학습을 더 안정적으로 만들어준다.
