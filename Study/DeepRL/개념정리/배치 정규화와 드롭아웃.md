# 배치 정규화(Batch Normalization)와 드롭아웃(Dropout)

> [!abstract] 한 줄 요약
> 둘 다 신경망이 **적은 데이터에 과하게 외워버리는 것(과적합)**을 막는 도구다. 배치 정규화는 "층마다 값의 스케일을 가지런히 정리"해 학습을 안정시키고, 드롭아웃은 "학습 중 일부러 일부 뉴런을 꺼서" 특정 뉴런에만 의존하지 못하게 만든다.

RLHF의 보상 모델은 겨우 100~300개의 사람 라벨로 학습되는데, 이렇게 데이터가 적으면 신경망이 [[과적합과 검증데이터|과적합]]에 매우 취약하다. 그래서 보상 모델의 합성곱 층마다 이 두 기법이 함께 들어간다.

```python
nn.Conv2d(input_shape[0], 16, kernel_size=7, stride=3),
nn.BatchNorm2d(16),
nn.Dropout(p=0.5),
nn.LeakyReLU(),
```

## 1. 배치 정규화 — 값의 스케일을 가지런히

신경망을 층층이 쌓다 보면, 학습이 진행되면서 각 층에 들어오는 값들의 평균·분산이 계속 들쭉날쭉 바뀐다. 이걸 **내부 공변량 변화(internal covariate shift)**라 부르는데, 매 층이 "자꾸 바뀌는 입력 분포"에 맞춰 계속 재적응해야 하니 학습이 느리고 불안정해진다.

> [!tip] 비유 — 계속 흔들리는 눈금
> 매번 눈금이 제멋대로 바뀌는 저울로 요리 재료를 계량한다고 생각해보자. 재료 비율을 맞추기가 매우 어렵다. **배치 정규화**는 매 층을 지날 때마다 "이 배치 안에서 평균 0, 분산 1이 되도록" 값을 다시 맞춰주는 것 — 저울 눈금을 매번 초기화해주는 셈이다. 그러면 다음 층은 항상 비슷한 스케일의 입력을 받으므로 학습이 훨씬 안정적이고 빨라진다.

`BatchNorm2d(16)`은 "16개 채널 각각에 대해, 지금 배치 안에서 평균·분산을 계산해 정규화한다"는 뜻이다.

## 2. 드롭아웃 — 일부러 일부를 꺼버리기

**드롭아웃**은 학습 중 매 순간 **뉴런의 일부를 확률적으로 완전히 꺼버리는(출력을 0으로 만드는)** 기법이다. `Dropout(p=0.5)`는 "이 층 출력의 각 값을 50% 확률로 0으로 만든다"는 뜻이다.

> [!tip] 비유 — 반 학생 절반이 매번 무작위로 결석
> 조별 과제를 하는데, 매 시간마다 조원의 절반이 무작위로 결석한다고 하자. 그러면 "한 명의 스타 조원에게만 의존"하는 전략은 통하지 않는다. 누가 빠지든 조가 굴러가려면, **모든 조원이 골고루 실력을 갖춰야** 한다. 드롭아웃도 마찬가지다 — 특정 뉴런 하나에 과도하게 의존하는 지름길을 막아, 신경망 전체가 골고루 강건한 특징을 배우게 한다.

학습이 끝나고 실전 추론(evaluation)에 쓸 때는 드롭아웃을 끄고 모든 뉴런을 다 사용한다(코드에서 `model.eval()`을 호출하면 자동으로 꺼진다).

## 3. 왜 둘 다 같이 쓰나

배치 정규화는 "학습을 안정적이고 빠르게" 만드는 데 초점이 있고, 드롭아웃은 "과적합을 막는 데" 초점이 있다. 목적이 달라 함께 써도 문제가 없고, 오히려 데이터가 아주 적은 RLHF 보상 모델처럼 **과적합 위험이 큰 상황**에서는 두 안전장치를 겹으로 두는 것이 흔한 관행이다.

## 세 줄 정리
- 배치 정규화는 매 층의 값 스케일을 가지런히 맞춰 학습을 안정시킨다.
- 드롭아웃은 학습 중 뉴런 일부를 무작위로 꺼서 특정 뉴런 의존을 막고 과적합을 줄인다.
- 데이터가 적은 RLHF 보상 모델처럼 과적합 위험이 큰 네트워크에 특히 함께 자주 쓰인다.
