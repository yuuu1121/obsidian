# 백분위수(Percentile) 필터링

> [!abstract] 한 줄 요약
> **백분위수**는 "전체 데이터 중 몇 %가 이 값보다 작은가"를 나타내는 기준점이다. **70번째 백분위수**로 필터링한다는 것은 "하위 70%를 버리고, 상위 30%만 남긴다"는 뜻이다.

## 1. 비유 — 시험 등수

전교생 100명이 시험을 봤다. "70번째 백분위수 점수가 80점"이라는 말은, **점수가 80점 이하인 학생이 전체의 70%**라는 뜻이다. 다시 말해 **80점을 넘긴 학생은 상위 30%**다.

```
점수 낮음 ──────────────────────────→ 점수 높음
[███████████████████████████████████░░░░░░░░░░]
              70% (하위)              30%(상위, 80점 초과)
                          ↑
                    70번째 백분위수 = 80점
```

## 2. 왜 "70점 이상"이 아니라 "70번째 백분위수"를 쓸까?

고정된 점수(예: "80점 이상만 합격")를 기준으로 삼으면, 그 시험이 쉬웠는지 어려웠는지에 따라 합격자 수가 들쭉날쭉해진다. 반면 **백분위수**를 쓰면, 시험 난이도와 무관하게 **항상 상위 몇 %**를 정확히 골라낼 수 있다. Chapter 4의 교차 엔트로피 방법에서는 훈련이 진행되며 에이전트의 실력(그리고 보상의 전체적인 수준)이 계속 바뀌기 때문에, 고정된 점수 기준보다 **상대적인 백분위수 기준**이 훨씬 유용하다.

## 3. NumPy에서의 계산

```python
reward_bound = float(np.percentile(rewards, percentile))
```

- `rewards`: 이번 배치에서 플레이한 모든 에피소드의 총 보상 리스트.
- `percentile`: 원하는 백분위수(예: 70).
- `np.percentile(rewards, 70)`: 이 리스트에서 "하위 70%가 이 값 이하"가 되는 경계 보상값을 계산해 준다.

### 예시

에피소드 10개의 보상이 `[10, 15, 20, 22, 25, 30, 35, 40, 45, 100]` 이라 하자. 70번째 백분위수는 대략 **7번째로 큰 값 근처**(하위 70% = 7개)인 35 정도가 된다. 이 값을 `reward_bound` 로 삼으면, 보상이 35보다 큰 에피소드들(40, 45, 100)만 "엘리트"로 남고, 나머지(35 이하)는 버려진다.

## 4. Chapter 4의 교차 엔트로피 방법에서

```python
PERCENTILE = 70
...
for episode in batch:
    if episode.reward < reward_bound:
        continue          # 하위 70%는 버림
    train_obs.extend(...)  # 상위 30%(엘리트)만 훈련 데이터로 사용
    train_act.extend(...)
```

이 **백분위수 필터링**이야말로 Chapter 4에서 배운 [[교차 엔트로피 Cross-Entropy]] 방법의 핵심 메커니즘이다. "잘한 것만 골라 따라 배우기"에서, **"잘한 것"을 정확히 어떻게 판별할지**를 정하는 도구가 바로 백분위수다.

> [!warning] 백분위수 필터링이 실패하는 경우 — FrozenLake
> Chapter 4에서 보았듯, FrozenLake처럼 보상이 **0 아니면 1뿐인 이진(binary) 값**이면, 백분위수 필터링이 제대로 작동하지 않는다. 예를 들어 배치의 100개 에피소드 중 95개가 실패(보상 0)하고 5개만 성공(보상 1)했다면, **70번째 백분위수는 0이 되어버린다**(하위 70%는 물론이고 그보다 훨씬 많은 에피소드가 보상 0이므로). 그러면 "경계값보다 높은" 에피소드는 성공한 5개뿐 아니라, **운 좋게 살아남은 실패 에피소드도 뒤섞여 들어갈 위험**이 있고, 애초에 성공 사례 자체가 워낙 희소해서 필터링이 무의미해진다. 이것이 [[몬테카를로식 에피소드]] 노트에서 언급한 "보상 구조가 나쁘면 학습이 어렵다"는 문제의 구체적인 원인이다.

## 세 줄 정리
- 백분위수 = "전체 중 몇 %가 이 값보다 작은가"를 나타내는 상대적 기준점.
- 고정 점수 대신 백분위수를 쓰면, 데이터(보상)의 전체 수준이 훈련 중 계속 바뀌어도 "항상 상위 몇 %"를 일관되게 골라낼 수 있다.
- Chapter 4에서는 `np.percentile(rewards, 70)` 로 보상 경계값을 구해, 상위 30% 에피소드만 훈련에 쓰는 "엘리트 필터링"을 구현한다.
