# 상태 · 관측 · 에피소드 · 정책 — RL 핵심 4용어

> [!abstract] 한 줄 요약
> RL을 읽다 보면 계속 나오는 네 단어. **상태**(세상의 실제 모습) → **관측**(내가 실제로 보는 것) → **에피소드**(한 판의 경험 기록) → **정책**(내 행동 규칙). 이 네 개만 확실히 잡으면 절반은 이해한 것이다.

## 1. 상태 (State) vs 관측 (Observation) — 가장 헷갈리는 구분

> [!important] 한 문장 구분
> **상태 = 환경의 진짜 속사정 (전부)**, **관측 = 내가 실제로 볼 수 있는 일부.**

### 비유 — 포커 게임
- **상태(state)**: 모든 플레이어의 손패 + 남은 카드 더미까지 포함한 **완전한 진실.** 아무도 다 알 수 없다.
- **관측(observation)**: 내 손패 + 테이블에 깔린 카드처럼 **내가 실제로 보는 것.**

포커를 잘 두려면 "안 보이는 상태"를 관측으로부터 **추측**해야 한다. RL도 마찬가지다.

### 왜 구분이 중요한가
- 상태는 이론상 **우주의 모든 원자**까지 포함해서 완전히 측정 불가능하다.
- 관측은 상태의 **일부**이거나, **노이즈**가 섞였거나, **가공**된 형태다.
- RL은 이렇게 **불완전한 관측만으로도** 학습하도록 설계되었다.

| 예시 | 상태(진짜 전부) | 관측(보이는 것) |
|---|---|---|
| 주식 트레이딩 | 전 세계 시장·뉴스·심리 | 주가, 뉴스 헤드라인 |
| 체스 | 상대의 실력·기분·전략 | 현재 보드 배치 |
| 게임 | 컴퓨터 메모리 전체 | 화면 픽셀, 소리 |

## 2. 에피소드 (Episode)

**에피소드 = 시작부터 끝까지 한 판의 경험 기록** (상태·행동·보상의 시퀀스).

예) 직장인 하루: `집 → 커피 → 커피 → 잡담 → 컴퓨터 → 집`
예) 게임: `시작 → (행동들·보상들) → 게임오버`

- 실제 전이 확률을 몰라도, 에피소드를 **많이 모으면** 시스템의 규칙을 추정할 수 있다.
- 에피소드마다 내용이 다르다(운·무작위성). 하지만 그 밑에 깔린 확률은 같다.

## 3. 정책 (Policy) $\pi$ — RL의 최종 목표

> **정책 = "어떤 상태에서 어떤 행동을 할지" 정하는 규칙.**

RL의 목표는 결국 **좋은 정책을 찾는 것**이다. 정책이 다르면 얻는 보상도 완전히 달라진다.

### 공식 정의 — 확률로 표현
$$\pi(a \mid s) = P[A_t = a \mid S_t = s]$$

읽는 법: *"상태 $s$ 일 때 행동 $a$ 를 고를 확률."*

### 왜 '확률'로 정의할까?
행동에 **무작위성**을 넣기 위해서다. 항상 같은 행동만 하면 새로운 걸 시도(탐험)할 수 없다.
- **확률적 정책**: 상태 s에서 "80% 왼쪽, 20% 오른쪽"처럼 확률로 고름.
- **결정론적 정책**: 항상 정해진 하나("100% 왼쪽"). → 확률적 정책의 특수한 경우다.

### 정책 예시 (격자 로봇)
- 무조건 앞으로만 간다
- 장애물을 만나면 돌아간다
- 계속 우회전만 한다 🙃
- 완전 무작위 (술 취한 로봇)
→ 정책마다 **모으는 보상이 천차만별.** 그래서 좋은 정책 찾기가 중요!

> [!note] 정책이 고정되면 MDP → MRP
> 학습 중 정책이 **고정**되어 있으면(같은 상태 → 항상 같은 행동 확률), 행동 차원을 정책 확률로 눌러 없앨 수 있어 MDP가 다시 MRP로 축소된다.

## 네 줄 정리
- **상태** = 세상의 진짜 전부 (측정 불가)
- **관측** = 내가 실제로 보는 일부
- **에피소드** = 한 판의 경험 기록
- **정책** = 상태별 행동 규칙 (RL이 찾으려는 목표)
