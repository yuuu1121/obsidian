# 신경망 · 경사하강 · 역전파 — 딥러닝 3대 기초

> [!abstract] 한 줄 요약
> **신경망**은 숫자를 넣으면 답을 내는 "조절 가능한 거대 함수"다. **경사하강**은 그 함수의 오차를 줄이는 방향으로 조금씩 내려가는 방법이고, **역전파**는 그 방향(기울기)을 효율적으로 계산하는 기술이다. 강화학습도 이 셋을 도구로 빌려 쓴다.

> [!note] 왜 RL 책에서 이걸 알아야 하나?
> "Deep" RL의 "Deep"이 바로 **심층 신경망(Deep Neural Network)** 이다. RL은 "무엇을 배울지"를 정하고, 신경망은 "어떻게 함수를 표현할지"를 담당한다. 3장에서 PyTorch로 자세히 배우지만, 여기서 직관을 미리 잡아두자.

## 1. 신경망 (Neural Network, NN)

**입력 숫자들을 넣으면 출력 숫자들이 나오는, 조절 가능한 함수.**

```
입력 (예: 게임 화면 픽셀)
   │
   ▼
[뉴런층] → [뉴런층] → [뉴런층]     ← 각 연결마다 '가중치(weight)'라는 손잡이가 있음
   │
   ▼
출력 (예: 각 행동의 좋음 정도)
```

- **뉴런**: 입력들을 **가중치**를 곱해 더하고, 살짝 구부려(활성화 함수) 다음 층으로 넘긴다.
- **가중치(weight)**: 수백만~수십억 개의 **조절 손잡이.** 이걸 잘 맞추는 게 "학습"이다.
- **비유**: 수백만 개의 볼륨 노브가 달린 거대한 믹서. 노브를 잘 돌리면 원하는 소리(정답)가 난다.

## 2. 손실(Loss) — 얼마나 틀렸는가

학습하려면 먼저 **"얼마나 틀렸는지"를 숫자로** 재야 한다. 이것이 **손실 함수(loss)**.
- 예: 정답이 5인데 3을 냈으면, 손실 = $(5-3)^2 = 4$.
- 목표: **손실을 최대한 작게** 만드는 가중치 찾기.

## 3. 경사하강 (Gradient Descent)

**손실이 줄어드는 방향으로 가중치를 조금씩 옮기는 방법.**

> [!tip] 비유 — 안개 낀 산에서 내려오기
> 짙은 안개 속 산에 있다. 정상 지도는 없지만, **발밑의 기울기**는 느낄 수 있다. 가장 가파르게 **내려가는 방향**으로 한 걸음씩 옮기면 결국 골짜기(최저점)에 닿는다.
> - 산 높이 = 손실(loss)
> - 위치 = 가중치
> - 내려가는 방향 = **경사(gradient)의 반대 방향**
> - 한 걸음 크기 = **학습률(learning rate)**

```
손실
 │＼
 │  ＼        한 걸음씩
 │    ＼___   내려간다
 │        ＼_____
 │              ＼___● ← 최저점(손실 최소)
 └───────────────────── 가중치
```

수식으로는: **새 가중치 = 옛 가중치 − (학습률 × 경사)**. 강화학습의 학습식들도 근본은 이 형태다.

## 4. 역전파 (Backpropagation)

**"어느 가중치를 얼마나 바꿔야 손실이 줄어드는지"(=경사)를 효율적으로 계산하는 방법.**

신경망에는 가중치가 수백만 개다. 각각에 대해 "이걸 조금 바꾸면 손실이 얼마나 변할까?"를 일일이 계산하면 너무 느리다. **역전파**는 미적분의 **연쇄법칙(chain rule)** 을 이용해, 출력 쪽 오차를 **입력 쪽으로 거꾸로 흘려보내며** 모든 경사를 **한 번에** 계산한다.

```
순전파(forward):  입력 → → → 출력 → 손실 계산
역전파(backward): 입력 ← ← ← 출력  (오차를 거꾸로 전파하며 경사 계산)
```

- **순전파**: 입력 → 출력 방향으로 답을 낸다.
- **역전파**: 손실 → 입력 방향으로 오차를 되돌리며 각 가중치의 경사를 구한다.
- 그 경사로 **경사하강**을 한 스텝 밟는다. 이 과정을 수백만 번 반복 = 학습.

> [!note] 이 셋의 관계
> **신경망**(표현) → **손실**(틀린 정도) → **역전파**(경사 계산) → **경사하강**(가중치 수정) → 반복. 이 사이클이 모든 딥러닝의 심장이며, Deep RL도 예외가 아니다.

## 네 줄 정리
- **신경망** = 조절 손잡이(가중치)가 잔뜩 달린 거대 함수
- **손실** = 얼마나 틀렸는지 재는 숫자
- **경사하강** = 손실 줄어드는 방향으로 한 걸음씩 (안개 속 하산)
- **역전파** = 그 방향(경사)을 연쇄법칙으로 빠르게 계산
