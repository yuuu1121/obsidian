# 엡실론-그리디(ε-greedy) 탐험

> [!abstract] 한 줄 요약
> **엡실론-그리디**는 확률 ε(엡실론)만큼은 무작위로 행동하고, 나머지 확률로는 지금까지 배운 최선의 행동을 하는 방법이다. 학습 초반엔 ε을 크게(많이 탐험), 후반엔 작게(많이 활용) 줄여가며 탐험과 활용의 균형을 맞춘다.

## 1. 왜 필요한가 — 탐험 vs 활용 문제

[[Chapter 01 - 강화학습이란 무엇인가]]에서 다룬 **탐험(explore) vs 활용(exploit)** 딜레마를 떠올려 보자. 에이전트가 학습 초기에 우연히 발견한 그럭저럭 괜찮은 행동만 계속 반복하면, 훨씬 더 좋은 행동이 있어도 영영 발견하지 못한다.

> [!tip] 비유 — 새로운 맛집 탐방
> 여러분이 이사 온 동네에서 첫날 들어간 식당이 꽤 맛있었다고 하자. 매일 그 집만 간다면 "이 동네 최고의 맛집"은 영영 못 찾을 수도 있다. 가끔은(확률 ε만큼) 새로운 식당에 **모험 삼아** 들어가 봐야, 진짜 최고의 맛집을 찾을 기회가 생긴다.

## 2. 알고리즘

매 스텝마다 다음 규칙으로 행동을 고른다.

$$
a = \begin{cases} \text{무작위 행동} & \text{확률 } \epsilon \text{로} \\ \arg\max_a Q(s,a) & \text{확률 } 1-\epsilon \text{로} \end{cases}
$$

- **ε (엡실론)**: 무작위 행동을 선택할 확률. 0~1 사이 값.
- ε=1.0이면 완전히 무작위(순수 탐험), ε=0이면 항상 Q값이 가장 큰 행동만 선택(순수 활용).

이 챕터의 코드에서는 다음처럼 구현된다.

```python
if np.random.random() < epsilon:
    action = env.action_space.sample()      # 무작위 행동
else:
    state_v = torch.as_tensor(self.state).to(device)
    state_v.unsqueeze_(0)
    q_vals_v = net(state_v)
    _, act_v = torch.max(q_vals_v, dim=1)
    action = int(act_v.item())               # Q값이 최대인 행동
```

`np.random.random()`은 0~1 사이 난수를 하나 뽑는다. 이 값이 ε보다 작으면(확률 ε로 발생) 무작위 행동을, 아니면 신경망이 예측한 Q값 중 가장 큰 행동을 선택한다.

## 3. ε을 점점 줄이는 이유 (Decay)

학습 초반에는 신경망의 Q값 추정이 형편없다(아직 아무것도 안 배웠으니까). 이때 Q값만 믿고 행동하면 처음부터 편향된 경험만 쌓인다. 그래서 **처음엔 ε=1.0(100% 무작위)** 으로 시작해 환경을 골고루 겪게 하고, 학습이 진행되며 신경망이 똑똑해질수록 **ε을 서서히 줄여** 점점 배운 지식을 신뢰하게 만든다.

이 챕터의 Pong 예제에서는 다음 스케줄을 쓴다.

```python
EPSILON_DECAY_LAST_FRAME = 150000
EPSILON_START = 1.0
EPSILON_FINAL = 0.01

epsilon = max(EPSILON_FINAL, EPSILON_START - frame_idx / EPSILON_DECAY_LAST_FRAME)
```

프레임(스텝) 수가 늘어날수록 `EPSILON_START - frame_idx / EPSILON_DECAY_LAST_FRAME` 값은 선형으로 줄어들다가, `EPSILON_FINAL`(0.01) 밑으로는 더 내려가지 않도록 `max()`로 막아둔다. 즉 150,000 프레임에 걸쳐 100% 무작위에서 1% 무작위까지 **직선으로** 줄어들고, 그 이후는 계속 1%를 유지한다.

> [!note] 원래 DeepMind 논문과의 차이
> DeepMind의 원 논문은 100만 프레임에 걸쳐 ε=1.0→0.1로 감소시켰다. 이 책은 Pong 하나에 맞춰 15만 프레임 만에 0.01까지 훨씬 빠르게 줄인다. 게임마다 최적의 감소 속도는 다르다 — 너무 빨리 줄이면 탐험 부족으로 나쁜 정책에 갇히고, 너무 느리면 학습이 오래 걸린다.

## 세 줄 정리
- 확률 ε로 무작위 행동(탐험), 확률 1-ε로 최선의 행동(활용)을 섞는다.
- 학습 초반엔 ε을 크게 시작해 골고루 경험을 쌓고, 점점 줄여 배운 지식을 활용한다.
- ε 감소 속도는 하이퍼파라미터이며, 게임/환경마다 적절히 조정해야 한다.
