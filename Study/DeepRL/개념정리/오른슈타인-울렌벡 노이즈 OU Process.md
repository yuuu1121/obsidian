# 오른슈타인-울렌벡(Ornstein-Uhlenbeck, OU) 노이즈

> [!abstract] 한 줄 요약
> [[결정론적 정책 Deterministic Policy]]는 스스로 탐험을 못 하므로, 행동 값에 **일부러 흔들림(노이즈)** 을 더해줘야 한다. OU 노이즈는 완전히 제멋대로인 흰 소음(백색잡음)과 달리, **관성이 있어서 부드럽게 이어지는** 흔들림을 만드는 방법이다.

## 1. 왜 그냥 랜덤 노이즈로는 부족한가

가장 단순한 탐험 방법은 매 순간 독립적인 무작위 값을 더하는 것이다: $a = \mu(s) + \epsilon \mathcal{N}$ (여기서 $\mathcal{N}$은 정규분포에서 뽑은 난수). 실제로 [[D4PG Distributed Distributional DDPG]]에서는 이 단순한 방법을 쓴다.

하지만 로봇 관절처럼 **관성이 있는 물리 시스템**에서는, 매 순간 완전히 독립적으로 방향이 뒤바뀌는 노이즈는 부자연스럽다. 마치 걷다가 매 걸음마다 무작위로 왼쪽·오른쪽을 홱홱 바꾸는 것과 같다 — 탐험 효율이 떨어진다. 그래서 **"이전 흔들림에서 이어지는" 좀 더 부드러운 노이즈**가 필요할 때가 있다.

## 2. OU 프로세스란

OU 프로세스는 원래 **마찰이 있는 유체 속 브라운 입자의 속도**를 모델링하려고 물리학·금융공학에서 만든 확률 과정이다. 연속시간에서는 다음 확률미분방정식으로 정의된다.

$$\partial x_t = \theta(\mu - x_t)\partial t + \sigma \partial W_t$$

말로 풀면:
- $\mu$: 노이즈가 **평균적으로 돌아가려는 목표값** (보통 0)
- $\theta$: 그 목표값으로 **얼마나 강하게 끌어당기는지**(되돌림 강도)
- $\sigma$: 매 순간 더해지는 **무작위성(변동성)의 크기**
- $W_t$: 위너 과정(브라운 운동) — 표준적인 무작위 흔들림원

즉 "지금 값이 목표 $\mu$에서 멀어져 있으면 $\theta$의 세기로 다시 끌어당기되, 동시에 $\sigma$만큼 계속 무작위로 흔든다"는 뜻이다.

## 3. 컴퓨터로 계산하는 이산 시간 버전

컴퓨터 시뮬레이션은 시간을 잘게 쪼갠 **이산 스텝**으로 진행하므로, 위 식을 스텝 단위로 다시 쓰면:

$$x_{t+1} = x_t + \theta(\mu - x_t) + \sigma \mathcal{N}$$

코드로 보면 이렇게 구현된다(책의 `AgentDDPG.__call__` 내부):

```python
a_state += self.ou_teta * (self.ou_mu - a_state)   # 목표값으로 끌어당기는 힘
a_state += self.ou_sigma * np.random.normal(size=action.shape)  # 무작위 흔들림 추가
action += self.ou_epsilon * a_state                # 최종 행동 = 원래 행동 + (스케일된) 노이즈
```

한 줄씩 설명:
- 첫 줄: 지금 노이즈 값(`a_state`)이 목표(`ou_mu`, 보통 0)에서 얼마나 떨어져 있는지를 보고, `ou_teta` 비율만큼 그 차이를 되돌린다.
- 둘째 줄: 거기에 정규분포 난수를 `ou_sigma` 크기로 더한다.
- 셋째 줄: 이렇게 만든 노이즈를 `ou_epsilon` 배율로 줄이거나 키워서, 원래 결정론적 행동값에 더한다.

> [!important] 왜 "상태를 기억"해야 하는가
> 이 계산에서 다음 스텝의 노이즈 `a_state`는 **이전 스텝의 노이즈 값**에 의존한다. 즉 노이즈 자체가 "관성"을 가지고 이어진다. 그래서 PTAN의 에이전트 클래스가 매번 새로 계산하지 않고, `agent_states`라는 자리를 통해 **이전 노이즈 값을 다음 호출로 넘겨줘야** 한다. 이런 식으로 에피소드 동안 상태를 기억하는 에이전트를 **스테이트풀(stateful) 에이전트**라 부르며, [[POMDP 부분관측 마르코프결정과정]]처럼 과거 정보가 필요한 다른 상황에서도 같은 메커니즘이 쓰인다.

## 4. 정리 — 두 가지 탐험 방식 비교

| | 단순 가우시안 노이즈 | OU 노이즈 |
|---|---|---|
| 방식 | 매 스텝 독립적인 난수를 더함 | 이전 노이즈 값에서 이어지는 난수 |
| 특징 | 계산 간단, 상태 기억 불필요 | 부드럽게 이어지는 흔들림, 상태 기억 필요 |
| 사용 예 | [[D4PG Distributed Distributional DDPG]] | [[결정론적 정책 경사 DDPG]] |
| 논문 결과 | D4PG 저자들은 "둘 다 결과가 비슷했다"고 보고 | — |

## 세 줄 정리
- 결정론적 정책은 탐험이 없어서 행동에 노이즈를 인위적으로 더해야 한다.
- OU 노이즈는 "이전 값으로 끌어당기는 힘 + 무작위성"으로, 매끄럽게 이어지는 흔들림을 만든다.
- 이전 노이즈 값을 기억해야 하므로 에이전트가 상태(state)를 유지하는 스테이트풀 방식이 필요하다.
