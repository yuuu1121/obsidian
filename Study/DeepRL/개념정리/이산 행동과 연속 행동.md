# 이산 행동 vs 연속 행동

> [!abstract] 한 줄 요약
> **이산 행동** = 버튼처럼 **정해진 몇 개 중 하나**를 고르는 것 (좌/우/점프). **연속 행동** = 다이얼처럼 **실수값**을 정하는 것 (핸들을 32.5도). 이 구분에 따라 쓰는 RL 알고리즘이 달라진다.

## 1. 이산 행동 (Discrete Actions)

**서로 배타적인, 유한 개의 선택지** 중 하나를 고른다.

- 예: 상/하/좌/우 이동, 게임 버튼(점프·공격), 체스의 말 이동
- 특징: 선택지를 **셀 수 있다** (1번, 2번, 3번…)

```
가능한 행동 = { 왼쪽, 오른쪽, 점프 }   ← 이 셋 중 딱 하나
```

## 2. 연속 행동 (Continuous Actions)

**값(수치)이 붙는 행동.** 무한히 많은 가능성이 있다.

- 예: 자동차 핸들 각도(−45.0도 ~ +45.0도 중 아무 실수), 로봇 팔 관절 토크, 가속 페달 세기
- 특징: "핸들 돌리기"만으론 부족하고 **정확히 몇 도인지**까지 정해야 한다.

```
가능한 행동 = 핸들 각도 ∈ [−45.0, +45.0]   ← 이 범위의 무한한 실수 중 하나
              32.5도? 32.51도? 32.512도? ...
```

## 3. 왜 이 구분이 중요한가?

**쓰는 알고리즘이 완전히 달라지기 때문이다.**

| | 이산 행동 | 연속 행동 |
|---|---|---|
| 방식 | 각 행동의 **가치(Q값)를 비교**해 최고를 고름 | 행동 **값 자체를 출력** |
| 대표 알고리즘 | **DQN** (6장) | **DDPG, A2C, PPO** (12·15·16장) |
| "최선의 행동 찾기" | 후보를 다 훑어 max 고르기 (쉬움) | 무한 후보라 max를 못 훑음 (어려움) |

> [!important] 연속 행동이 더 까다로운 이유
> 이산 행동은 "3개 중 최고"를 고르면 되지만, 연속 행동은 **후보가 무한**이라 "다 해보고 최고 고르기"가 불가능하다. 그래서 **정책이 행동 값을 직접 출력**하는 방식(정책 기반 방법, Part III)이 필요하다. 이 책의 15장이 연속 행동 공간을 통째로 다룬다.

## 4. 섞여 있는 경우도 있다
- **NN 구조 탐색**: 층 개수(이산) + 드롭아웃 확률(연속)이 함께.
- 실제 로봇: 기어 선택(이산) + 조향 각도(연속).

## 세 줄 정리
- 이산 = **버튼**(정해진 몇 개 중 하나), 연속 = **다이얼**(실수값)
- 연속은 후보가 무한이라 **더 어렵다**
- 이산 → DQN 계열, 연속 → 정책 기반(PPO 등)
