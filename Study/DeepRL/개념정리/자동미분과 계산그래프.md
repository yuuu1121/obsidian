# 자동미분과 계산그래프 (Autograd)

> [!abstract] 한 줄 요약
> **자동미분(autograd)**은 여러분이 수행한 계산 과정을 라이브러리가 몰래 다 기록해뒀다가, "이 결과를 각 변수로 미분하면?"이라고 물으면 그 기록을 거꾸로 훑어가며 **기울기(그래디언트)를 자동으로 계산**해주는 기능이다. [[신경망 경사하강 역전파 기초]]에서 배운 "역전파"를 실제로 구현한 것이 바로 이것이다.

> [!note] 옛날엔 손으로 미분했다
> 자동미분이 없던 시절엔, 신경망의 모든 함수에 대해 도함수를 손으로 계산하고 연쇄법칙을 직접 적용해 코드로 옮겨야 했다. 아주 단순한 신경망도 지독하게 번거로운 일이었다. 지금은 계산만 해두면 미분은 라이브러리가 대신 해준다.

## 1. 계산 그래프란?

우리가 텐서로 어떤 계산(더하기, 곱하기 등)을 하면, PyTorch는 그 계산의 **순서와 관계를 그래프(graph) 형태로 기록**해둔다. 그래프의 노드는 텐서, 화살표는 "이 텐서가 저 텐서로부터 계산되어 나왔다"는 관계다.

```
v1 ──┐
     ├─▶ (+) ─▶ v_sum ─▶ (×2) ─▶ (Σ) ─▶ v_res
v2 ──┘
```

> [!tip] 비유 — 요리 레시피 녹화
> 계산 그래프는 "어떤 재료를 어떤 순서로 섞었는지" 녹화한 요리 영상과 같다. 완성된 요리(결과)를 보고 "소금을 반만 넣었으면 맛이 어떻게 바뀌었을까?"를 알고 싶을 때, 이 영상을 거꾸로 돌려보며 각 재료가 최종 맛에 얼마나 영향을 줬는지 계산할 수 있다. 이게 바로 `backward()`가 하는 일이다.

## 2. leaf 텐서와 `requires_grad`

- **leaf 텐서**: 사용자가 직접 만든, 계산 그래프에서 "뿌리"에 해당하는 텐서. (`is_leaf == True`)
- **`requires_grad`**: 이 텐서에 대한 그래디언트를 계산할지 여부. 기본은 `False`이며, 그래디언트가 필요하면 명시적으로 켜야 한다.
- 이 속성은 "전염성"이 있어서, 계산에 관여한 텐서 중 하나라도 `True`면 그 뒤에 나오는 결과 텐서들도 전부 `True`가 된다.

## 3. `backward()`와 `.grad`

```python
v1 = torch.tensor([1.0, 1.0], requires_grad=True)
v2 = torch.tensor([2.0, 2.0])
v_sum = v1 + v2
v_res = (v_sum * 2).sum()
v_res.backward()      # 그래프를 거꾸로 훑으며 그래디언트 계산
print(v1.grad)          # tensor([2., 2.])
```

`v_res.backward()`를 호출하면, `v_res`를 계산하는 데 관여한 모든 leaf 텐서(`requires_grad=True`인 것들)의 그래디언트가 계산되어 각 텐서의 `.grad` 속성에 쌓인다. `v1.grad`가 `[2, 2]`라는 것은 "v1의 원소를 1만큼 늘리면 v_res가 2만큼 늘어난다"는 뜻이다.

메모리 절약을 위해 그래디언트는 **leaf 노드에만** 저장되며, 중간 노드는 `retain_grad()`를 호출해야 저장된다.

## 세 줄 정리
- 자동미분 = 계산 과정을 기록해뒀다가 거꾸로 훑으며 기울기를 자동 계산하는 기능
- `requires_grad=True`인 leaf 텐서만 `.grad`에 그래디언트가 쌓인다
- `backward()` 한 번 호출로 신경망의 모든 파라미터에 대한 그래디언트를 한꺼번에 얻는다
