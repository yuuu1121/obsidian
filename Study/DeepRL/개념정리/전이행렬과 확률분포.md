# 전이행렬과 확률분포

> [!abstract] 한 줄 요약
> **전이행렬**은 "각 상태에서 다른 상태로 갈 확률"을 표(격자)로 정리한 것이다. 각 행은 하나의 **확률분포**이며, 그래서 **각 행의 합은 항상 1**이다.

## 1. 먼저 — 확률분포란?

**확률분포**는 "일어날 수 있는 모든 경우와 그 각각의 확률"을 모아놓은 것이다. 규칙은 딱 하나: **모든 확률을 더하면 1(=100%).**

예) 오늘이 맑을 때 내일 날씨의 확률분포:
- 맑음: 0.8, 비: 0.2 → 합 = 1.0 ✅

## 2. 전이행렬 (Transition Matrix)

여러 상태가 있을 때, **"어느 상태에서 → 어느 상태로" 갈 확률**을 전부 표로 만든 것이 전이행렬이다. N개 상태면 **N×N 정사각 표**가 된다.

### 날씨 예시
|  | → 맑음 | → 비 |
|---|---|---|
| **맑음에서** | 0.8 | 0.2 |
| **비에서** | 0.1 | 0.9 |

**읽는 법**: "i행 j열" = 상태 i에서 상태 j로 갈 확률.
- 1행: 맑은 날 → (맑음 0.8, 비 0.2). 합 = 1 ✅
- 2행: 비 오는 날 → (맑음 0.1, 비 0.9). 합 = 1 ✅

> [!important] 핵심 규칙 — 각 '행'의 합은 반드시 1
> 한 상태에서 출발하면 **어딘가로는 반드시 가야 하므로**, 그 상태(행)에서 나가는 확률을 다 더하면 100%가 된다. 열의 합은 1이 아닐 수 있으니 주의!

## 3. 그래프로 표현하기

전이행렬은 **화살표 그림**으로도 그린다.
- **원(노드)** = 상태
- **화살표(엣지)** = 전이, 옆에 확률을 적는다
- 확률이 0이면 **화살표를 안 그린다**(갈 수 없는 길)

```
        0.2
  ┌────────────▶
[맑음]          [비]
  ◀────────────┘
        0.1
  (맑음→맑음 0.8, 비→비 0.9는 자기 자신으로 도는 화살표)
```

## 4. MDP에서는 3차원(직육면체)이 된다

강화학습의 MDP에서는 **행동**이 추가된다. "상태 i에서 **행동 a를 했을 때** 상태 j로 갈 확률"이 되므로, 표가 한 차원 늘어 **(상태 × 상태 × 행동)의 3D 직육면체**가 된다.

```
2D (MP·MRP):  [출발상태] × [도착상태]           ← 평면 표
3D (MDP):     [출발상태] × [도착상태] × [행동]   ← 직육면체
```

예) 불완전한 모터를 가진 로봇: "전진" 행동을 해도 **90%만 앞칸, 10%는 제자리**. 이런 확률적 결과를 담으려면 3D 전이행렬이 필요하다.

## 5. 실전에서는 행렬을 모른다 → 추정한다

현실에서는 전이행렬을 미리 아는 경우가 드물다. 대신 **관측한 에피소드**(상태 시퀀스)를 많이 모아서:
1. 각 상태에서 어디로 몇 번 갔는지 **센다**.
2. 그 횟수를 **정규화(합이 1이 되도록 나눔)** 한다.
3. → 전이 확률의 **추정값**을 얻는다. 데이터가 많을수록 참값에 가까워진다.

## 세 줄 정리
- 전이행렬 = 상태 간 이동 확률의 **N×N 표**
- **각 행의 합 = 1** (반드시 어딘가로는 가니까)
- MDP에선 행동이 붙어 **3D 직육면체**가 된다
