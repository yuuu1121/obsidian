# 머신러닝의 세 갈래

> [!abstract] 한 줄 요약
> 머신러닝은 **정답표가 있느냐 / 없느냐 / 보상만 있느냐** 에 따라 세 갈래로 나뉜다.

## 비유로 먼저 — 세 가지 공부법

세 학생이 수학을 공부한다고 상상하자.

| 학생 | 공부 방식 | 대응되는 학습 |
|---|---|---|
| **A** | 문제집에 **정답지**가 있어서, 풀고 바로 맞춰본다 | **지도학습** |
| **B** | 정답지 없이 **문제들을 스스로 분류**하며 패턴을 찾는다 | **비지도학습** |
| **C** | 정답은 없지만, 시험 **점수(보상)** 를 보고 공부법을 조금씩 고친다 | **강화학습** |

## 1. 지도학습 (Supervised Learning)

- **핵심**: "입력 → 정답" 쌍이 잔뜩 있다.
- **목표**: 처음 보는 입력에도 올바른 출력을 내는 함수를 배운다.
- **'지도(supervised)'** = 정답(ground truth)이라는 **선생님**이 있다.
- **예**: 스팸 분류, 사진 속 개/고양이 구분, 내일 날씨 예측(회귀), 리뷰 감성 분석.

```
입력: 🐕 사진  →  모델  →  출력: "개"   (정답: "개" ✅ 맞음!)
입력: 🐈 사진  →  모델  →  출력: "개"   (정답: "고양이" ❌ 틀림 → 수정)
```

## 2. 비지도학습 (Unsupervised Learning)

- **핵심**: 정답(라벨)이 **전혀 없다.**
- **목표**: 데이터 속 **숨은 구조**를 발견.
- **대표 기법**:
  - **군집화(clustering)**: 비슷한 것끼리 자동으로 묶기.
  - **GAN(생성적 적대 신경망)**: 두 신경망이 경쟁. 하나는 **가짜 생성**(위조범), 하나는 **진짜/가짜 판별**(감별사). 경쟁하며 둘 다 정교해진다.

```
데이터: ●●● ▲▲▲ ■■■  →  (라벨 없음)  →  모델이 스스로 3개 그룹 발견
```

## 3. 강화학습 (Reinforcement Learning)

- **위치**: 지도학습과 비지도학습의 **중간**.
- **핵심**: 정답표는 없지만 **보상(reward)** 신호가 있다.
- **특별한 점**: **시간**과 **행동의 결과**를 학습에 자연스럽게 포함한다.
- **도구는 지도학습에서 빌려온다**: 신경망, 경사하강, 역전파. 하지만 쓰는 방식이 다르다.

```
에이전트 행동 → 환경 → 보상(+3) → "이 행동 좋았어, 강화!"
에이전트 행동 → 환경 → 보상(−5) → "이 행동 나빴어, 약화!"
```

> [!note] 왜 강화학습이 더 어려운가?
> 지도학습은 "정답"이 매 순간 명확하다. 강화학습은 **보상이 늦게 오고**(지연 보상), **내 행동이 다음 데이터를 바꾸며**(non-IID), **탐험과 활용 사이에서 갈등**한다. 그래서 더 어렵지만, 그만큼 **현실의 의사결정**에 가깝다.

## 세 줄 정리
- 지도학습 = **정답지 보고** 배우기
- 비지도학습 = **정답 없이 구조** 찾기
- 강화학습 = **점수(보상) 보고** 행동 고치기
