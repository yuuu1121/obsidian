# 텐서 gather() 연산

> [!abstract] 한 줄 요약
> `gather()`는 큰 표(텐서)에서 **각 행마다 서로 다른 열 번호**를 지정해 값을 콕 집어 꺼내오는 연산이다. DQN에서 "이 배치의 각 샘플이 실제로 선택했던 행동의 Q값만" 뽑아낼 때 쓴다.

## 1. 왜 필요한가

신경망 `net(states)`은 한 번의 순전파로 **배치의 모든 샘플에 대해, 가능한 모든 행동의 Q값**을 한꺼번에 출력한다. 예를 들어 배치 크기 6, 행동 개수 4라면 출력은 (6, 4) 모양의 표다.

```
        action0  action1  action2  action3
sample0   ...      ...      ...      ...
sample1   ...      ...      ...      ...
...
```

그런데 손실을 계산하려면, 각 샘플에서 **그때 실제로 선택했던 행동**의 Q값만 필요하다. 샘플0은 행동0을 선택했을 수도, 샘플1은 행동3을 선택했을 수도 있다 — 즉 **샘플마다 뽑아야 할 열이 다르다.** 이런 "행마다 다른 위치의 값 꺼내기"를 파이썬 반복문 없이 한 번에 처리해 주는 것이 `gather()`다.

> [!tip] 비유 — 학급별로 다른 번호의 학생 출석 확인
> 6개 반이 있고, 각 반의 "오늘 발표자 번호"가 다르다고 하자(1반은 3번, 2반은 1번, 3반은 2번…). `gather()`는 "각 반의 출석부에서, 그 반에 지정된 번호의 학생만 콕 집어 명단을 뽑아오는" 작업과 같다. 반마다 몇 번을 뽑을지 다 다른데, 이걸 한 번의 명령으로 처리하는 것이다.

## 2. 실제 코드와 그림으로 이해하기

```python
state_action_values = net(states_t).gather(
    1, actions_t.unsqueeze(-1)
).squeeze(-1)
```

- `net(states_t)`: (batch_size, n_actions) 모양의 Q값 표.
- `1`: gather를 수행할 차원. 여기서는 "행동(열) 방향"을 의미(0번 차원은 배치=행, 1번 차원은 행동=열).
- `actions_t.unsqueeze(-1)`: 실제 선택된 행동 번호들(모양 (batch_size,))을 (batch_size, 1) 모양으로 바꾼다. `gather`가 요구하는 인덱스 텐서는 **데이터와 같은 차원 수**를 가져야 하기 때문이다.
- `.squeeze(-1)`: 결과로 나온 (batch_size, 1) 모양을 다시 (batch_size,)로 눌러 펴서, 원래 하나의 값들이 나란히 있는 벡터로 되돌린다.

## 3. `unsqueeze`와 `squeeze`는 왜 필요한가

- **`unsqueeze(-1)`**: 텐서에 크기 1짜리 차원을 추가한다. (batch_size,) → (batch_size, 1). 마치 "가로로 나열된 숫자들"을 "세로로 한 줄씩 선 숫자들"로 살짝 모양만 바꾸는 것과 같다. `gather`는 인덱스 텐서가 원본 데이터와 **같은 차원 개수**여야 동작하므로 이 단계가 꼭 필요하다.
- **`squeeze(-1)`**: 반대로 크기 1짜리 차원을 없앤다. gather 결과가 (batch_size, 1) 모양으로 나오는데, 이후 계산(보상과 더하기 등)에서는 (batch_size,) 모양이 더 다루기 편하므로 다시 눌러준다.

## 세 줄 정리
- `gather()`는 배치의 각 행(샘플)마다 지정된 열(행동)의 값만 뽑아내는 텐서 연산이다.
- 인덱스 텐서는 `unsqueeze`로 차원을 맞춰 넣고, 결과는 `squeeze`로 다시 펴준다.
- DQN에서는 "실제로 선택했던 행동의 Q값"만 손실 계산에 쓰기 위해 사용한다.
