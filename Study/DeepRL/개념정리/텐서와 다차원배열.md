# 텐서와 다차원배열 (Tensor)

> [!abstract] 한 줄 요약
> **텐서**는 숫자들을 여러 차원으로 쌓아놓은 "숫자 상자"다. 숫자 하나(점) → 줄(벡터) → 표(행렬) → 그 이상(텐서)으로, 차원이 늘어날수록 더 복잡한 데이터를 담을 수 있다.

> [!note] 왜 알아야 하나?
> PyTorch뿐 아니라 거의 모든 딥러닝 도구의 **가장 기본 단위**가 텐서다. 신경망에 들어가는 데이터도, 신경망의 가중치도, 계산 결과도 전부 텐서다.

## 1. 차원이 늘어나는 과정

```
숫자 하나(3)         → 0차원 (스칼라)
[3, 7, 4, 9, 1]      → 1차원 (벡터)
[[16,3,2,13], ...]   → 2차원 (행렬)
[[[0,1,7],...],...]  → 3차원 (3D 텐서)
...                  → n차원 (n텐서)
```

> [!tip] 비유 — 상자 쌓기
> - 스칼라 = 구슬 하나
> - 벡터 = 구슬을 한 줄로 꿴 목걸이
> - 행렬 = 구슬을 바둑판처럼 깐 평면
> - 3D 텐서 = 그 평면을 여러 장 겹쳐 쌓은 정육면체
> - 그 이상은 상상하기 어렵지만, 컴퓨터는 그냥 "숫자들의 규칙적인 배열"로 다룬다.

## 2. 텐서의 타입(dtype)

텐서는 **모양(shape)** 뿐 아니라 **원소의 타입**으로도 구분된다. float(실수), int(정수), bool 등 다양한 타입이 있고, 딥러닝에서는 보통 **32비트 float**(`torch.float32`)를 표준으로 쓴다. 64비트(double)는 정밀하지만 메모리·속도 손해가 있어 과한 경우가 많다.

## 3. NumPy와의 관계

파이썬에서 과학 계산에 흔히 쓰는 **NumPy**의 배열(`ndarray`)이 사실상 텐서와 같은 것이다. PyTorch는 NumPy와 비슷하게 설계되어 있어서, NumPy에 익숙하면 PyTorch 텐서 연산도 낯설지 않다.

## 4. 예시 코드

```python
import torch
a = torch.FloatTensor(3, 2)   # 3행 2열 크기의 텐서(0으로 채워짐)
b = torch.zeros(3, 4)          # 0으로 채워진 3행 4열 텐서
c = torch.tensor([1, 2, 3])    # 파이썬 리스트로부터 텐서 생성
```

## 세 줄 정리
- 텐서 = 숫자를 여러 차원으로 쌓은 배열 (점 → 벡터 → 행렬 → 그 이상)
- 딥러닝의 텐서는 수학의 "텐서"와 이름만 같고 뜻은 다르다(그냥 다차원 배열)
- NumPy 배열과 사실상 같은 개념이라, NumPy를 알면 이해가 빠르다
