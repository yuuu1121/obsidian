# 할인율 감마(γ)와 등비급수

> [!abstract] 한 줄 요약
> **할인율 γ(감마)** 는 "미래의 보상을 지금 얼마나 값지게 볼지"를 정하는 0~1 사이 숫자다. γ가 1에 가까울수록 먼 미래까지 챙기고, 0에 가까울수록 눈앞만 본다.

## 1. 왜 미래 보상을 '할인'할까?

### 이유 A — 현실 감각 (돈의 시간가치)
**"오늘 받는 만원 vs 10년 뒤 받는 만원"**, 어느 게 더 좋은가? 당연히 오늘 것이다. 미래는 불확실하고, 지금 받으면 그동안 활용할 수 있으니까. 미래 보상은 **가치를 조금 깎아서(할인해서)** 계산하는 게 합리적이다.

### 이유 B — 수학적 필요 (무한대 방지)
과정이 끝없이 이어지면, 보상을 그냥 다 더하면 **무한대**가 되어 버린다. 무한대끼리는 비교가 안 된다. γ<1로 먼 미래를 점점 깎으면 합계가 **유한한 값**으로 수렴한다.

## 2. 리턴(Return) 공식

시각 $t$ 부터의 **리턴** $G_t$ 는 미래 보상들의 **할인 합계**다:

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

- **바로 다음 보상** $R_{t+1}$ → 그대로 ($\gamma^0 = 1$)
- **한 스텝 뒤** $R_{t+2}$ → $\gamma$ 배 (예: 0.9배)
- **두 스텝 뒤** $R_{t+3}$ → $\gamma^2$ 배 (예: 0.81배)
- … 멀수록 더 많이 깎인다.

```
보상:    R₁     R₂      R₃       R₄        ...
가중치:  1  →  0.9  →  0.81  →  0.729  →  ...   (γ=0.9일 때)
                         ↑ 멀수록 작아짐(할인)
```

## 3. γ 값에 따른 성격

| γ 값 | 성격 | 의미 |
|---|---|---|
| **γ = 0** | 극단적 근시안 | 바로 다음 보상만 본다. 미래 완전 무시. |
| **γ = 0.9** | 균형 (흔히 사용) | 약 10스텝 앞까지 의미 있게 반영 |
| **γ = 0.99** | 원시안 (흔히 사용) | 약 100스텝 앞까지 반영 |
| **γ = 1** | 완벽한 원시안 | 모든 미래를 동등하게. **무한 발산 위험!** |

> [!tip] γ를 "몇 스텝 앞을 보는가"로 이해하기
> 대략 $\frac{1}{1-\gamma}$ 스텝 정도를 내다본다고 생각하면 편하다.
> - γ=0.9 → 약 10스텝
> - γ=0.99 → 약 100스텝

## 4. 등비급수 (Geometric Series) — 왜 유한값으로 수렴하나

보상이 매번 똑같이 1이라고 하면, 리턴은:

$$G = 1 + \gamma + \gamma^2 + \gamma^3 + \cdots$$

이것이 바로 고등학교에서 배우는 **무한 등비급수**다. 공비가 $\gamma$ 이고 $|\gamma| < 1$ 이면 합이 수렴한다:

$$1 + \gamma + \gamma^2 + \cdots = \frac{1}{1-\gamma}$$

- γ=0.9 → $\frac{1}{1-0.9} = 10$
- γ=0.99 → $\frac{1}{1-0.99} = 100$

**핵심**: γ<1이면 무한히 더해도 유한값! γ=1이면 $1+1+1+\cdots = \infty$ (발산). 이것이 책에서 "γ=1이면 모든 상태의 가치가 무한대가 된다"고 한 이유다.

> [!note] 예외 — γ=1을 써도 되는 경우
> **유한 지평(finite horizon)** 환경, 즉 반드시 끝나는 게임이면 γ=1도 안전하다.
> - 틱택토: 최대 9수면 끝
> - 한 판이 확실히 종료되는 에피소드형 문제
> 끝이 있으면 무한 합이 아니므로 발산하지 않는다.

## 세 줄 정리
- γ = 미래 보상을 **얼마나 값지게 볼지** (0~1)
- γ<1이면 **등비급수가 수렴** → 무한 발산 방지
- 실전에선 보통 **0.9 ~ 0.99** 를 쓴다
