# 활성화함수 (Activation Function)

> [!abstract] 한 줄 요약
> **활성화함수**는 신경망의 각 층 사이에 끼워 넣는 "구부리는 함수"다. 이게 없으면 신경망을 아무리 여러 층 쌓아도 결국 하나의 직선(선형 함수)과 다를 게 없어진다.

> [!note] 왜 필요한가?
> `nn.Linear` 같은 층은 입력에 가중치를 곱하고 더하는 **선형(linear) 변환**만 한다. 선형 변환을 아무리 여러 번 이어붙여도 결과는 여전히 선형이다(직선 위에 직선을 그어봤자 직선이듯). 그런데 세상의 대부분 문제(이미지 인식, 게임 전략 등)는 직선 하나로 설명할 수 없는 **곡선·복잡한 패턴**을 갖고 있다. 활성화 함수가 층 사이에서 "살짝 구부려" 줘야, 신경망 전체가 복잡한 곡선도 표현할 수 있게 된다.

> [!tip] 비유 — 꺾이는 관절
> 선형 층만 쌓은 신경망은 관절 없이 뻣뻣한 막대기와 같다. 아무리 이어붙여도 결국 하나의 곧은 막대다. 활성화 함수는 그 사이사이에 **관절**을 넣어주는 것과 같다. 관절이 있어야 막대가 구부러져 복잡한 모양(곡선)을 만들 수 있다.

## 대표적인 활성화 함수

| 이름 | PyTorch 클래스 | 하는 일 |
|---|---|---|
| ReLU | `nn.ReLU()` | 음수는 0으로, 양수는 그대로 통과시킨다. 가장 널리 쓰이는 기본 선택. |
| Sigmoid | `nn.Sigmoid()` | 어떤 값이든 0~1 사이로 눌러 짜낸다. "확률"처럼 해석하기 좋음(예: GAN 판별자의 출력). |
| Softmax | `nn.Softmax(dim=1)` | 여러 값을 "합이 1인 확률 분포"처럼 바꾼다. 여러 클래스 중 하나를 고르는 분류 문제의 출력층에 흔히 쓰인다. |

## 예시

```python
s = nn.Sequential(
    nn.Linear(2, 5),
    nn.ReLU(),          # 활성화 함수 — 층 사이에 비선형성을 넣는다
    nn.Linear(5, 20),
    nn.ReLU(),
    nn.Linear(20, 10),
    nn.Softmax(dim=1)   # 출력을 확률 분포처럼 만든다
)
```

`Softmax(dim=1)`의 `dim=1`은 "어느 차원을 기준으로 정규화할지"를 뜻한다. 신경망에 데이터를 넣을 땐 보통 여러 개를 한 번에 묶어서(배치, [[에폭 배치 미니배치]] 참고) 넣기 때문에, 차원 0은 "배치 안에서 몇 번째 샘플인가"이고 차원 1이 실제 "클래스별 점수" 차원이다.

## 세 줄 정리
- 활성화 함수 = 층과 층 사이에서 값을 "구부려" 비선형성을 만드는 함수
- 이게 없으면 신경망이 아무리 깊어도 결국 하나의 직선과 같아진다
- ReLU(중간층에 흔함), Sigmoid(확률 하나), Softmax(확률 분포)가 대표적
