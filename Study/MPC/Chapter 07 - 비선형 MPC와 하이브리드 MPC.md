# Chapter 7 · 비선형 MPC와 하이브리드 MPC

> [!abstract] 이 챕터를 한 문장으로
> 지금까지의 MPC는 "선형 모델 + 이차 비용함수 → 볼록한 QP"라는 아주 편안한 조합 위에 서 있었는데, 실제 공정이 심하게 비선형이거나 **켜짐/꺼짐 같은 이산 변수까지 섞여 있으면** 이 조합이 무너진다. 이 챕터는 그런 상황에서 쓸 모델(볼테라·하머슈타인·신경망·쿠프만), 그때 풀어야 하는 **비볼록 비선형계획(NLP)** 과 **혼합정수계획(MIP)** 의 실제 해법, 그리고 최적해를 못 찾는 상황에서도 안정성을 어떻게 확보하는지를 훑는다.

## 들어가며 — 왜 이 챕터가 필요한가?

1장부터 6장까지 우리가 쓴 재료는 늘 같았다. **선형 모델**로 미래를 예측하고, **이차 비용함수**를 세우고, 제약을 **선형 부등식**으로 적으면, 결과는 항상 [[볼록 최적화와 이차계획법 QP]] 하나로 떨어졌다. 볼록하다는 것은 "골짜기가 하나뿐"이라는 뜻이고, 골짜기가 하나면 아무 데서나 굴러 내려가도 반드시 바닥, 즉 전역 최적해에 도착한다. 게다가 이 QP를 **샘플링 주기보다 짧은 시간 안에** 확실히 푸는 상용 솔버가 널려 있다. 산업 현장에서 MPC가 그렇게 널리 쓰인 이유의 절반은 이 계산적 안정감 덕분이다.

그런데 책은 여기서 솔직하게 인정한다. **실제 산업 공정은 일반적으로 비선형이다.** 그럼에도 대부분의 MPC 응용이 선형 모델로 잘 굴러가는 이유는, 대개의 목표가 "공정을 한 정상상태(stationary state) 근처에 붙들어 두는 것"이지 운전점을 자주 갈아타는 것이 아니기 때문이다. 한 점 근처에만 머문다면 그 점 주변에서 접선을 그은 정밀한 선형 모델 하나로 충분하다.

문제는 그 가정이 깨지는 경우들이다. 책은 세 가지를 든다.

1. **비선형성이 너무 심한 공정.** 정상상태 근처에서조차 비선형성이 강하고, 그 비선형성이 폐루프 안정성에 결정적이어서 선형 모델로는 안 되는 경우. 이 챕터 마지막의 pH 중화 공정이 딱 그렇다.
2. **정상상태에 아예 도달하지 않는 공정.** 시동(startup)·정지(shutdown)처럼 연속적인 천이가 계속되거나, 배치(batch) 공정처럼 **운전 전체가 과도 상태**로 이루어지는 경우. 붙들어 둘 "한 점"이 애초에 없다.
3. **하이브리드 공정.** 연속 변수와 이산 변수가 함께 있어서, 시간에 따라 흐르는 동역학(time-driven)과 사건에 따라 튀는 동역학(event-driven)을 예측제어기가 동시에 다뤄야 하는 경우. 온-오프 펌프, 밸브, 자동화 논리가 섞인 공정이 여기 해당한다.

> [!note] 비유 — 자동변속기 자동차와 수동변속기 자동차
> 선형 MPC는 "고속도로에서 6단 정속주행 중인 차"를 다루는 것과 같다. 가속페달과 속도의 관계가 거의 직선이라, 페달을 2배 밟으면 가속도도 대략 2배가 된다. 그런데 시내 주행처럼 **기어를 계속 바꿔가며(=이산 변수) 저속에서 급가속(=강한 비선형)** 하는 상황이라면 그 직선 관계가 완전히 무너진다. 게다가 "기어를 3단으로 넣을까 4단으로 넣을까"는 0.5단 같은 중간값이 없는 **정수 결정**이다. 이 챕터는 바로 그런 시내 주행용 MPC를 다룬다.

아이디어 자체를 비선형으로 확장하는 것은 **개념적으로는 곧바로(conceptually straightforward)** 된다. 예측하고, 비용을 최소화하고, 첫 수만 적용하고, 한 칸 밀고 다시 — [[이동 구간 원리 Receding Horizon]] 는 그대로다. 문제는 그 과정에서 생기는 세 가지 실무적 난관이다.

- **비선형 모델을 실험 데이터로부터 얻는 것 자체가 미해결 문제다.** 신경망이나 볼테라 급수 같은 대안이 있지만 완전한 해결책은 아니고, 물질·에너지 수지로부터 제1원리 모델을 세우는 것도 늘 가능하지는 않다.
- **최적화 문제가 비볼록(nonconvex)이 된다.** QP보다 훨씬 풀기 어렵고 오래 걸리며, **국소 최적해가 여러 개** 생긴다. 이것은 제어 품질만 떨어뜨리는 게 아니라 **안정성 문제로까지 번진다**.
- **안정성과 강인성의 이론적 분석이 훨씬 복잡해진다.**

이 챕터는 이 세 난관을 차례대로 다룬다. 7.1은 첫 번째(모델링과 식별), 7.2와 7.3은 두 번째(최적화 문제 풀이), 7.5는 세 번째(안정성)다. 그리고 7.4는 이산 변수가 섞인 하이브리드 시스템이라는 특별한 영역을 따로 떼어 다룬다.

> [!important] 이 챕터의 성격
> 책 스스로 이 챕터를 **"파노라마식 개관(panoramic overview)"** 이라고 부른다. 앞 챕터들처럼 하나의 알고리즘을 끝까지 유도하는 게 아니라, 비선형 MPC라는 넓은 영역의 지도를 그리고 각 방향에 어떤 방법이 있는지 이름과 핵심 아이디어를 붙여주는 방식이다. 그래서 "이걸 다 외워야 하나" 하고 겁먹을 필요는 없다. **어떤 선택지가 있고 각각 무엇을 포기하고 무엇을 얻는지**의 지도를 갖는 것이 이 챕터의 목표다.

## 7.1 비선형 시스템의 모델링과 식별 (Modelling and Identification of Nonlinear Systems)

### 선형 모델을 최대한 지키려는 시도들

표준 MPC가 성공한 이유 중 하나는 **모델을 얻기가 쉬웠다**는 점이다. 스텝 응답, 임펄스 응답([[임펄스 응답과 컨볼루션]]), 저차 전달함수 — 이 정도는 공정에 계단 입력 하나 넣어보면 나온다. 그런데 **일반적인 비선형 공정을 표현하는 데 "이거다" 싶은 표준 모델 형태는 존재하지 않는다.** 입출력 데이터로부터도, 물질·에너지 보존 법칙으로부터도 비선형 모델은 훨씬 만들기 어렵다.

그래서 연구자들이 먼저 시도한 방향은 "**어떻게든 선형의 성질을 붙들고 늘어지는**" 것이었다.

- **스케줄링 선형화 MPC (scheduled linearized MPC)**: 여러 운전점 각각에서 모델을 선형화해 두고, 공정이 한 운전점에서 다른 운전점으로 옮겨갈 때 모델도 **갈아 끼운다**.
- **확장 선형 MPC (extended linear MPC)**: 기본 선형 모델을 쓰되, 예측을 보정하고 비선형성을 잡아주는 **명시적 비선형 모델**을 곁들인다.

그 대표적 구현이 **국소 모델 네트워크(local model network)** 다. 전체 운전 공간을 여러 선형 모델로 덮고, 그 결과를 가중합한다.

$$y(t+1) = \sum_{j=1}^{M} \rho_j(\Phi(t)) \left( \sum_{i=0}^{n_a} a_{ij}\, y(t-i) + \sum_{i=0}^{n_b} b_{ij}\, u(t-i) + c_j \right)$$

기호를 하나씩 풀면:

- $M$ : 준비해 둔 국소 선형 모델의 개수.
- $a_{ij},\, b_{ij}$ : $j$번째 모델의 $i$번째 계수. 즉 $j$번째 국소 모델은 그냥 익숙한 선형 ARX 모델 $\sum a_{ij} y(t-i) + \sum b_{ij} u(t-i) + c_j$ 하나다.
- $c_j$ : $j$번째 모델의 상수 오프셋(운전점이 다르면 기준점도 다르므로 필요하다).
- $\rho_j(\Phi(t))$ : **기저 함수(basis function)** 로 만든 가중치. $j$번째 모델이 현재 운전 영역을 잘 근사하는 구간에서는 값이 **1에 가깝고**, 아닌 구간에서는 **0에 가깝게** 설계한다. $\Phi(t)$ 는 "지금 어느 운전 영역인가"를 알려주는 스케줄링 변수다.

결과적으로 전체는 **비선형 ARX 모델**이 되지만, 각 순간에는 국소적으로 유효한 선형 표현으로 볼 수 있다. 여기에는 **운전 영역의 개수와 모델 복잡도 사이의 트레이드오프**가 있다: 영역을 잘게 쪼갤수록 정확하지만 모델이 무거워진다.

> [!tip] 왜 이게 매력적인가
> 국소 영역을 식별하는 일 자체는 어렵지만, 일단 해 두면 **선형 예측제어기를 그대로 쓸 수 있다.** 계산 시간도 짧고 최적성 문제(국소 최적해 함정)도 없다. 더 나아가 "모델-제어기 쌍"의 가족을 만들고 **스케줄러**가 어느 제어기(또는 제어기들의 조합)를 쓸지 결정하게 하면, 고전적인 게인 스케줄링과 같은 구조가 된다. 이 전략은 실제 pH 중화 플랜트에서 성공적으로 검증되었다.

### 비선형 모델의 세 갈래

비선형성이 더 심해지면 결국 비선형 모델을 써야 한다. 책은 이 영역의 모델을 크게 **세 가지**로 나눈다.

#### 1. 근본 모델 (Fundamental Models) — 제1원리 모델

물질·에너지·운동량 **수지(balance)** 로부터 곧장 유도되는 모델이다.

- **장점**: 다른 운전 조건으로 **외삽(extrapolate)** 하기 쉽고, 파라미터 수가 적으며, 그 파라미터들이 **물리적 의미**를 가져서 실험실 실험으로 추정할 수 있다.
- **단점**: 복잡한 산업 공정에서는 이런 모델을 얻는 것이 **매우 어렵고 비싸다.** 상당한 전문성이 필요하기 때문이다.

다만 실무적인 우회로가 있다. 디지털 트윈, 시뮬레이터, 운전원 훈련용으로 이미 만들어 둔 상세 모델이 있다면, 그것을 단순화하거나 그대로 제어에 쓸 수 있다. 이때 복잡한 모델의 기본 동적 거동만 남기기 위해 **특이 섭동(singular perturbation)** 같은 모델 축소 기법을 쓰는 것도 흔하다.

모델을 기술하는 미분방정식을 일단 얻으면, 이것을 [[상태공간 모델]] 형태의 비선형 표현으로 바꾸는 것은 쉽다:

$$x(t+1) = f(x(t), u(t)) \tag{7.1}$$
$$y(t) = g(x(t))$$

여기서 $x(t)$ 는 상태 벡터이고 $f$ 와 $g$ 는 일반적인 비선형 함수다. 4장에서 본 선형 상태공간 모델 $x(t+1) = Ax(t) + Bu(t)$ 에서 행렬곱이 **임의의 함수 $f$** 로 바뀐 것뿐이다.

이 형태가 비선형 플랜트에 가장 널리 쓰이는데, 안정성·강인성에 대한 이론적 결과가 이 형태 위에서 많이 나왔고 상용 도구도 이것을 쓰기 때문이다. 다만 **상태를 측정할 수 있거나 상태 관측기를 넣어야 한다**는 조건이 붙고, 관측기는 폐루프 성능과 안정성에 영향을 준다([[상태 관측기와 칼만 필터]]).

> [!note] 이동 구간 추정 (MHE)
> 책은 각주로 **NMPC의 쌍대(dual) 문제**를 짚어둔다. **이동 구간 추정(moving horizon estimation, MHE)** 은 상태 추정을 온라인 최적화로 정식화한 것으로, **과거 측정값의 이동 구간**을 이용해 최적화 기반 상태 추정치를 얻는다. 제어가 "미래 구간에 대한 최적화"라면 추정은 "과거 구간에 대한 최적화"인 셈이다. 구조가 거울처럼 대칭이다.

#### 2. 경험 모델 (Empirical Models) — 데이터로부터

입출력 데이터만으로 만드는 이산시간 비선형 모델이다. 일반형은 **외생 입력을 갖는 비선형 자기회귀 이동평균 모델(NARMAX)** 로 쓸 수 있다:

$$y(t) = \Phi\big[y(t-1), \ldots, y(t-n_y),\; u(t-1), \ldots, u(t-n_u),\; e(t), \ldots, e(t-n_e+1)\big] \tag{7.2}$$

여기서 $\Phi$ 는 비선형 사상(mapping), $y$ 는 출력, $u$ 는 입력, $e$ 는 잡음 입력이다. $n_y, n_u, n_e$ 는 각각 몇 개의 과거값을 쓸지를 정하는 차수다.

이 식은 매우 넓은 범위를 덮지만, 바로 그래서 **문제는 "$\Phi$ 를 어떤 형태로 고를 것인가"** 가 된다. 이것이 경험 모델링의 근본적 어려움이다. 문헌에서 제안된 대안들을 책은 표 7.1로 정리한다.

| 모델 이름 | 모델 식 |
|---|---|
| 국소 모델 네트워크 | $y(t+1) = \sum_{j=1}^{M} \rho_j(\Phi(t))\left(\sum_{i=0}^{n_a} a_{ij} y(t-i) + \sum_{i=0}^{n_b} b_{ij} u(t-i) + c_j\right)$ |
| 볼테라 모델 | $y(t) = y_0 + \sum_{i=0}^{N} a_1(i) y(t-i) + \sum_{i=0}^{N} h_1(i) u(t-i) + \sum_{i=0}^{M}\sum_{j=0}^{M} h_2(i,j) u(t-i)u(t-j) + \ldots$ |
| 쌍선형 모델 | $y(t) = \sum_{i=0}^{N} h_1(i) u(t-i) + \sum_{i=0}^{M}\sum_{j=0}^{M} h_2(i,j)\, y(t-i)\, u(t-j)$ |
| 하머슈타인 모델 | $y(t) = \sum_{i=0}^{M} h(i)\, g(u(t-i))$ |
| 위너 모델 | $y(t) = g\!\left(\sum_{i=0}^{M} h(i)\, u(t-i)\right)$ |
| 신경망 모델 | $\hat{y}(t+k) = W_2\big(g(W_1 \Psi(t+k-1)) + b_i\big) + b_o$ |

*표 7.1 — 경험 모델의 예*

**볼테라 모델(Volterra model)** 부터 보자. 이것은 비선형 시스템에 대한 **테일러 급수 전개의 일반화**로 볼 수 있다. 오프셋 $y_0$ 에 선형 컨볼루션 모델(익숙한 $\sum h_1(i)u(t-i)$)을 더하고, 거기에 **고차 항**을 더 붙인 구조다. 2차 항 $\sum\sum h_2(i,j)u(t-i)u(t-j)$ 는 과거 입력들끼리의 **교차곱**이다.

> [!tip] 비유 — 테일러 급수의 시계열 판
> 고등학교에서 $f(x) \approx f(0) + f'(0)x + \tfrac{1}{2}f''(0)x^2 + \cdots$ 로 함수를 다항식 근사하는 법을 배운다. 볼테라 모델은 정확히 이 아이디어를 **"입력의 과거 전체"** 로 확장한 것이다. 1차항은 "각 과거 입력이 따로따로 미치는 영향"(= 선형 임펄스 응답), 2차항은 "두 시점의 입력이 **함께** 있을 때만 생기는 추가 영향"이다.

실전에서는 각 합이 유한하게 **절단(truncation)** 되는데, 문제는 공정의 정정 시간(settling time)이 보통 샘플링 시간의 10~50배라는 점이다. 그러면 $N$ 이 커야 하고, 2차 항은 $N$ 에 대해 제곱으로 늘어나므로 **파라미터가 폭발한다**. 이 문제를 완화하는 방법 하나는 **과거 출력값을 포함시키는 것**이다:

$$y(t) = y_0 + \sum_{i=0}^{N} a_1(i)\, y(t-i) + \sum_{i=0}^{N} h_1(i)\, u(t-i) + \sum_{i=0}^{M}\sum_{j=0}^{M} h_2(i,j)\, u(t-i)u(t-j) \tag{7.3}$$

과거 출력 항 $\sum a_1(i) y(t-i)$ 이 "지금까지 축적된 결과"를 요약해 주므로, 입력 이력을 그만큼 길게 끌고 다니지 않아도 된다. (2장에서 임펄스 응답 모델보다 전달함수 모델이 파라미터가 적었던 것과 같은 이치다.)

한계는 있지만 볼테라 모델은 일반적으로 **거동이 얌전하고(well-behaved)**, 그 **비선형 가법 구조(nonlinear additive structure)** 를 제어기 설계에 활용할 수 있다는 장점이 있다. 이 점은 7.3절에서 다시 나온다.

밀접하게 관련된 모델이 **쌍선형 모델(bilinear model)** 이다. 볼테라 급수로도 표현할 수 있으며, **입력과 출력의 교차곱**을 포함한다는 것이 특징이다. 표를 보면 2차 항이 $h_2(i,j)\,y(t-i)\,u(t-j)$ 로, 볼테라의 $u \cdot u$ 대신 $y \cdot u$ 다. 열교환기, 증류탑, 화학 반응기, 폐수 처리 플랜트, pH 중화 반응기의 모델링·제어에 성공적으로 쓰였다.

#### 하머슈타인과 위너 — 정적 비선형성을 분리하기

**하머슈타인(Hammerstein) 모델**과 **위너(Wiener) 모델**은 아핀 구조와 정적 비선형성을 결합한다. 아이디어가 아주 깔끔하다.

- **하머슈타인**: **정적 비선형성 하나**가 **선형 동적 모델**의 앞에 직렬로 붙는다. 즉 $u \to g(\cdot) \to$ 선형 동역학 $\to y$.
- **위너**: 같은 부품을 **순서만 뒤집는다**. 즉 $u \to$ 선형 동역학 $\to g(\cdot) \to y$.

![[mpc_fig_7_1.png]]
*그림 7.1 — 하머슈타인 모델과 위너 모델*

> [!example] 그림이 말하는 것
> 위쪽(a)이 하머슈타인, 아래쪽(b)이 위너다. 두 경우 모두 **비선형 블록은 기억이 없는(정적) 함수 하나**이고, **동역학은 전부 선형 블록에 몰려 있다**. 핵심은 그림 가운데의 **대리 변수(proxy variable)** 다. 하머슈타인에서는 비선형 블록의 출력 $\Phi(t) = g(u(t))$ 를, 위너에서는 비선형 블록의 입력을 대리 변수로 삼으면, **제어기는 선형 동역학만 상대하면 된다.** 훨씬 편하다. 이 "대리 변수 트릭"은 7.5절 pH 예제와 7.6절 연습문제 7.1에서 실제로 쓰인다.

> [!tip] 비유 — 페달이 이상한 자동차
> 하머슈타인 모델은 "**엔진은 지극히 정상인데 가속페달만 이상하게 생긴 차**"다. 페달을 조금 밟으면 거의 반응이 없다가 어느 지점부터 확 튀는 식이다. 이때 영리한 운전자는 "내가 원하는 엔진 출력"을 먼저 정하고, 그 출력을 내려면 페달을 몇 도 밟아야 하는지 **거꾸로 환산**한다. 이 "환산"이 바로 $g^{-1}(\cdot)$ 이고, 그 덕에 운전자의 머릿속 문제는 다시 선형이 된다. 위너 모델은 반대로 "**엔진은 정상인데 속도계 눈금이 이상한 차**"다.

#### 인공신경망 (ANN)

또 하나의 경험적 접근으로, 예측제어 응용과 상용 제품에서 크게 성공한 것이 **인공신경망(artificial neural network, ANN)** 이다. **어떤 비선형 함수든 원하는 정확도로 근사할 수 있다**는 보편 근사 정리가 이론적 근거다.

![[mpc_fig_7_2.png]]
*그림 7.2 — 순방향 신경망(feedforward neural network)의 구조도. 뉴런 3개짜리 입력층, 4개짜리 은닉층, 2개짜리 출력층으로 구성된다.*

> [!example] 그림이 말하는 것
> 동그라미가 뉴런이고 선이 **가중치(weight)** 다. 신호는 왼쪽 입력층에서 오른쪽 출력층으로 한 방향으로만 흐른다(그래서 "순방향"). 각 뉴런의 입력은 **이전 층 출력들의 아핀 변환**(가중합 + 바이어스)이고, 그 값을 **활성화 함수**에 통과시킨 것이 그 뉴런의 출력이다. 훈련 중에 조정되는 것은 바로 이 선들, 즉 가중치다.

ANN은 뉴런 같은 처리 노드들의 층이 서로 연결된 구조이고, 각 노드의 출력은 입력들의 **아핀 결합**을 **비선형(보통 시그모이드 계열) 활성화 함수**에 통과시켜 얻는다. 은닉층이 하나인 ANN으로 공정을 모델링한다면, 측정 벡터

$$\Psi = [\,y(t-1),\, y(t-2), \ldots, y(t-n),\, u(t-1),\, u(t-2), \ldots, u(t-m)\,]^{\mathrm T}$$

를 입력으로 넣고 모델 출력은 다음처럼 된다:

$$\hat{y}(t+k) = W_2\big(g(W_1 \Psi(t+k-1)) + b_i\big) + b_o$$

- $W_1$ : 은닉층의 가중치 행렬. $W_2$ : 출력 노드의 가중치 행렬.
- $b_i$ : 은닉층 바이어스. $b_o$ : 출력 바이어스.
- $g(\cdot)$ : 활성화 함수.

이 파라미터들은 **신경망 훈련**, 즉 "예측 출력과 실제 값의 차이를 최소화하는 최적화"를 통해 실험 데이터로부터 학습해야 한다.

책은 각주에서 뉴런 하나의 입출력 관계를 더 자세히 적는다:

$$a_i^{(l)} = g^{(l)}\Big( \underbrace{\sum_{j=1}^{n^{(l-1)}} w_{ji}^{(l)} a_j^{(l-1)} + b_i^{(l)}}_{\text{입력}} \Big) = g^{(l)}\big(W_i^{(l)} a^{(l-1)} + b_i^{(l)}\big)$$

읽는 법: $a_i^{(l)}$ 은 $l$번째 층의 $i$번째 뉴런의 **출력**이다. 그 입력은 이전 층의 $n^{(l-1)}$ 개 뉴런 출력들의 아핀 함수이며, $w_{ji}$ 가 가중치, $b_i^{(l)}$ 는 공정 모델의 오프셋을 감당하기 위한 바이어스 항이다. 이 합산값을 비선형 활성화 함수 $g(\cdot)$ 에 통과시키면 노드 출력이 나온다. **출력층에는 이 활성화 함수가 없는데**, 그래야 신경망이 실수 전 범위의 값을 제한 없이 예측할 수 있기 때문이다.

> [!warning] ANN의 치명적 약점 — 외삽 불가
> ANN은 **훈련 데이터의 범위 밖으로 외삽하지 못한다.** 그래서 실무에서는 보통 선형 모델과 조합해서 쓴다. **모델 신뢰도 지수(model confidence index)** 를 두고, ANN의 예측이 미덥지 않아 보이면 ANN을 **점진적으로 꺼서** 예측을 선형 부분에 의존시킨다. 근본 모델이 외삽에 강한 것과 정확히 반대되는 성질이다.

#### 3. 회색상자 모델 (Grey-Box Models)

경험적 접근과 근본적 접근을 **결합**해 양쪽의 장점을 취하는 모델이다. 기본적인 제1원리 정보에 경험 데이터를 덧붙인다. 책은 두 가지 흔한 방식을 소개한다.

1. **근본 모델 안의 미지 함수를 경험 모델로 추정한다.** 예를 들어 화학 반응기의 반응 속도 같은 것. 이 경우 정상상태 경험 모델만 있어도 충분하다.
2. **근본 모델로 기본 동역학을 잡고, 플랜트와 모델의 잔차(residual)를 비선형 경험 모델로 기술한다.**

두 방식 모두 **엄밀한 물리 모델 없이도 물리적 지식을 통합**할 수 있게 해준다.

> [!warning] 용어 혼동 주의
> 책은 각주에서 명확히 경고한다. 이런 회색상자 모델을 경험적 정보와 이론적 정보가 섞였다는 뜻에서 **"hybrid model"** 이라 부르기도 하는데, 이것을 7.4절의 **"hybrid process"**(시간 구동 + 사건 구동 동역학을 갖는 공정)와 **혼동하면 안 된다.** 완전히 다른 개념이다. 이 노트에서는 후자만 "하이브리드"라고 부르겠다.

#### 쿠프만 연산자 (Koopman operator)

최근 인기를 얻고 있는 회색상자 접근이 **쿠프만 연산자**다. 변환을 이용해 **비선형 동역학을 선형 틀 안으로 옮겨 놓는다.**

![[mpc_fig_7_3.png]]
*그림 7.3 — 쿠프만 연산자 $\mathcal{K}_f$ 와 그 역을 이용한 동적 시스템의 이중 표현*

> [!example] 그림이 말하는 것
> 그림 위쪽에는 시스템의 **상태** $x \in \mathcal{X}$ 가 있고, 이들은 비선형 동역학 $f(x): \mathcal{X} \to \mathcal{X}$ 에 따라 진화한다. 그림 아래쪽에는 **관측가능량(observables)** $\psi(x) \in \mathcal{F}$ 가 있는데, 이것은 상태를 **더 높은 차원의 공간으로 들어올리는(lift)** 함수들이다. 그 높은 차원에서는 $\mathcal{K}_f \psi(x): \mathcal{F} \to \mathcal{F}$ 라는 **선형** 동역학이 성립하고, 변환을 되돌리면 원래 비선형 동역학 $f(x)$ 의 진화와 연결된다. 즉 위아래로 상태↔관측가능량, 좌우로 비선형↔선형이 대응하는 **쌍대(duality) 구조**다.

책이 드는 비유가 아주 좋다. 이 쌍대성은 **고전 제어의 라플라스 변환**과 같다. 라플라스 변환은 시간 영역의 어려운 미분방정식 문제를 주파수 영역의 쉬운 대수 문제로 바꿔준다. 마찬가지로 쿠프만 연산자 틀은 **상태의 비선형 진화를 직접 다루는 대신, 관측가능량이 시간에 따라 어떻게 변하는지에 집중**하게 해준다. 관측가능량의 진화가 선형이므로, 선형 해석 도구를 비선형 시스템에 쓸 수 있다.

> [!important] 공짜 점심은 없다
> 여기서 결정적인 것은 **관측가능량을 어떻게 고르느냐**이며, 이는 가용한 시스템 정보에 기반해 **매번 그 문제에 맞게(ad hoc)** 정해야 한다. 원래의 비선형 동역학에 등장하는 항들로부터 관측가능량을 정의할 수 있을 때도 있지만, 그렇지 않을 때는 상태 공간에 **방사기저함수(radial basis function, RBF)** 집합을 깔아 경험적으로 정한다. 7.3절 예제 7.4에서 이 RBF 방식을 실제로 본다.

### 모델 식별 — 왜 비선형은 훨씬 어려운가

모델 형태를 골랐으면 다음은 실험 데이터로 파라미터를 추정할 차례다([[최소제곱 파라미터 추정]]).

일반적으로 **근본 모델은 경험 모델보다 데이터가 적게 필요하다.** 파라미터 수가 적고 물리적 의미가 있어 실험실 실험으로 추정 가능하기 때문이다. 반면 **블랙박스 모델**은 ANN의 가중치와 바이어스처럼 **물리적 의미가 전혀 없는 파라미터**들로 이루어진다.

그런데 시스템 식별 절차에서 **수학적으로 근본적인 장애물**이 하나 있다. 바로 **비선형 시스템에는 [[중첩의 원리]]가 없다**는 것이다.

이 말의 무게를 정확히 이해해 보자. 선형 시스템이라면 이런 일이 가능하다. 입력 $u_1(t), u_2(t), \ldots, u_n(t)$ 로 시험해서 응답 $y_1(t), y_2(t), \ldots, y_n(t)$ 를 얻었다면, **이 입력들의 임의의 선형 결합**

$$u(t) = \alpha_1 u_1(t) + \alpha_2 u_2(t) + \cdots + \alpha_n u_n(t)$$

에 대한 응답은 **더 시험해 볼 필요도 없이** 다음과 같다:

$$y(t) = \alpha_1 y_1(t) + \alpha_2 y_2(t) + \cdots + \alpha_n y_n(t)$$

즉 몇 번의 시험으로 **무한히 많은 입력에 대한 응답을 공짜로 안다.** 이것이 선형 시스템 식별이 쉬운 근본 이유다.

비선형 공정은 이 특권이 없다. **가능한 모든 입력 신호에 대해 일일이 분석해야 한다.** 그래서 비선형 플랜트의 스텝 응답을 얻으려면 **크기가 다른 여러 계단 입력**으로 시험해야 한다. 크기 1짜리 계단의 응답을 2배 해도 크기 2짜리 계단의 응답이 아니기 때문이다. 공정이 다변수이면 필요한 시험 횟수의 차이는 더욱 벌어진다.

> [!question] 자기 점검
> "선형 시스템은 스텝 응답 **하나**만 있으면 되는데 비선형 시스템은 여러 크기의 스텝 응답이 필요하다"는 말이 왜 중첩의 원리로부터 곧장 나오는지 설명할 수 있는가? 힌트: 크기 $2$ 의 계단은 크기 $1$ 의 계단에 $\alpha=2$ 를 곱한 것이다.

거의 모든 비선형 시스템이 저마다 유일하지만, 식별 도구는 많이 개발되었고 대체로 비슷한 접근을 따른다. 그 안에서 최적화 기법이 큰 역할을 한다. 요컨대 **비선형 시스템 식별은 다음 다섯 가지 과제**로 이루어진다.

1. **구조 선택 (Structure selection)** — 어떤 종류의 모델을 쓸지, 그리고 그 모델의 파라미터(식 (7.2)의 $n_y$, $n_u$ 나 볼테라 모델의 차수 등)를 고르는 일.
2. **입력 시퀀스 설계 (Input sequence design)** — 출력 시퀀스를 얻기 위해 플랜트에 주입할 입력 시퀀스의 결정. 앞서 말한 중첩 원리의 부재 때문에 **이것은 여전히 열린 문제**다.
3. **잡음 모델링 (Noise modelling)** — 잡음 입력에 대한 동적 모델의 결정.
4. **파라미터 추정 (Parameter estimation)** — 입출력 데이터와 잡음 입력으로부터 나머지 모델 파라미터를 추정.
5. **모델 검증 (Model validation)** — 모델 개발에 **쓰지 않은** 플랜트 데이터와 모델 예측을 비교.

마지막으로 고려할 것이 **모델의 유효 범위**다. 근본 모델의 장점 하나가 바로 **모델 개발에 쓴 데이터에 나타나지 않는 운전 영역으로도 외삽 가능하다**는 점이다. 플랜트가 넓은 조건 범위에서 운전될 때 특히 중요한데, 다른 모델링 접근들은 **검증 영역 밖에서 모델과 실제 공정 응답이 크게 발산**할 수 있기 때문이다.

### 예제 7.1 — 석고 소성로의 볼테라 모델과 하머슈타인 모델

실제 **석고 소성로(gypsum kiln)** 의 동역학을 잡기 위해 여러 비선형 모델을 맞춰 본 예제다.

**공정 설명**: 석고 암석을 가열해 수분을 제거하고 **소성 석고(calcined gypsum, 흔히 "파리 석고")** 를 만드는 산업용 로다. 이 소성 과정은 광물을 고운 분말로 바꾸고, 이 분말은 물과 섞이면 굳어서 건축과 주형 제작에 널리 쓰인다.

이 공정의 거동은 **외란의 존재와 여러 변수 간 결합**으로 인한 비선형 효과의 영향을 받고, 회전로를 따라 물질이 이동하기 때문에 **무시할 수 없는 지연 $d$** 가 있다. 소성 온도의 거동이 출력 제품 온도를 **선행(anticipate)** 하므로 — 즉 소성 온도를 보면 제품 온도를 미리 알 수 있으므로 — 이 부분의 좋은 모델은 플랜트 제어를 개선할 수 있다.

![[mpc_fig_7_4.png]]
*그림 7.4 — 샘플링된 데이터. 온도값은 이미 식별·추정용 작업 범위로 스케일링되어 있다. 데이터의 샘플 주기는 2분이다.*

> [!example] 그림이 말하는 것
> 시간에 따른 입력 온도와 출력 온도의 실측 시계열이다. 값들이 물리 단위(℃)가 아니라 **스케일링된 작업 값**이라는 점에 주의하자. 식별 알고리즘이 수치적으로 잘 동작하도록 미리 정규화해 둔 것이다. 샘플 주기가 2분이라는 것은 이 공정이 상당히 **느린 공정**임을 알려준다.

근본 모델링의 장점에도 불구하고 이 경우 그런 관계식을 얻기가 어려워, **입출력 데이터로부터 모델을 얻는 대안**을 택했다. 모델 복잡도와 모델링 오차 사이의 트레이드오프를 기준으로 세 모델을 골랐다.

- **선형 모델** — 비선형 모델로 얻는 개선을 보여주기 위한 **기준선(baseline)**. 여기서 모델의 차수는 AR 다항식(따라서 고려하는 과거 출력의 개수)과 관련되고, 비선형 모델에서는 절단 차수 $N$ 을 뜻한다.
- **2차 하머슈타인 모델**:
$$y(t) = h_0 + \sum_{i=0}^{N} h_{1i}\, u(t-i) + \sum_{i=0}^{N} h_{2i}\, u^2(t-i) \tag{7.4}$$
- **절단 차수 $N$ 의 2차 볼테라 모델**:
$$y(t) = h_0 + \sum_{i=0}^{N} h_{1i}\, u(t-i) + \sum_{i=0}^{N}\sum_{j=i}^{N} h_{2ij}\, u(t-i)\, u(t-j) \tag{7.5}$$

두 식을 나란히 놓고 차이를 보는 것이 이 예제의 핵심이다. **하머슈타인은 $u^2(t-i)$ — 같은 시점 입력의 제곱만** 쓴다. **볼테라는 $u(t-i)u(t-j)$ — 서로 다른 시점 입력의 교차곱까지** 쓴다. 볼테라 쪽의 안쪽 합이 $j=i$ 부터 시작하는 것은 **삼각형 형태(triangular form)** 를 쓴 것인데, 볼테라 모델의 2차 파라미터가 대칭($h_{2ij} = h_{2ji}$)이라 일반성을 잃지 않고 절반만 쓰면 되기 때문이다.

기호 정리: $h_0$ 는 바이어스, $h_{1i}$ 는 임펄스 응답 계수, $h_{2i}$ 와 $h_{2ij}$ 는 각각 하머슈타인과 볼테라의 2차 항 계수다. 고려할 과거 데이터의 개수(모델의 절단)와 지연은 실제 소성로 데이터로부터 **최소제곱법**으로 계산한다.

![[mpc_fig_7_5.png]]
*그림 7.5 — 모델 식별: (a) 모델링 대안 간 오차 비교, (b) 최선의 모델링 대안*

> [!example] 그림이 말하는 것
> (a)는 모델 차수를 바꿔가며 (각각 최적 지연에서의) 최소 모델 오차를 그린 것이다. 읽어야 할 세 가지가 있다. 첫째, **하머슈타인과 저차 볼테라 모델의 최적 지연은 16 샘플**이다. 둘째, **고차 볼테라(예: $N=15$)에서는 최적 지연이 3~4 샘플 정도로 줄어드는데**, 이는 지연된 입력들 사이의 교차곱이 추가 정보를 제공하기 때문이다. 셋째, **볼테라는 차수를 올리면 정확도가 계속 개선되고 정보 포화가 하머슈타인만큼 빨리 오지 않는다.** (b)는 최종 선택된 모델들의 실제 데이터 적합을 보여준다. 최선의 선형 모델은 $A(q^{-1})$ 다항식 기준 3차, 하머슈타인은 차수와 정확도의 절충으로 $N=5$, 볼테라는 $N=10$ 을 선택했다.

| 모델 | 차수 | 추정 오차 |
|---|---|---|
| 선형 | $N_y = 3$ | 0.0120 |
| 하머슈타인 | $N = 5$ | 0.0108 |
| 볼테라 | $N = 10$ | 0.0050 |

*표 7.2 — 모델 오차*

이 표가 이 예제의 결론이다. **선형 → 하머슈타인은 개선 폭이 작지만(0.0120 → 0.0108), 볼테라는 절반 이하로 떨어진다(0.0050).** 매우 높은 차수를 쓴다고 해서 선형·하머슈타인 모델의 오차가 크게 개선되지는 않는 반면, **볼테라 모델은 항상 다른 대안들을 능가하며 차수가 올라갈수록 성능이 좋아진다.**

당연한 결과다. 자유도가 더 많으니까. 하지만 **대가가 있다.** 책이 구체적인 숫자로 보여준다.

- **5차 하머슈타인**: 2차 부분을 기술하는 데 계수 **5개**면 된다.
- **5차 볼테라**: 같은 자리에 **55개**가 필요하다.
- $N=15$ 라면: 하머슈타인은 **15개**, 볼테라는 **120개**.

> [!important] 이 예제가 가르치는 것
> 비선형 모델링은 **정확도와 파라미터 개수의 거래**다. 볼테라는 교차곱 덕에 표현력이 뛰어나지만 파라미터가 $O(N^2)$ 로 늘어 고차에서는 **금지적(prohibitive)** 이다. 하머슈타인은 표현력은 떨어져도 파라미터가 $O(N)$ 이라 가볍다. 어느 쪽이 "옳다"가 아니라, **얼마나 많은 데이터가 있고 얼마나 많은 계수를 신뢰성 있게 추정할 수 있는가**가 선택을 결정한다.

### 예제 7.2 — 선형 모델을 보완하는 신경망

Continental Controls의 MVC 알고리즘, Pavillion Technologies의 Process Perfecter 같은 **초기 상용 예측제어기**들은 **정적 비선형 모델 + 선형 동적 모델**의 입출력 모델을 썼다. 비선형 부분을 ANN이 기술한다.

동적 부분은 **편차 변수(deviation variable)** 로 기술된다:

$$\delta u(t) = u(t) - u_s, \qquad \delta y(t) = y(t) - y_s$$

여기서 입력·출력의 정상상태 값은 정적 비선형 모델을 만족한다:

$$y_s = h_s(u_s)$$

그리고 편차 변수는 선형 동적 관계(보통 $n=2$)를 따른다:

$$\delta y(t) = \sum_{i=1}^{n} a_i\, \delta y(t-i) + b_i\, \delta u(t-i) \tag{7.6}$$

즉 이 모델은 **선형 동적 부분 + 비선형 정적 부분**의 조합이다. 선형 동적 모델의 식별은 플랜트 시험으로, 비선형 정적 모델은 **과거 이력 데이터로 만든 신경망**으로 한다.

> [!tip] 왜 이 분업이 실용적인가
> **이력 데이터에는 보통 정상상태 정보가 풍부하다.** 공장은 대부분의 시간을 정상 운전으로 보내니까. 반면 동역학 정보는 무언가 변할 때만 얻어지므로 이력 데이터에 드물다. 그래서 **정적 비선형성은 공짜로 얻은 이력 데이터로, 동적 서브모델만 별도의 플랜트 시험으로** 맞춘다. 플랜트를 흔드는 값비싼 시험을 최소화하는 영리한 분업이다.

핵심 아이디어는 식 (7.6)의 동적 모델 계수를, **초기·최종 정상상태 게인을 선형 보간한 정적 게인**을 이용해 갱신하는 것이다:

$$K_s(u(t)) = K_s^i + \frac{K_s^f - K_s^i}{u_s^f - u_s^i}\, \delta u(t) \tag{7.7}$$

이 게인이 **$u(t)$ 에 의존한다**는 점에 주목하자. 보간에 쓰는 두 게인은 정적 비선형 모델에서 **미분**으로 평가한다:

$$K_s^i = \left.\frac{dy_s}{du_s}\right|_{u_s^i}, \qquad K_s^f = \left.\frac{dy_s}{du_s}\right|_{u_s^f}$$

즉 정적 비선형 곡선 $y_s = h_s(u_s)$ 위에서 **출발점의 기울기**와 **도착점의 기울기**를 구하고, 그 사이를 직선으로 잇는 것이다.

여기서 공정 동역학은 전 운전 범위에서 선형으로 유지된다고 가정한다(즉 계수 $a_i$ 는 변하지 않는다). 따라서 $b_i$ 계수만 (7.7)이 주는 새 $K_s$ 값에 맞게 조정된다. 그런데 $K_s$ 가 $\delta u(t)$ 에 의존하므로, 조정된 계수들은 **$\delta u^2(t-i)$ 에도 의존**하게 된다. 동적 방정식은 이렇게 바뀐다:

$$\delta y(t) = \sum_{i=1}^{n} a_i\, \delta y(t-i) + \overline{b}_i\, \delta u(t-i) + g_i\, \delta u^2(t-i) \tag{7.8}$$

여기서

$$\overline{b}_i = \frac{b_i K_s^i \left(1 - \sum_{j=1}^{n} a_j\right)}{\sum_{j=1}^{n} b_j}, \qquad g_i = \frac{b_i \left(1 - \sum_{j=1}^{n} a_j\right)}{\sum_{j=1}^{n} b_j} \cdot \frac{K_s^f - K_s^i}{u_s^f - u_s^i}$$

> [!warning] 원문 수식 확인 필요
> 추출 텍스트에서 $g_i$ 의 분수 구조가 흐트러져 있다. 문맥상 $g_i$ 는 $\overline{b}_i$ 에서 $K_s^i$ 자리에 보간 기울기 $\frac{K_s^f - K_s^i}{u_s^f - u_s^i}$ 가 들어간 형태(즉 위에 적은 대로)로 읽는 것이 (7.7)의 선형 보간과 일관되지만, 원문에서는 이 항이 분모 쪽에 놓인 것처럼 보이는 배치다. PDF 원본으로 확인이 필요하다.

이 계수들이 맞다는 것은 (7.8)의 **정적 게인을 계산해 보면** 확인된다. 정적 게인은 "$\delta u$ 를 상수로 유지했을 때 $\delta y$ 가 수렴하는 값 ÷ $\delta u$" 이므로:

$$\frac{\sum_{i=1}^{n} \overline{b}_i + g_i}{\sum_{i=1}^{n} a_i} = K_s(u(t))$$

이 동적 모델이, 비선형 최적화 프로그램이 정적 모델을 이용해 최적의 입력·출력 값($u_s^f$ 와 $y_s^f$)을 계산한 **뒤에** 제어기 계산에 실제로 쓰이는 모델이다.

여기서 관찰할 점: **(7.8)의 동적 부분 계수는 샘플 주기마다 바뀐다.** 정적 비선형 모델의 새로운 국소 게인에 맞도록 매번 재스케일되기 때문이다. 이 전략은 **초기 상태와 최종 상태에서 각각 선형화한 게인들을 선형 보간하는 것**으로 볼 수 있고, 게인 스케줄링과 비슷한 정식화이되 국소 모델이 다르다.

> [!warning] 이 방법의 구조적 한계
> 공정 동역학이 운전 범위 전체에서 선형으로 유지된다고 **가정**했으므로, **시정수가 방향에 따라 다른 것 같은 비대칭 동역학은 이 모델로 표현할 수 없다.** "올라갈 때는 빠르고 내려갈 때는 느린" 공정이라면 이 방법은 부적합하다.

책은 같은 조합의 또 다른 예로 **Aspen Target**을 든다. 플랜트 모델이 이렇게 주어진다:

$$x(t+1) = A x(t) + B u(t)$$
$$y(t) = C x(t) + NN(x(t))$$

즉 **출력 비선형성을 선형 관계와 비선형 신경망의 중첩으로 모델링**한다. 이 모델은 일반적이며, 상태 벡터가 물리 변수에 한정되지 않으므로 **측정 비선형성 외의 비선형 효과까지** 담을 수 있다. 시스템을 일단 선형으로 식별하고, 남은 출력 잔차를 신경망으로 상태에 맞춘다. 여기에 **확장 칼만 필터(EKF)** 를 덧붙여 모델링 오차와 측정 불가능한 외란을 보정할 수 있으며, 이것이 MPC에서 흔히 쓰는 **상수 피드백 오차**를 대체한다(2·3장에서 본 $\hat{y} + d$ 형태의 외란 보정 대신 EKF를 쓴다는 뜻이다).

## 7.2 NMPC 문제의 해법 (Solution of the NMPC Problem)

### 연속시간 문제를 이산화하기

NMPC 문헌에서 일부 저자들은 **연속시간** 설정을 쓴다. 즉 시각 $t$ 의 제어 입력을, 시간 구간 $\tau \in [t,\, t+T]$ 에 걸친 비용을 최소화하도록 계산한다. 하지만 수치적으로 풀려면 **이산화(discretization)** 해야 한다:

$$J = \int_{t}^{t+T} L(\mathbf{x}(\tau), \mathbf{u}(\tau))\, d\tau + \varphi(\mathbf{x}(T)) \;\approx\; \sum_{i=0}^{N-1} L(\mathbf{x}_i, \mathbf{u}_i)\, \Delta\tau + \varphi(\mathbf{x}_N)$$

기호를 하나씩 보자.

- $L(\cdot)$ : **단계 비용(stage cost)**. 매 순간 얼마나 나쁜지를 재는 함수다. 앞 챕터들의 $\|y - w\|^2 + \lambda\|\Delta u\|^2$ 에 해당한다.
- $\varphi(\cdot)$ : **종단 비용(terminal cost)**. 구간 끝의 상태에만 매기는 벌점이다. 7.5절 안정성 논의의 주인공이 된다.
- $N$ : 이산화 점의 개수.
- $\mathbf{x}_i = \mathbf{x}_i(t + i\Delta\tau)$, $\mathbf{u}_i = \mathbf{u}_i(t + i\Delta\tau)$ : $i$번째 시간 스텝에서 샘플링된 상태·제어 궤적.
- $\Delta\tau = \dfrac{T}{N}$ : 시간 스텝 크기.

적분이 합으로 바뀌었을 뿐, 구조는 앞 챕터들의 비용함수와 같다. 제어 궤적은 보통 **구간별 상수 함수(piecewise constant)** 로 두지만, 다항식 매개변수화 같은 대안도 가능하다. 상태 궤적은 예측 구간에 걸쳐 **시스템 동역학 방정식을 적분**해서 이산화 점에서의 값을 만들어야 한다. 원래 연속시간 문제의 제약도 마찬가지로 이산화해 **경로 제약(path constraint)** 으로 바꿔야 한다.

이 이산화에는 여러 전략이 있고, 어떤 것을 쓰느냐가 결과적으로 나오는 최적화 문제의 **구조를 결정한다**.

- **단일 슈팅 (single shooting)**: 초기 상태에서 출발해 시스템 동역학을 **끝까지 한 번에 적분**하고, 제어 변수를 구간 전체에 걸쳐 최적화한다.
- **다중 슈팅 (multiple shooting)**: 시간 구간을 여러 소구간으로 나누고, 각 소구간에서 상태와 제어를 함께 풀되 **소구간 사이의 연속성을 제약으로 강제**한다.
- **직접 배치법 (collocation)**: 상태와 제어를 모두 특정 **배치점(collocation point)** 에서 이산화하고, 동역학 방정식을 **등식 제약으로 직접 전사(transcribe)** 한다. 이렇게 하면 시스템 동역학의 **명시적 수치 적분 자체가 사라지고**, 배치점에서 암묵적으로 강제된다.

> [!tip] 비유 — 서울에서 부산까지 가는 경로 계획
> **단일 슈팅**은 "출발점에서 핸들 조작 시퀀스만 정하고 끝까지 시뮬레이션해 본다"는 방식이다. 변수는 적지만, 출발 직후의 작은 조작 오차가 부산 도착 지점에서 엄청나게 증폭된다(수치적으로 나쁜 조건). **다중 슈팅**은 "대전, 대구에도 통과 지점을 변수로 두고, 각 구간을 따로 시뮬레이션한 뒤 이어붙는지를 제약으로 건다". 변수는 많아지지만 오차가 구간별로 갇힌다. **배치법**은 아예 전 구간의 모든 점을 변수로 두고 "이웃한 점들이 물리 법칙을 만족하는가"를 제약으로 건다.

### 일반 NLP로의 정식화

이산화 후, NMPC 문제는 일반적인 **비선형계획법(NLP, nonlinear program)** 으로 쓸 수 있다. 최적 궤적 $\mathbf{u}$ 와 $\mathbf{x}$ 를 다음을 풀어 찾는다:

$$\min_{\mathbf{w}} \; J(\mathbf{w}) \tag{7.9}$$
$$\text{subject to: } \mathbf{c}(\mathbf{w}) = 0, \qquad \mathbf{h}(\mathbf{w}) \le 0$$

여기서 $\mathbf{w}^{\mathrm T} = [\mathbf{u}^{\mathrm T}\; \mathbf{x}^{\mathrm T}]$ 이고, $\mathbf{u} = [\mathbf{u}_i]$, $\mathbf{x} = [\mathbf{x}_i]$ 다. 즉 **결정변수 $\mathbf{w}$ 안에 미래 제어 입력과 미래 상태가 모두 들어간다.**

$\mathbf{c}(\mathbf{w})$ 의 $n_c$ 개 **등식 제약**은 초기 상태(가용하다고 가정하는 $\hat{\mathbf{x}}$)와 모델 제약에 대응한다:

$$\mathbf{x}_0 - \hat{\mathbf{x}} = 0, \qquad \mathbf{x}_j - f(\mathbf{x}_{j-1}, \mathbf{u}_{j-1}) = 0 \quad j = 1..N$$

읽는 법: 첫 식은 "예측의 시작점은 현재 측정된 상태여야 한다", 둘째 식은 "**모델이 예측하는 대로 상태가 진화해야 한다**"는 뜻이다. 선형 MPC에서는 이 관계를 그냥 대입해서 없앨 수 있었지만($\mathbf{y} = G\mathbf{u} + \mathbf{f}$), 비선형에서는 $f$ 를 반복 대입하면 식이 감당 못하게 복잡해지므로 **제약으로 남겨두는 편**이 낫다.

$\mathbf{h}(\mathbf{w})$ 의 $n_h$ 개 **부등식 제약**은 고려 대상 부등식들을 모은 것이다:

$$\underline{\mathbf{x}} \le \mathbf{x}_{j-1} \le \overline{\mathbf{x}}, \qquad j = 1..N$$
$$\underline{\mathbf{u}} \le \mathbf{u}_{j-1} \le \overline{\mathbf{u}}, \qquad j = 1..M-1$$
$$\underline{\Delta\mathbf{u}} \le \Delta\mathbf{u}_{j-1} \le \overline{\Delta\mathbf{u}}, \qquad j = 1..M-1$$

$M$ 은 제어 지평([[예측 지평과 제어 지평]])이다. 5장에서 본 진폭·증분 제약 그대로다. 책은 각주에서 **완화(softening)** 도 언급한다. 여유 변수(slack variable)와 벌점 항을 더하면 제약을 쉽게 소프트하게 만들 수 있고, 출력 제약도 상태를 통해 이 정식화에 포함시킬 수 있다.

> [!important] 무엇이 근본적으로 달라졌는가
> 비선형 모델링의 어려움에 더해, **비선형 모델을 쓰는 순간 제어 문제가 볼록 QP에서 비볼록 비선형 문제로 바뀐다.** 이것이 이 절 전체의 출발점이다. 볼록성이 사라지면 "굴러 내려가면 바닥"이라는 보장이 사라진다. 국소 최소값에 갇힐 수 있고, 전역 최적해를 찾았다는 보장도 없다.

### KKT 조건 — 해가 만족해야 하는 것

문제 (7.9)를 푸는 열쇠는 **$\mathbf{w}$ 가 유효한 해가 되기 위해 만족해야 하는 근본 성질**에 있고, 그것은 [[라그랑주 승수와 등식 제약]]에서 출발한다. **라그랑지안 함수**는:

$$\mathcal{L}(\mathbf{w}, \lambda_c, \lambda_h) = J(\mathbf{w}) + \lambda_c^{\mathrm T}\, \mathbf{c}(\mathbf{w}) + \lambda_h^{\mathrm T}\, \mathbf{h}(\mathbf{w})$$

여기서 $\lambda_c \in \mathbb{R}^{n_c}$ 와 $\lambda_h \in \mathbb{R}^{n_h}$ 가 **라그랑주 승수**다. 제약 하나마다 승수 하나가 붙고, "제약을 위반하면 비용이 올라가도록" 목적함수에 섞어 넣는 구조다.

이에 대응하는 **1차 KKT 조건**(5장에서 도입)은 다음과 같다([[KKT 조건과 부등식 제약]]):

$$\nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}, \lambda_c, \lambda_h) = 0 \tag{7.10}$$
$$\mathbf{c}(\mathbf{w}) = 0 \tag{7.11}$$
$$\mathbf{h}(\mathbf{w}) \le 0 \tag{7.12}$$
$$\lambda_h^{\mathrm T}\, \mathbf{h}(\mathbf{w}) = 0 \tag{7.13}$$

여기에 $\lambda_h \ge 0$ 이 붙는다. 각 조건의 뜻을 한 줄씩 새기면:

- **(7.10) 정상성(stationarity)**: 라그랑지안의 기울기가 0. "제약을 고려한 뒤에는 더 내려갈 방향이 없다."
- **(7.11), (7.12) 실현가능성(feasibility)**: 등식 제약은 정확히 만족, 부등식 제약은 위반하지 않음.
- **(7.13) 상보성(complementarity)**: $\lambda_h^{\mathrm T}\mathbf{h}(\mathbf{w}) = 0$. $\lambda_h \ge 0$ 이고 $\mathbf{h} \le 0$ 이므로 각 항이 곱해서 0이려면, **제약이 활성(active, $h_i = 0$)이거나 그 승수가 0이거나** 둘 중 하나여야 한다. 말로 하면 "**닿지 않은 벽은 힘을 주지 않는다**".

수치적 편의를 위해, 부등식 제약 (7.12)를 등식 제약으로 바꾸는 **여유 변수 벡터 $\mathbf{s}$** 를 도입하는 것이 일반적이다. 그러면 (7.13)도 함께 대체된다:

$$\mathbf{h}(\mathbf{w}) + \mathbf{s} = 0 \tag{7.14}$$
$$\mathbf{s} \ge 0, \quad \lambda_s \ge 0, \quad \lambda_s^{\mathrm T}\mathbf{s} = 0 \tag{7.15}$$

책의 각주가 $\mathbf{s}$ 의 의미를 정확히 짚는다. **제약이 활성이면 $\mathbf{s} = 0$, 아니면 $\mathbf{s} > 0$ 이어서 제약이 엄격히 만족됨을 나타낸다.** 즉 $\mathbf{s}$ 는 "벽까지 남은 거리"다.

> [!warning] 여기서 생기는 현실적 문제
> 이 문제를 푼다는 것은 **비볼록 비선형 문제를 (적어도 부분적으로) 푼다**는 뜻이고, 이는 NLP를 온라인에서 푸는 데 드는 **비용과 신뢰성**에 관련된 많은 계산적 어려움을 낳는다. 게다가 **전역 최적해를 찾는다는 보장이 없다.** 특히 정해진 시간 안에 최적해를 얻어야 하는 실시간 제어에서는 더욱 그렇다.

그래서 문헌에는 여러 대안이 제안되어 있으며, **수렴 속도**와 **나쁜 조건수·극단적 비선형성을 다루는 방식**에서 차이가 난다. 책은 세 가지를 자세히 소개한다.

### 방법 1 — 내부점법 (Interior Point Methods)

IPOPT 같은 인기 있는 NLP 솔버에 구현된 방식이다. 일반적으로 내부점법은 조건 (7.15)를 **장벽 함수(barrier function)** 와 **상보성 조건의 완화**로 다룬다. 장벽 함수가 여유 변수 벡터의 $\mathbf{s} \ge 0$ 을 보장하고, 완화 덕분에 대응하는 승수 벡터 $\lambda_s$ 도 동시에 0보다 클 수 있게 된다. 실제로 푸는 최적화 문제는 이렇게 된다:

$$\min_{\mathbf{w},\, \mathbf{s}} \; J(\mathbf{w}) - \gamma \sum_{j=1}^{n_h} \log s_j \tag{7.16}$$
$$\text{subject to: } \mathbf{c}(\mathbf{w}) = 0, \quad \mathbf{h}(\mathbf{w}) + \mathbf{s} = 0$$

> [!tip] 비유 — 낭떠러지 앞의 전기 울타리
> $-\gamma \sum \log s_j$ 항을 보자. $s_j$ 가 0에 가까워지면(= 제약의 벽에 닿으면) $\log s_j \to -\infty$ 이므로 이 항은 $+\infty$ 로 발산한다. 즉 **벽에 가까워질수록 비용이 무한대로 치솟는 보이지 않는 울타리**를 세운 것이다. 최적화 알고리즘은 애초에 벽 근처로 가지 않으므로, "이번 반복에서 벽을 넘었는가"를 매번 검사할 필요가 없다. $\gamma$ 는 울타리를 벽에서 얼마나 떨어뜨릴지를 정하는 손잡이다.

$\gamma > 0$ 에 대해, 문제 (7.16)의 최적성 KKT 조건은 (7.10), (7.11), (7.14) 그리고

$$\lambda_s^{\mathrm T}\mathbf{s} = \gamma$$

가 되며, 이것은 **$\gamma$ 가 0으로 접근할 때 (7.15)가 된다.** 즉 원래의 상보성 조건 $\lambda_s^{\mathrm T}\mathbf{s} = 0$ 을 $\gamma$ 만큼 느슨하게 푼 다음, $\gamma$ 를 점점 줄여 진짜 해에 다가가는 것이다.

주변수(primal)와 쌍대변수(dual)를 간략히 $\mathbf{z}$ 로 묶으면, 이 최적성 조건들은 이렇게 표현된다:

$$F_\gamma(\mathbf{z}) = \begin{bmatrix} \nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}) \\ \mathbf{c}(\mathbf{w}) \\ \mathbf{h}(\mathbf{w}) + \mathbf{s} \\ \lambda_s^{\mathrm T}\mathbf{s} - \gamma \end{bmatrix} = 0$$

이제 문제는 **"$F_\gamma(\mathbf{z}) = 0$ 인 $\mathbf{z}$ 를 찾아라"** 라는 비선형 방정식 풀이가 되었고, 이것은 스텝 크기 $\alpha$ 를 갖는 고전적인 **뉴턴 방법**으로 반복적으로 풀 수 있다:

$$\mathbf{z}_{k+1} \leftarrow \mathbf{z}_k + \alpha \underbrace{\left. \left(-\frac{\partial F_\gamma}{\partial \mathbf{z}}\right)^{-1} \right|_{\mathbf{z}_k} F_\gamma(\mathbf{z}_k)}_{\Delta \mathbf{z}_k}$$

여기서 $\dfrac{\partial F_\gamma}{\partial \mathbf{z}}$ 는 $F_\gamma(\mathbf{z})$ 의 결정변수 $\mathbf{z}$ 에 대한 **야코비 행렬(Jacobian matrix)** 이다. 즉 **$F_\gamma(\mathbf{z})$ 의 각 성분이 $\mathbf{z}$ 의 작은 변화에 얼마나 민감한지**를 담은 1차 편미분 행렬이다. 명시적으로 쓰면:

$$\frac{\partial F_\gamma}{\partial \mathbf{z}} = \begin{bmatrix} \dfrac{\partial F_{\gamma,1}}{\partial z_1} & \cdots & \dfrac{\partial F_{\gamma,1}}{\partial z_n} \\ \vdots & \ddots & \vdots \\ \dfrac{\partial F_{\gamma,m}}{\partial z_1} & \cdots & \dfrac{\partial F_{\gamma,m}}{\partial z_n} \end{bmatrix}$$

$F_{\gamma,i}$ 는 벡터 함수 $F_\gamma(\mathbf{z})$ 의 $i$번째 성분, $z_j$ 는 $\mathbf{z}$ 의 $j$번째 변수다.

> [!note] 뉴턴 방법을 한 줄로
> 고등학교에서 배우는 뉴턴-랩슨법 $x_{k+1} = x_k - \dfrac{f(x_k)}{f'(x_k)}$ 를 **다변수로 확장한 것**이 위 식이다. 나눗셈 $\div f'(x_k)$ 이 **야코비 행렬의 역행렬 곱하기**로 바뀌었을 뿐이다. 자세한 배경은 [[뉴턴법과 야코비 행렬]] 참고.

따라서 이 방법은 먼저 **큰 $\gamma$** 로 $\mathbf{z}$ 를 찾아 부등식 제약을 경계에서 멀리 밀어낸 다음, **이전 반복의 해로 뉴턴법을 초기화하면서 장벽 파라미터를 계속 줄여간다.**

### 방법 2 — 순차 이차계획법 (SQP)

**Sequential Quadratic Programming**은, 최적화 문제의 KKT 조건의 해로 수렴하기 위해 **비선형 문제의 이차 근사를 반복적으로 푸는** 뉴턴 계열 방법이다.

각 반복 $k$ 에서 $\mathbf{w}_k$ 로부터 출발해 새 값을 $\mathbf{w}_{k+1} = \mathbf{w}_k + \mathbf{d}_k$ 로 찾는다. **탐색 방향** $\mathbf{d}^{\mathrm T} = [\mathbf{d}_u^{\mathrm T}\; \mathbf{d}_x^{\mathrm T}]$ 는 다음 **이차계획 문제**를 풀어 얻는다:

$$\min_{\mathbf{d}} \; \nabla J(\mathbf{w}_k)^{\mathrm T} \mathbf{d} + \frac{1}{2}\mathbf{d}^{\mathrm T} B_k \mathbf{d}$$

여기서 $B_k$ 는 **라그랑지안의 헤시안(Hessian)** 에 대한 근사다:

$$B_k = \nabla^2_{\mathbf{w}\mathbf{w}} \mathcal{L}(\mathbf{w}, \lambda_c, \lambda_h) = \nabla^2 J(\mathbf{w}) + \sum_{i=1}^{n_c} \lambda_{ci} \nabla^2 c_i(\mathbf{w}) + \sum_{i=1}^{n_h} \lambda_{hi} \nabla^2 h_i(\mathbf{w})$$

그리고 **선형화된 제약**을 만족해야 한다:

$$\mathbf{c}(\mathbf{w}_k) + \nabla \mathbf{c}(\mathbf{w}_k)^{\mathrm T} \mathbf{d} = 0, \qquad \mathbf{h}(\mathbf{w}_k) + \nabla \mathbf{h}(\mathbf{w}_k)^{\mathrm T} \mathbf{d} \le 0$$

(책의 각주: 부등식 제약이 이미 선형이면 선형화할 필요가 없다.)

> [!tip] SQP를 한 문장으로
> **"어려운 비선형 문제를, 지금 서 있는 자리에서 만든 QP로 갈아 끼워 한 걸음 가고, 도착한 자리에서 QP를 다시 만들어 또 한 걸음 가는 것."** 우리가 앞 챕터 내내 풀었던 그 QP를 **반복적으로** 푸는 셈이므로, 5장에서 배운 QP 도구가 그대로 재사용된다. 비유하자면 곡선 도로를 **아주 짧은 직선 구간들의 연속**으로 근사해 운전하는 것이다.

이 방법을 적용할 때 여러 문제가 나타난다. **2차 도함수를 구할 수 있는가**, 그리고 **중간 해가 실현가능한가**. 후자는 실시간 최적화에서 매우 중요한데, **시간이 부족하면 마지막 반복 $\mathbf{u}_k$ 를 플랜트로 보내야 하는데**, 그것은 **제약의 국소 선형 근사만 만족**하므로 **원래 제약을 위반할 수 있기 때문**이다. 원래 방법의 주요 문제들을 극복하려는 여러 변형이 존재하며, 수렴 성질과 효율 개선 변형들은 Biegler가 상세히 논의한다.

### 방법 3 — 연속법/GMRES (C/GMRES) NMPC

Ohtsuka가 제안했고 최신 MATLAB® 버전에 NMPC 문제 해법으로 포함된 방법이다. 이 방법의 최적화 문제 해법은 **해밀토니안(Hamiltonian)** 에 기반한다. 해밀토니안은 **공상태 변수(co-state variable)** $\lambda_f$ 를 통해 시스템 동역학 $f(\cdot)$ 를 포함시킨 **확장 라그랑지안**으로 볼 수 있다:

$$H = L(x(t), u(t)) + \lambda_f^{\mathrm T}(t) f(x(t), u(t)) + \lambda_c^{\mathrm T}(t)\mathbf{c}(x(t), u(t)) + \lambda_h^{\mathrm T}(t)\mathbf{h}(x(t), u(t))$$
$$\approx L(\mathbf{w}_i) + \lambda_{f,i}^{\mathrm T} f(\mathbf{w}_i) + \lambda_{c,i}^{\mathrm T} \mathbf{c}(\mathbf{w}_i) + \lambda_{h,i}^{\mathrm T} \mathbf{h}(\mathbf{w}_i), \quad \text{with } \mathbf{w}_i = \begin{pmatrix} \mathbf{x}_i \\ \mathbf{u}_i \end{pmatrix}$$

즉 해밀토니안은 **단계 비용 $L(\cdot)$ 을 최소화하는 것, 시스템 동역학 $f(\cdot)$ 를 따르는 것, 제약 $\mathbf{c}(\cdot)=0$ 과 $\mathbf{h}(\cdot)\le 0$ 을 만족하는 것 사이의 순간적 트레이드오프를 측정한다.**

**폰트랴긴 최대 원리(Pontryagin's maximum principle)** 에 따르면, 최적성의 필요조건은 **제어 입력이 매 시간 스텝에서 해밀토니안을 최소화**하는 것이다. 따라서 1차 최적성 필요조건은 해밀토니안에 대한 이산화된 KKT 조건으로 세울 수 있다:

$$\lambda_N = \varphi_{\mathbf{x}}^{\mathrm T}(\mathbf{x}_N)$$
$$\lambda_{f,i} = \lambda_{f,i+1} + H_{\mathbf{x}}^{\mathrm T}(\mathbf{w}_i, \lambda_{f,i+1}, \lambda_{c,i+1}, \lambda_{h,i+1})\, \Delta\tau, \quad i = 1, \ldots, N-1$$
$$H_{\mathbf{u}}^{\mathrm T}(\mathbf{x}_i^*, \mathbf{u}_i^*, \lambda_{i+1}^*, \mu_i^*, \nu_i^*) = 0, \quad i = 0, \ldots, N-1$$
$$\nu_i^* \ge 0, \quad \nu_i^{*\mathrm T} \mathbf{h}(\mathbf{x}_i^*, \mathbf{u}_i^*) = 0, \quad i = 0, \ldots, N-1$$

각 조건이 하는 일을 순서대로 읽으면:

1. **첫 두 식**으로 공상태 수열 $\lambda_{f,i}$ 를 계산할 수 있다. 첫 식이 **종단 조건**(구간 끝에서의 값, 종단 비용 $\varphi$ 의 기울기)이고, 둘째 식이 **역방향 재귀(backward recursion)** 다. 증분은 해밀토니안의 상태에 대한 기울기로 주어진다. 상태는 앞으로 흐르는데 공상태는 뒤에서부터 거꾸로 흐른다는 것이 핵심이다([[동적 계획법과 최적성 원리]]와 같은 구조다).
2. **셋째 조건**은 각 시간 스텝에서 제어 입력이 해밀토니안을 최소화할 것을 요구한다(그래서 $H$ 의 $\mathbf{u}$ 에 대한 기울기가 0).
3. **넷째·다섯째 조건**은 라그랑주 승수 $\nu_i^*(t)$ 로 부등식 제약을 다룬다(비음수성 + 상보성).

여기에 상태·입력의 최적 수열이 만족해야 하는 조건들이 더 붙는다:

$$\mathbf{x}_0^* = \mathbf{x}(t)$$
$$\mathbf{x}_{i+1}^* = \mathbf{x}_i^* + f(\mathbf{x}_i^*, \mathbf{u}_i^*)\, \Delta\tau, \quad i = 0, \ldots, N-1$$
$$\mathbf{c}(\mathbf{x}_i^*, \mathbf{u}_i^*) = 0, \quad i = 0, \ldots, N-1$$

이 모두를 합치면 결국 **"최적성 오차를 0으로 만들어라"** 하나로 정리된다:

$$F(\mathbf{U}, \mathbf{x}_0) = \begin{bmatrix} H_{\mathbf{u}}^{\mathrm T}(\mathbf{x}_0^*, \mathbf{u}_0^*, \lambda_1^*, \mu_0^*, \nu_0^*) \\ \mathbf{c}(\mathbf{x}_0^*, \mathbf{u}_0^*) \\ \nu_0^{*\mathrm T}\mathbf{h}(\mathbf{x}_0^*, \mathbf{u}_0^*) \\ \vdots \\ H_{\mathbf{u}}^{\mathrm T}(\mathbf{x}_{N-1}^*, \mathbf{u}_{N-1}^*, \lambda_N^*, \mu_{N-1}^*, \nu_{N-1}^*) \\ \mathbf{c}(\mathbf{x}_{N-1}^*, \mathbf{u}_{N-1}^*) \\ \nu_{N-1}^{*\mathrm T}\mathbf{h}(\mathbf{x}_{N-1}^*, \mathbf{u}_{N-1}^*) \end{bmatrix} = 0$$

여기서

$$\mathbf{U} = \big[\, \mathbf{u}_0^{*\mathrm T},\; \mu_0^{*\mathrm T},\; \nu_0^{*\mathrm T},\; \ldots,\; \mathbf{u}_{N-1}^{*\mathrm T},\; \mu_{N-1}^{*\mathrm T},\; \nu_{N-1}^{*\mathrm T} \,\big]$$

가 결정할 변수들을 담은 벡터다. (책의 각주: 상태 $\mathbf{x}$ 와 공상태 $\lambda$ 의 수열은 시스템 동역학 제약과 공상태 KKT 조건을 이용해 이 변수들로부터 계산할 수 있다. 또 다른 각주: 상보 조건에 해당하는 쌍선형 항은 수치적 이유로 보통 **매끄러운 함수로 근사**하며, 초기화를 쉽게 하려고 처음에는 **짧은 구간**으로 풀고 점차 확장하기도 한다.)

**여기가 이 방법의 진짜 아이디어다.** $F(\mathbf{U}, \mathbf{x}_0) = 0$ 을 뉴턴 방법으로 매번 푸는 대신, **$t=0$ 에서 실현가능한 초기 수열 $\mathbf{U}(0)$ 하나**(즉 $F(\mathbf{U}(0), \mathbf{x}_0(0)) = 0$ 을 만족하는 것)를 찾아 두고, 그 다음부터는 **해가 시간에 따라 진화하도록** 한다:

$$\mathbf{U}(t + \Delta\tau) = \mathbf{U}(t) + \dot{\mathbf{U}}(t)\, \Delta\tau$$

$\dot{\mathbf{U}}(t)$ 는 **연속 조건(continuation condition)** 을 만족하도록 계산한다:

$$\dot{F}(\mathbf{U}(t), \mathbf{x}_0(t)) = -\zeta F(\mathbf{U}(t), \mathbf{x}_0(t))$$

$\zeta$ 는 수치 방법의 진화가 매끄럽도록 보장하는 양의 실수다. 이 조건의 의미를 읽어 보자. $\dot{F} = -\zeta F$ 는 **$F$ 가 지수적으로 0을 향해 감쇠하도록** 만드는 미분방정식이다. 즉 오차가 정확히 0이 아니더라도 **시간이 지나면서 저절로 0으로 끌려간다.**

연쇄법칙을 적용하면:

$$F_{\mathbf{U}}\dot{\mathbf{U}}(t) + F_{\mathbf{x}}\dot{\mathbf{x}}_0(t) + F_t = -\zeta F$$

(아래첨자는 $F(\mathbf{U}(t), \mathbf{x}_0(t))$ 의 해당 편미분을 뜻한다.) 따라서 $\dot{\mathbf{U}}(t)$ 는 다음 **선형 문제**를 풀어 얻는다:

$$F_{\mathbf{U}}\dot{\mathbf{U}}(t) = -F_{\mathbf{x}}\dot{\mathbf{x}}_0(t) - F_t - \zeta F$$

이 선형 문제를 **일반화 최소잔차법(generalized minimal residual method, GMRES)** 으로 수치적으로 다룬다.

> [!important] 왜 이것이 실시간에 강력한가
> **$\mathbf{U}(t)$ 를 갱신하는 계산 부담이 뉴턴 방법 한 번 반복 수준**이다. 매 샘플마다 비볼록 NLP를 처음부터 푸는 대신, "이미 맞춰 둔 해를 조건 변화에 맞게 조금씩 밀어준다"는 발상이기 때문이다. 그래서 실시간 응용에 적합하다.

이 짧은 선별은 **많은 변수와 제약을 다룰 수 있는 효율적 비선형계획 알고리즘의 빠른 발전**을 보여준다. 게다가 이런 알고리즘의 구현은 **CasADi**(Diehl 그룹)와 **AutoGenU**(Ohtsuka 그룹) 같은 도구 덕에 크게 단순해졌다.

### 예제 7.3 — 자기부상 시스템의 NMPC 코딩

물체의 위치 $x$ 를, 전자석을 흐르는 전류 $u$ 를 조절해 들어 올리도록 설계된 **자기부상(magnetic levitation) 시스템**을 생각하자.

![[mpc_fig_7_6.png]]
*그림 7.6 — 자기부상 시스템. 전자석이 힘을 만들어 물체를 부상시키며, 전류 $u$ 로 조절한다. 위치 $x$ 는 물체와 전자석 사이의 거리이며, 주어진 설정점에 도달하도록 제어된다.*

> [!example] 그림이 말하는 것
> 위쪽에 전자석, 아래쪽에 떠 있는 금속 물체가 있고, 둘 사이의 거리가 $x$ 다. 물체에는 아래로 중력, 위로 자기력이 작용한다. 주의할 점은 **$x$ 가 작아질수록(가까워질수록) 자기력이 급격히 세진다**는 것이다. 이것이 이 시스템을 강한 비선형으로 만드는 원인이며, 동시에 **본질적으로 불안정**하게 만든다. 조금만 가까워지면 더 세게 당겨져 더 가까워지는 양의 되먹임이 있기 때문이다.

시스템 동역학은 중력과 자기력의 균형으로 지배된다:

$$m\ddot{x} = mg - \frac{k u^2}{x^2}$$

여기서 $m$ 은 부상하는 물체의 질량, $g$ 는 중력가속도, $k$ 는 상수다. 이 식이 **왜 비선형인지** 두 군데를 짚어 보자. 첫째, 입력이 **$u^2$** 로 들어간다(전류의 제곱에 비례하는 자기력). 둘째, 상태가 **$1/x^2$** 로 들어간다(거리의 제곱에 반비례). 어느 쪽도 선형이 아니다.

물체의 위치 $x$ 와 속도 $\dot{x}$ 를 상태로 삼아 상태공간으로 쓰면:

$$\begin{cases} \dot{x}_1 = x_2 \\[4pt] \dot{x}_2 = g - \dfrac{k u^2}{m x_1^2} \end{cases}$$

NMPC 제어기는 $u$ 를 조절해 중력을 상쇄하며 물체 위치를 목표 $\bar{r} = 0.1\,\mathrm{m}$ 에 유지해야 한다. 이를 위해 매 시각 $t$ 마다 다음 비용함수를 최소화해 최적 제어 입력 수열을 계산한다:

$$J = \sum_{l=1}^{N_p} \Big( Q\,\big(x_1(t+l) - \bar{r}\big)^2 + R\, u(t+l)^2 \Big)$$

제어 입력 제한은 $u \in [0, 5]\,\mathrm{A}$ 다. 파라미터는 다음과 같다.

| 파라미터 | 값 | 의미 |
|---|---|---|
| $N_p$ | 10 | 예측 지평 |
| $Q$ | 100 | 위치 오차 가중치 |
| $R$ | 1 | 제어 노력 가중치 |
| $m$ | 0.05 kg | 부상 물체 질량 (50 g) |
| $T_s$ | 0.005 s | 샘플링 시간 |
| $T_f$ | 3 s | 총 시뮬레이션 시간 |
| $\bar{r}$ | 0.1 m | 목표 위치 |

$Q/R = 100$ 이라는 비율은 "위치를 맞추는 것이 전류를 아끼는 것보다 100배 중요하다"는 설계 의도를 담고 있다([[제어 가중치 람다]] 참고).

![[mpc_fig_7_7.png]]
*그림 7.7 — 자기부상 시스템의 위치와 제어 입력의 시간 변화*

> [!example] 그림이 말하는 것
> 위쪽 그래프는 부상 물체의 위치가 목표 위치 0.1 m에서 안정화되는 모습이고, 아래쪽 그래프는 물체를 원하는 높이에 유지하는 데 필요한 제어 입력(전류)이다. 초기 상태가 $x = 0.15\,\mathrm{m}$ 이므로 물체를 **끌어올려야** 하고, 그래서 초반에 전류가 크게 들어간 뒤 정상상태에서는 **중력을 정확히 상쇄하는 값**으로 수렴한다. 이 정상상태 전류는 0이 아니라는 점에 주의하자. 전류를 끄면 물체가 떨어지기 때문이다.

구현에서 눈여겨볼 점들을 짚자.

- 그림 7.7의 결과는 **SQP 방법을 `fmincon` 으로 실행**해서 얻었다.
- 늘 그렇듯 **적용되는 제어 동작은 계산된 수열의 첫 값**뿐이다([[이동 구간 원리 Receding Horizon]]).
- 시스템이 비선형이므로 **상태의 시간 진화는 시스템 동역학 방정식을 적분법으로 시뮬레이션**한다.
- **시뮬레이션을 더 현실적으로 만들기 위해, 제어기가 최적화하는 비용함수(코드 7.2)는 다른 적분법을 쓴다.** 이것이 이 예제의 숨은 교훈이다. 제어기 내부의 모델과 실제 플랜트가 **완전히 일치하지 않는 상황**을 일부러 만든 것이다.

**코드 7.1 — 자기부상 NMPC 제어의 메인 스크립트**

```matlab
parameters = [Np, Ts, Q, R, setpoint, g, m, k];
x = [0.15; 0];              % 초기 상태
xHistory = x;
uHistory = [];
u_0 = zeros(Np, 1);         % 초기 추정값
options = optimoptions('fmincon', 'Display', 'none', 'Algorithm', 'sqp');

for l = 1:numSteps           % 시뮬레이션 루프
    % 제어 수열 최적화 및 웜 스타트 준비
    [u_opt, ~] = fmincon(@(U) costFunction(U, x, parameters), ...
        u_0, [], [], [], [], uMin*ones(Np,1), uMax*ones(Np,1), [], options);
    u_0 = [u_opt(2:end); u_opt(end)];

    % 비선형 동역학으로 시스템 상태 갱신
    [~, xout] = ode45(@(t, xk) stateFcn(xk, u_opt(1), parameters), [0 Ts], x);
    x = xout(end, :)';

    % 그래프용 이력 저장
    xHistory = [xHistory, x];
    uHistory = [uHistory, u_opt(1)];
end
```

> [!tip] 코드에서 놓치기 쉬운 한 줄
> `u_0 = [u_opt(2:end); u_opt(end)];` 이 줄이 **웜 스타트(warm start)** 다. 이번에 구한 최적 수열의 **두 번째 원소부터를 다음 반복의 초기 추정값**으로 쓰고, 마지막은 한 번 더 복제해 길이를 맞춘다. 이것이 7.3절 각주에 나오는 **"꼬리(tail)"** 개념이다. 비볼록 문제에서 좋은 초기 추정값은 **수렴 속도와 어느 국소해로 갈지를 좌우**하므로, 이 한 줄이 실시간 실현가능성을 크게 좌우한다.

**코드 7.2 — NMPC 제어를 위한 비용함수**

```matlab
function J = costFunction(U, x, parameters)
    Np = parameters(1);
    Ts = parameters(2);
    Q  = parameters(3);
    R  = parameters(4);
    targetPos = parameters(5);
    J  = 0;      % 비용 초기화
    xk = x;      % 예측 상태 초기화
    for i = 1:Np                      % 비용 누적
        u = U(i);
        xk1 = xk + Ts * stateFcn(xk, u, parameters);
        J = J + Q*(xk1(1) - targetPos)^2 + R*u^2;
        xk = xk1;                     % 다음 스텝을 위한 상태 갱신
    end
end
```

이 함수가 하는 일을 말로 풀면: **제어 수열 $U$ 를 받아서, 현재 상태에서 시작해 $N_p$ 스텝을 한 칸씩 예측하며 비용을 누적**한다. `xk1 = xk + Ts * stateFcn(...)` 이 **오일러 전진 적분**이고, 메인 스크립트가 실제 플랜트에 쓰는 `ode45`(4~5차 룽게-쿠타)보다 훨씬 거친 방법이다. 바로 이 차이가 앞서 말한 "모델-플랜트 불일치"를 만든다.

**코드 7.3 — 자기부상 시스템의 동역학 함수**

```matlab
function f = stateFcn(x, u, parameters)
    g = parameters(6);
    m = parameters(7);
    k = parameters(8);
    pos = x(1);
    vel = x(2);
    f = [vel; g - (k*u^2)/(m*pos^2)];
end
```

앞서 쓴 상태공간 식 $\dot{x}_1 = x_2$, $\dot{x}_2 = g - ku^2/(mx_1^2)$ 를 그대로 코드로 옮긴 것이다.

마지막으로, 이 **매개변수화 방식은 MATLAB®에 포함된 CGMRES 같은 다른 NMPC 솔버로 곧바로 전환할 수 있게** 해준다. 비용함수·동역학·제약을 함수로 분리해 두었기 때문이다.
