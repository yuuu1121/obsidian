# 다중 파라미터 계획법 Multiparametric Programming

> [!abstract] 한 줄 요약
> **다중 파라미터 계획법**은 최적화 문제의 답을 하나의 숫자로 구하는 대신 **"변하는 값(파라미터)의 함수"라는 공식으로** 구해 두는 기법이다. 파라미터가 바뀔 때마다 문제를 다시 풀 필요가 없어지며, MPC에서는 현재 상태를 파라미터로 놓아 **명시적 MPC**를 만들어 낸다.

## 비유로 이해하기

**근의 공식 대 계산기.**

이차방정식 $ax^2+bx+c=0$의 근을 구하는 방법은 두 가지다.

- **매번 푸는 방식**: $a,b,c$ 값이 주어질 때마다 수치해석으로 근을 찾아 헤맨다. 계수가 바뀌면 처음부터 다시.
- **공식으로 두는 방식**: $x = \dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$ 를 한 번 유도해 놓는다. 계수가 아무리 바뀌어도 **대입 한 번**이면 끝난다.

다중 파라미터 계획법은 **두 번째 방식**이다. 최적화 문제의 답을 파라미터의 **함수(공식)로** 미리 구해 두는 것이다.

다만 근의 공식과 결정적으로 다른 점이 하나 있다. 제약이 있는 최적화에서는 **공식이 하나가 아니다.** 파라미터 값에 따라 "어느 제약이 걸리느냐"가 달라지고, 그때마다 공식도 달라진다. 그래서 답은 **"영역별로 다른 여러 개의 공식 + 그 영역들의 경계"** 라는 세트로 나온다. 세금표가 소득 구간마다 다른 식을 쓰는 것과 같다.

> [!note] "다중(multi-)"과 "파라미터(parametric)"의 뜻
> **파라미터**는 "문제를 풀 때는 상수로 취급하지만, 실제로는 변하는 값"이다. 결정 변수($\mathbf{u}$)와 구별된다. **다중**은 그런 파라미터가 여러 개라는 뜻이다. MPC에서는 상태 성분 하나하나, 기준값, 측정 외란이 각각 파라미터가 되므로 자연히 여럿이다.

## 핵심 정의와 수식

**다중 파라미터 QP (mp-QP)**

$$\min_{\mathbf{u}} \;\; \frac{1}{2}\mathbf{u}^\mathrm{T}\mathbf{H}\mathbf{u} + \mathbf{b}(\mathbf{p})^\mathrm{T}\mathbf{u} + f_0 \qquad \text{s.t.}\;\; \mathbf{R}\mathbf{u}\le\mathbf{r}(\mathbf{p})$$

여기서 **파라미터 벡터 $\mathbf{p}$** 에 대해 $\mathbf{b}(\mathbf{p})$와 $\mathbf{r}(\mathbf{p})$가 **아핀하게** 의존하는 것이 조건이다.

$$\mathbf{b}(\mathbf{p}) = \mathbf{b}_0 + \mathbf{B}_p\mathbf{p}, \qquad \mathbf{c}(\mathbf{p}) = \mathbf{c}_0 + \mathbf{R}_p\mathbf{p}$$

**해의 형태.** 이 조건 아래에서 해는 다음 형태로 나온다.

$$\mathbf{u}^*(\mathbf{p}) = \mathbf{K}_a\,\mathbf{p} + \overline{\mathbf{u}}_a \qquad \text{if } \mathbf{p}\in\mathcal{P}_a$$

즉 **파라미터 공간을 다면체 조각 $\mathcal{P}_a$로 나누고, 조각마다 다른 아핀 공식**을 쓴다. 자세한 유도와 조각의 정의는 [[조각별 아핀 PWA와 명시적 MPC]]와 [[임계 영역과 상태 공간 분할]]을 보라.

**핵심 원리 두 줄.**

1. 해를 결정하는 것은 **활성 제약 집합**이다([[활성 집합법 Active Set Method]]).
2. 활성 집합이 고정되면 [[KKT 조건]]이 **선형 연립방정식**이 되고, 파라미터가 아핀하게 들어가므로 답도 파라미터의 아핀 함수다.

**민감도 분석과의 관계.** 다중 파라미터 계획법은 최적화 해의 **민감도 분석**과 밀접하다. 민감도 분석이 던지는 두 질문이 다음과 같기 때문이다.

- 목적함수의 계수가 바뀌면 최적해가 어떻게 변하는가?
- 제약의 우변이 바뀌면 최적해가 어떻게 변하는가?

MPC에서 상태 $x(t)$가 바뀌면 $\mathbf{b}$와 $\mathbf{c}$가 **동시에** 바뀌므로, 두 질문을 한꺼번에 푸는 셈이다.

> [!warning] 공짜가 아닌 이유
> 파라미터 개수가 곧 **영역이 정의되는 공간의 차원**이다. 상태만 파라미터로 쓰면 차원이 $n_x$지만, 기준값과 미래 외란까지 넣으면 차원이 훌쩍 뛴다. 영역 개수는 차원에 대해 급격히 늘어나므로, **어떤 값을 파라미터로 승격시킬지 고르는 것 자체가 설계 결정**이다.

## 챕터 속 맥락 (9장)

9.2절 전체가 이 개념의 전개다. 9.1절에서는 상태 $x(t)$ 하나만 놓고 "제약 비활성 / 활성" 두 경우로 나눠 손으로 유도했다면, 9.2절은 그 상태를 **더 일반적인 파라미터 벡터 $\mathbf{p}$** 로 승격시켜 KKT 조건에서 한 번에 유도한다. 그 결과가 식 (9.15) $\mathbf{u}_a^*(\mathbf{p}) = \mathbf{K}_a\mathbf{p} + \overline{\mathbf{u}}_a$ 이다.

이 일반화가 실제로 무엇을 가능하게 하는지는 **예제 9.2**가 보여 준다. 1차 시스템 $x(t+1)=0.9x(t)+u(t)$에서 상수 기준값 $\bar r$을 추종하는 문제인데, 파라미터를

$$p(t) = \begin{bmatrix}x(t)\\ \bar r\end{bmatrix}$$

로 잡음으로써 **기준값이 바뀌어도 다시 풀지 않는 명시적 제어기**를 얻는다. 그림 9.2의 세로축이 기준값인 이유가 이것이다. 영역 분할이 (상태, 기준값) 평면 위에 그려져 있다.

연습문제 9.6도 같은 트릭을 측정 가능한 외란 $p(t)$에 적용하라고 요구하며, 3번 항목은 외란 예측식이 두 시점을 쓰면 파라미터 벡터를 **한 차원 더 늘려야 한다**는 것을 깨닫게 하는 문제다.

책은 이 기법의 이점을 이렇게 요약한다. **"파라미터가 바뀌어도 최적화 문제를 다시 풀 필요가 없다. 해가 이미 그 불확실 파라미터의 함수로 얻어져 있기 때문이다."**

## 세 줄 정리
- 다중 파라미터 계획법은 최적화의 답을 숫자가 아니라 **파라미터의 함수**로 구해 두는 기법이다.
- 목적함수와 제약이 파라미터에 아핀하게 의존하면, 답은 **파라미터 공간의 조각별 아핀 함수**가 된다.
- MPC에서 파라미터로 상태·기준값·측정 외란을 넣을 수 있지만, 차원이 늘면 영역 개수도 함께 폭발한다.
