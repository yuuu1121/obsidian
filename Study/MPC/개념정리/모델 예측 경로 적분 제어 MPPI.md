# 모델 예측 경로 적분 제어 MPPI

> [!abstract] 한 줄 요약
> **MPPI**는 최적화 문제를 푸는 대신 **입력 수열을 무작위로 잔뜩 뽑아 시뮬레이션해 보고, 비용이 낮은 것에 더 큰 가중치를 주어 평균 내는** 샘플링 기반 MPC다. QP도 LP도 미분도 필요 없고 **비용을 계산할 수만 있으면** 되므로 비선형·비볼록 문제에 강하며, 궤적끼리 독립이라 GPU 병렬화가 쉽다.

## 비유로 이해하기

**학급 평균이 아니라 성적 가중 평균.**

어려운 문제의 답을 모른다. 그래서 학생 1000명에게 각자 조금씩 다른 답을 내게 한다. 그리고 채점한 뒤, **점수가 높은 답에 더 큰 목소리를 주어 평균**을 낸다.

아무도 정답을 모르지만, 잘한 답들 쪽으로 계속 끌려가다 보면 꽤 좋은 답에 도달한다. 다음 라운드에서는 그 평균을 출발점으로 삼아 다시 1000명이 조금씩 흔들어 본다.

여기서 중요한 것은 **"어느 방향으로 가야 좋은지" 계산할 필요가 없다**는 점이다. 기울기(미분)를 구하지 않는다. 그냥 **해 보고 채점**할 뿐이다. 목적함수가 아무리 울퉁불퉁하고 미분 불가능해도 상관없는 이유다.

> [!tip] $\lambda$가 조절하는 것 — 얼마나 독선적일 것인가
> 가중치는 $e^{-J/\lambda}$ 형태다. $\lambda$가 **작으면** 1등 답에 거의 모든 가중치가 쏠린다(탐욕적, 잡음에 취약). $\lambda$가 **크면** 모든 답을 고르게 평균한다(보수적, 느리게 개선). 온도 조절 손잡이라고 생각하면 된다.

## 핵심 정의와 수식

각 샘플링 시각에서 MPPI가 하는 일은 다음과 같다.

1. **공칭 입력 수열 $\mathbf{u}_0$에서 출발**한다 (이전 해를 시프트하거나 휴리스틱 추측).
2. **$M$개의 섭동 수열을 생성**한다.
$$\mathbf{u}_i = \mathbf{u}_0 + \boldsymbol\nu_i, \qquad i = 1..M$$
$\boldsymbol\nu_i$는 **평균 0, 공분산 $\Sigma$의 가우시안**에서 뽑은 수열이다. 공분산 $\Sigma$가 **얼마나 공격적으로 탐색할지**를 결정한다.
3. **각 수열의 궤적을 시뮬레이션**한다. 내부 모델은
$$x(t+1) = f(x(t),u(t)) + w(t)$$
이고 $w(t)$는 확률적 외란 벡터다. 모델 $f$가 **비선형이어도 무방**하다.
4. **각 궤적에 비용을 매긴다.**
$$J(\mathbf{x}_i,\mathbf{u}_i) = \mathbb{E}\left[\sum_{k=t}^{t+N_\mathrm{p}-1}\ell\left(x_i(k),u_i(k)\right) + \ell_N\left(x(t+N_\mathrm{p})\right)\right]$$
$\ell(\cdot)$은 **단계 비용**, $\ell_N(\cdot)$은 **종단 비용**이다.
5. **비용 가중 평균으로 제어 수열을 갱신**한다.
$$\mathbf{u} = \frac{\displaystyle\sum_{i=1}^{M}\mathbf{u}_i\,e^{-\frac{1}{\lambda}J(\mathbf{x}_i,\mathbf{u}_i)}}{\displaystyle\sum_{i=1}^{M}e^{-\frac{1}{\lambda}J(\mathbf{x}_i,\mathbf{u}_i)}}$$
분모는 가중치의 합이므로, 전체가 **가중 평균**임을 알 수 있다. 비용이 낮을수록 지수가 커져 가중치가 크므로, 수열은 **비용이 낮은 쪽으로 이동**한다.
6. 늘 그렇듯 **$\mathbf{u}$의 첫 원소만 플랜트에 적용**하고 다음 샘플에 1번으로 돌아간다.

> [!note] 왜 하필 지수 가중치인가
> $e^{-J/\lambda}$ 는 통계물리의 **볼츠만 분포**와 같은 형태다. 에너지가 낮은 상태가 더 자주 나타난다는 그 분포다. 경로 적분(path integral) 이론에서 최적 제어 문제를 이 형태의 기댓값으로 바꿀 수 있음이 유도되며, 그것이 이 방법의 이름과 이론적 근거다. 실용적으로는 **"항상 양수이고, 비용 차이에 지수적으로 민감한 가중치"** 라고 이해하면 충분하다.

**장점과 대가.**

| 항목 | 내용 |
|---|---|
| 필요한 것 | 확률적 샘플링과 비용 평가뿐. QP·LP·명시적 해 불필요 |
| 모델 | **비선형이어도 무방** (그냥 시뮬레이션하면 되므로) |
| 병렬화 | 각 궤적이 독립이라 **GPU로 쉽게 병렬화** |
| 대가 | 해가 **준최적**이고, **폐루프 제약 만족을 보장하지 못할 수 있음** |

## 챕터 속 맥락 (9장)

9.5절의 근사 구현 목록 중 네 번째로 소개된다. 이 절의 다른 방법들과 성격이 확연히 다르다는 점이 흥미롭다.

- **명시적 MPC**(9.1~9.4절)는 최적화를 **오프라인에서 미리 다 풀어** 조회로 바꾼다.
- **무브 블로킹**과 **조기 종료**는 최적화 문제를 **작게 하거나 덜 푼다**([[무브 블로킹과 룩업 테이블]]).
- **MPPI는 최적화를 아예 하지 않는다.** 무작위 시도와 채점만 있다.

책이 강조하는 것은 **"QP나 LP 문제를 풀 필요도 없고, 명시적 다중 파라미터 해도 필요 없다"** 는 점이다. 이 때문에 [[다중 파라미터 계획법 Multiparametric Programming|다중 파라미터 계획법]]이 요구하는 "목적함수와 제약이 파라미터에 아핀하게 의존" 같은 구조적 조건에서 완전히 자유롭다.

접근법 자체는 [[몬테카를로와 시나리오 근사|몬테카를로]] 방식이며, 6장에서 확률적 MPC를 다룰 때 본 시나리오 근사와 같은 계열의 사고방식이다. 다만 목적이 다르다. 시나리오 근사는 **불확실성을 다루려고** 샘플링하지만, MPPI는 **최적화를 회피하려고** 샘플링한다.

## 세 줄 정리
- MPPI는 입력 수열을 무작위로 섭동해 시뮬레이션하고 $e^{-J/\lambda}$로 가중 평균하는 샘플링 기반 MPC다.
- 미분도 볼록성도 필요 없이 비용 평가만 가능하면 되므로 비선형 문제에 강하고 GPU 병렬화가 쉽다.
- 대가는 준최적성과 폐루프 제약 만족 보장의 부재다.
