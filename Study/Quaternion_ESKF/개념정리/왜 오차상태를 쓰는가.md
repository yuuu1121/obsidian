# 왜 오차상태를 쓰는가

> [!abstract] 한 문장으로
> 쿼터니언은 숫자 4개로 자유도 3개를 표현하는 **과매개변수화** 구조라서, 그대로 칼만 필터에 넣으면 **공분산 행렬이 특이(singular)** 해진다. 상태를 "큰 신호(공칭) + 작은 신호(오차)"로 쪼개고 **오차만 3차원으로 다루면** 이 문제가 사라지고, 덤으로 선형화 정확도까지 좋아진다.

---

## 1. 문제의 발단 — 숫자 하나가 남는다

[[쿼터니언이란 무엇인가]]에서 본 대로, 단위 쿼터니언은 숫자 4개지만 자유도는 3개다.

$$\mathbf{q} = (q_w, q_x, q_y, q_z), \qquad \|\mathbf{q}\| = 1$$

제약 조건 하나가 자유도 하나를 깎는다. 회전을 표현하는 데는 문제가 없다. 문제는 **칼만 필터에 넣을 때** 생긴다.

---

## 2. 왜 그냥 EKF에 넣으면 안 되는가

### 2.1 공분산이 특이해진다

확장 칼만 필터(EKF)에 쿼터니언을 상태로 넣으면, 쿼터니언 부분의 공분산은 $4\times4$ 행렬이 된다.

$$\mathbf{P}_q \in \mathbb{R}^{4\times4}$$

그런데 실제 불확실성의 자유도는 **3개**다. 단위 구면 $\|\mathbf{q}\|=1$ 위에서만 움직일 수 있으므로, **구면에 수직한 방향(반지름 방향)으로는 불확실성이 존재할 수 없다.**

$$\mathrm{rank}(\mathbf{P}_q) = 3 < 4$$

> [!warning] 랭크가 부족한 공분산은 재앙이다
> 칼만 이득을 계산할 때 역행렬이 필요하다.
> $$\mathbf{K} = \mathbf{P}\mathbf{H}^\top(\mathbf{H}\mathbf{P}\mathbf{H}^\top+\mathbf{V})^{-1}$$
> 특이 행렬은 역행렬이 없다. 수치적으로는 "거의 특이한" 행렬이 되어 **역행렬 계산이 폭발**하거나, 반대로 인위적인 잡음을 넣어 억지로 가역으로 만들어야 한다. 어느 쪽도 좋지 않다.

### 2.2 자코비안도 직사각형이다

[[Chapter 04 - 섭동 미분 적분]] 3.2절에서 유도한 결과를 보자. 회전된 벡터를 쿼터니언으로 미분하면

$$\frac{\partial(\mathbf{q}\otimes\mathbf{a}\otimes\mathbf{q}^*)}{\partial\mathbf{q}} \in \mathbb{R}^{3\times4}$$

**$3\times4$** 다. 입력 4개, 출력 3개. 이 자코비안으로 공분산을 전파하면 $4\times4$ 특이 행렬이 나온다.

반면 **회전 벡터로 미분하면**

$$\frac{\partial(\mathbf{q}\otimes\mathbf{a}\otimes\mathbf{q}^*)}{\partial\boldsymbol{\theta}} = -\mathbf{R}[\mathbf{a}]_\times\mathbf{J}_r \in \mathbb{R}^{3\times3}$$

**정사각형이고 특이하지 않다.** 여기에 답이 있다.

### 2.3 정규화가 필터를 망친다

EKF가 상태를 갱신하면 $\mathbf{q} \leftarrow \mathbf{q} + \mathbf{K}(\dots)$ 가 되는데, 이 덧셈 결과는 길이가 1이 아니다. 그래서 정규화해야 한다.

$$\mathbf{q} \leftarrow \frac{\mathbf{q}}{\|\mathbf{q}\|}$$

> [!warning] 정규화는 필터 이론 바깥의 조작이다
> 칼만 필터는 "이렇게 갱신하면 최적"이라는 수학적 보장 위에 서 있다. 그런데 갱신 후에 **필터가 모르는 조작(정규화)** 을 가하면 그 보장이 깨진다. 공분산은 정규화 전 기준으로 계산되어 있는데 상태만 바뀌므로, **상태와 공분산이 서로 어긋난다.**
>
> 실무적으로는 어찌어찌 돌아가기도 하지만, 이론적으로는 지저분하고 장시간 운용 시 일관성 문제를 일으킨다.

## 3. 해법 — 상태를 둘로 쪼갠다

### 3.1 발상

$$\mathbf{x}_t = \mathbf{x}\oplus\delta\mathbf{x}$$

| | 공칭 상태 $\mathbf{x}$ | 오차 상태 $\delta\mathbf{x}$ |
|---|---|---|
| 크기 | **큰 신호** | **작은 신호** |
| 다루는 방법 | 비선형 수치 적분 | **선형** 칼만 필터 |
| 쿼터니언 부분 | $\mathbf{q}$ (4개) | $\delta\boldsymbol{\theta}$ (**3개**) |
| 잡음 고려 | 안 함 | 전부 고려 |

> [!important] 핵심 아이디어
> **"큰 것은 비선형으로 적분하고, 작은 것만 선형 필터로 다룬다."**
>
> 공칭 상태는 크지만 비선형이어도 상관없다. 그냥 적분하면 되니까. 오차 상태는 작으므로 선형으로 다뤄도 정확하다. 각자 잘하는 일을 맡기는 분업이다.

### 3.2 차원을 세어 보자

[[Chapter 05 - IMU 기반 오차상태 운동학]]의 상태 구성이다.

| 항목 | 공칭 상태 | 오차 상태 |
|---|---|---|
| 위치 | 3 | 3 |
| 속도 | 3 | 3 |
| **자세** | **4** (쿼터니언) | **3** (각오차 벡터) |
| 가속도계 바이어스 | 3 | 3 |
| 자이로 바이어스 | 3 | 3 |
| 중력 | 3 | 3 |
| **합계** | **19** | **18** |

> [!important] 차이가 정확히 1이다
> 그 1이 바로 **쿼터니언의 과잉 매개변수**다. 오차 상태에서는 그것이 사라졌다.
>
> 그리고 공분산 행렬 $\mathbf{P}$ 는 **$18\times18$** 이다. 특이하지 않다. 제약 조건이 없는 자유로운 18개 숫자의 공분산이기 때문이다.

### 3.3 자세 오차는 어떻게 3개가 되는가

[[Chapter 04 - 섭동 미분 적분]]의 $\oplus$ 연산을 쓴다.

$$\mathbf{q}_t = \mathbf{q}\otimes\delta\mathbf{q}, \qquad \delta\mathbf{q} = \mathrm{Exp}(\delta\boldsymbol{\theta})$$

- **$\mathbf{q}$** — 곡면($S^3$) 위에 있다. 4개 숫자, 제약 있음.
- **$\delta\boldsymbol{\theta}$** — 접공간($\mathbb{R}^3$)에 있다. **3개 숫자, 제약 없음.**

칼만 필터는 $\delta\boldsymbol{\theta}$ 만 추정한다. 평평한 벡터 공간이므로 평범한 3차원 가우시안으로 다룰 수 있다. 자세한 개념은 [[리 군과 리 대수]] 참고.

## 4. ESKF의 네 가지 이점

논문이 Madyastha et al. (2011)을 인용하며 정리한 내용이다.

### 4.1 자세 오차의 표현이 최소다

> [!note] 원문 요지
> 오차상태의 매개변수 개수가 자유도와 같아서, **과매개변수화(중복)로 인한 문제와 그에 따른 공분산 행렬의 특이성 위험을 피한다.** 이런 특이성은 보통 제약 조건을 강제할 때 생긴다.

위의 2.1절 문제가 근본적으로 해결된다.

### 4.2 항상 원점 근처에서 동작한다

오차는 정의상 0 근처에 머문다. 따라서

> [!note] 원문 요지
> **매개변수 특이점, 짐벌 락 등의 문제에서 멀리 떨어져 있고, 선형화의 타당성이 항상 보장된다.**

EKF의 고질적 문제는 "선형화 지점이 참값에서 멀어지면 근사가 깨진다"는 것이다. ESKF는 **항상 0 근처에서 선형화**하므로 이 문제가 없다.

### 4.3 2차 항을 전부 무시할 수 있다

오차가 작으므로 $\delta\theta^2 \approx 0$ 이다. 그 결과

$$\mathbf{q}\{\delta\boldsymbol{\theta}\} \approx \begin{bmatrix}1\\ \delta\boldsymbol{\theta}/2\end{bmatrix}, \qquad \mathbf{R}\{\delta\boldsymbol{\theta}\} \approx \mathbf{I}+[\delta\boldsymbol{\theta}]_\times$$

삼각함수가 사라지고 1차식만 남는다.

> [!note] 원문 요지
> **자코비안 계산이 매우 쉽고 빨라진다.** 어떤 자코비안은 상수이거나 이미 가지고 있는 상태값과 같아진다.

[[Chapter 05 - IMU 기반 오차상태 운동학]]의 $\mathbf{F}_x$ 를 보면 실제로 $\mathbf{I}$, $\mathbf{I}\Delta t$, $-\mathbf{R}\Delta t$ 같은 단순한 블록들로 채워져 있다. 우자코비안 $\mathbf{J}_r$ 도 $\approx\mathbf{I}$ 가 되어 사라진다.

### 4.4 보정을 낮은 주기로 해도 된다

> [!note] 원문 요지
> **오차의 동역학이 느리다.** 큰 신호의 동역학은 전부 공칭 상태가 흡수했기 때문이다. 따라서 KF 보정(오차를 관측하는 유일한 수단)을 예측보다 **낮은 주기로** 적용해도 된다.

실용적으로 매우 중요하다. IMU는 200Hz로 적분하면서 GPS는 5Hz, 카메라는 30Hz로 받아도 필터가 잘 작동한다.

## 5. 대가 — 세 단계를 지켜야 한다

공짜는 아니다. ESKF는 보정할 때마다 **세 단계**를 거쳐야 한다. ([[Chapter 06 - IMU와 보조센서 융합]])

### 5.1 관측 → 주입 → 리셋

```
1. 관측  δx̂ = K(y - h(x))        ← 칼만 보정으로 오차를 추정
2. 주입  x ← x ⊕ δx̂              ← 추정한 오차를 공칭 상태에 반영
         특히 q ← q ⊗ Exp(δθ̂)
3. 리셋  δx̂ ← 0,  P ← G P Gᵀ     ← 오차를 0으로 되돌리고 공분산 갱신
```

> [!warning] 리셋을 빼먹으면 필터가 발산한다
> 오차를 공칭 상태에 반영했는데 오차 변수를 0으로 되돌리지 않으면, **다음 사이클에서 같은 오차를 또 적용**하게 된다. 이중 반영이 누적되어 필터가 터진다.

### 5.2 왜 공분산도 갱신해야 하는가

$$\mathbf{P} \leftarrow \mathbf{G}\,\mathbf{P}\,\mathbf{G}^\top, \qquad \mathbf{G} = \begin{bmatrix}\mathbf{I}_6&0&0\\ 0&\mathbf{I}-[\tfrac{1}{2}\hat{\delta\boldsymbol{\theta}}]_\times&0\\ 0&0&\mathbf{I}_9\end{bmatrix}$$

> [!important] 기준 좌표계가 회전했기 때문이다
> 공칭 자세가 $\mathbf{q}\to\mathbf{q}\otimes\hat{\delta\mathbf{q}}$ 로 바뀌었다. 각오차는 **공칭 자세 기준으로 정의**되므로, **오차를 재는 자 자체가 회전한 것**이다. 남아 있는 불확실성도 새 기준에 맞춰 다시 표현해야 한다.
>
> 이것은 매니폴드 위에서 작업할 때만 생기는 현상이다. 평평한 공간이라면 기준점을 옮겨도 방향이 그대로라 공분산이 변하지 않는다.
>
> 다만 실무에서는 $\hat{\delta\boldsymbol{\theta}}$ 가 워낙 작아서 **대부분의 구현이 $\mathbf{G}=\mathbf{I}$ 로 근사**한다. 논문도 이를 인정하면서, 정확한 식은 **장기 표류를 줄이는 데 유용**하다고 덧붙인다.

## 6. EKF vs ESKF 한눈에 비교

| | **EKF (쿼터니언 직접)** | **ESKF** |
|---|---|---|
| 자세 상태 | $\mathbf{q}$ (4개) | 공칭 $\mathbf{q}$(4) + 오차 $\delta\boldsymbol{\theta}$(3) |
| 공분산 크기 | $4\times4$ (자세 부분) | $3\times3$ (자세 부분) |
| 공분산 랭크 | **3 < 4, 특이** | **3 = 3, 정상** ✅ |
| 자코비안 | $3\times4$ 직사각형 | $3\times3$ 정사각 ✅ |
| 정규화 | 필터 밖에서 강제 (이론 위반) | $\oplus$ 연산이 자동 처리 ✅ |
| 선형화 지점 | 현재 상태 (참값에서 멀 수 있음) | **항상 0 근처** ✅ |
| 2차 항 | 무시하기 어려움 | **항상 무시 가능** ✅ |
| 예측/보정 주기 | 비슷해야 함 | **예측 ≫ 보정 가능** ✅ |
| 구현 복잡도 | 단순 | 주입·리셋 단계 추가 ❌ |

## 7. 자주 나오는 질문

> [!question] 오차상태의 평균은 항상 0인가?
> **예측 단계에서는 그렇다.** $\hat{\delta\mathbf{x}} \leftarrow \mathbf{F}_x\hat{\delta\mathbf{x}}$ 에서 초기값이 0이므로 계속 0이다. 그래서 논문은 **이 줄을 코드에서 생략해도 된다**고 한다(다만 빠뜨린 게 없음을 확인하려고 주석 처리해 두라고 권한다).
>
> **보정 단계에서만 0이 아니게 된다.** $\hat{\delta\mathbf{x}} = \mathbf{K}(\mathbf{y}-h(\mathbf{x}))$ 로 값이 생기고, 곧바로 주입 후 다시 0으로 리셋된다.

> [!question] 그럼 오차상태는 왜 필요한가? 공분산만 있으면 되는 것 아닌가?
> 거의 맞는 지적이다. **실질적으로 중요한 것은 공분산 $\mathbf{P}$** 다. 오차의 평균은 보정 순간에만 잠깐 값을 갖는다.
>
> 하지만 "오차상태"라는 개념 틀이 있어야 **어떤 공분산을 어떤 자코비안으로 전파할지**가 정의된다. $\mathbf{P}$ 는 $\delta\mathbf{x}$ 의 공분산이지 $\mathbf{x}$ 의 공분산이 아니다.

> [!question] 공분산 예측도 생략할 수 있나?
> **절대 안 된다.** 논문이 느낌표 두 개를 붙여 강조하는 부분이다.
> $$\mathbf{P} \leftarrow \mathbf{F}_x\mathbf{P}\mathbf{F}_x^\top + \mathbf{F}_i\mathbf{Q}_i\mathbf{F}_i^\top$$
> $\mathbf{F}_i\mathbf{Q}_i\mathbf{F}_i^\top$ 가 0이 아니므로 **공분산은 계속 커진다.** 예측 단계에서는 당연히 그래야 한다. 이것을 빼먹으면 필터가 IMU를 과신해서 GPS 보정을 무시하게 된다.

> [!question] MEKF와 같은 건가?
> 거의 같다. **MEKF(Multiplicative EKF)** 는 항공우주 분야에서 같은 아이디어를 부르는 이름이다. "곱셈적(multiplicative)"이라는 말이 $\mathbf{q}_t = \mathbf{q}\otimes\delta\mathbf{q}$ 처럼 오차를 **곱으로** 합성한다는 뜻이다. ESKF와 본질적으로 같은 기법이다.

---

## 정리

> [!abstract] 핵심만
> - **문제**: 쿼터니언은 4개 숫자 / 3개 자유도 → 공분산이 **특이**해지고, 자코비안이 **$3\times4$** 이며, **정규화가 필터 이론을 깬다.**
> - **해법**: 상태를 **공칭(비선형 적분) + 오차(선형 필터)** 로 분리하고, **오차의 자세는 3차원 벡터 $\delta\boldsymbol{\theta}$** 로 다룬다.
> - **결과**: 공분산 $18\times18$(정상), 자코비안 $3\times3$(정상), 항상 원점 근처에서 선형화, 2차 항 무시 가능, 보정 주기 자유.
> - **대가**: 보정할 때마다 **관측 → 주입 → 리셋** 세 단계를 지켜야 한다.
