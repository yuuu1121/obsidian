# TD-Linear

```ad-note
title: Summary
collapse: true

- ==TD-Linear: [[Temporal Difference Learning]] + Linear [[Value Function Approximation]]==
- ==Semi-gradient: TD target의 gradient 무시 → MSVE가 아닌 [[Projected Bellman Error]] 최소화==
- ==TD Fixed Point: $w^* = A^{-1}b$로 수렴 (Tabular일 때 정확히 $v_\pi$)==
```

## Definition

[[Temporal Difference Learning]]과 [[Value Function Approximation|Linear Function Approximation]]을 결합하여 ==주어진 정책 $\pi$의 state value $v_\pi(s)$를 추정==하는 알고리즘 ([[Policy Evaluation]])

$$w_{t+1} = w_t - \alpha_t \underbrace{\left[\phi^T(s_t)w_t - (r_{t+1} + \gamma \phi^T(s_{t+1})w_t)\right]}_{\delta_t} \phi(s_t)$$

- $\hat{v}(s, w) = \phi^T(s)w$: ==Linear function approximator==
- $\phi(s) \in \mathbb{R}^m$: Feature vector (수동 설계)
- $w \in \mathbb{R}^m$: 학습할 파라미터 ($m \ll \lvert\mathcal{S}\rvert$)

```ad-info
title: Note - Comparison with Tabular TD

| 특성 | Tabular TD | TD-Linear |
|:---|:---|:---|
| **값 표현** | 테이블 $v(s)$ | 함수 $\hat{v}(s,w) = \phi^T(s)w$ |
| **업데이트 대상** | 해당 상태의 entry | ==파라미터 벡터 $w$== |
| **영향 범위** | 해당 상태만 | ==모든 상태의 값 변경== (일반화) |
| **저장 공간** | $O(\lvert\mathcal{S}\rvert)$ | ==$O(m)$== |
| **정확도** | 수렴 시 정확 | ==근사 오차 존재== |

==Tabular TD는 TD-Linear의 특수 케이스== — one-hot encoding $\phi(s) = e_s$ 사용 시 동일
```

```ad-warning
title: Note - Policy Evaluation Only

TD-Linear는 ==state value $v_\pi(s)$만 학습== — 최적 정책을 찾으려면 ==action value $q(s,a)$ 학습 필요==

→ [[Sarsa with Function Approximation]] (On-Policy), [[Deep Q-Learning|DQN]] (Off-Policy)
```

<br/><br/>

## Derivation

==Mean Squared Value Error (MSVE)== 최소화 문제에서 출발:

$$J(w) = \mathbb{E}_{S \sim d_\pi}\left[(\hat{v}(S, w_k) - v_\pi(S))^2\right]$$

- $d_\pi(s)$: [[Stationary Distribution]] — 정책 $\pi$를 따라 샘플링하면 자연스럽게 $d_\pi$에 따라 상태 방문

### Step 1: [[Gradient Descent]] 적용

$$w_{k+1} = w_k - \alpha_k \mathbb{E}\left[(\hat{v}(S, w_k) - v_\pi(S))\nabla_w \hat{v}(S, w_k)\right]$$

→ **문제**: ==기댓값을 계산할 수 없음==

```ad-important
title: Proof - Gradient of MSVE
collapse: true

**Chain rule을 적용한 gradient 유도**:

$$\begin{aligned}
\nabla_w J(w_k) &= \nabla_w \mathbb{E}\left[(\hat{v}(S, w_k) - v_\pi(S))^2\right] \\
&= 2\mathbb{E}\left[(\hat{v}(S, w_k) - v_\pi(S))\nabla_w \hat{v}(S, w_k)\right]
\end{aligned}$$

- $v_\pi(S)$는 $w$에 ==무관한 상수==이므로 $\nabla_w v_\pi(S) = 0$
- 계수 2는 $\alpha_k$에 흡수, $w = w - \alpha \nabla J$ 형태
```

<br/>

### Step 2: SGD로 대체

단일 샘플 $(s_t, v_\pi(s_t))$ 사용:

$$w_{t+1} = w_t - \alpha_t (\hat{v}(s_t, w_t) - v_\pi(s_t))\nabla_w \hat{v}(s_t, w_t)$$

→ **문제**: ==$v_\pi(s_t)$를 모름==

<br/>

### Step 3: $v_\pi(s_t)$를 TD Target으로 대체

$$v_\pi(s_t) \approx r_{t+1} + \gamma \hat{v}(s_{t+1}, w_t)$$

**최종 업데이트 규칙**:

$$w_{t+1} = w_t - \alpha_t \underbrace{[\hat{v}(s_t, w_t) - (r_{t+1} + \gamma \hat{v}(s_{t+1}, w_t))]}_{\delta_t} \nabla_w \hat{v}(s_t, w_t)$$

```ad-warning
title: Note - Semi-gradient Method

TD target $r + \gamma \hat{v}(S', w)$는 ==$w$의 함수==이므로, true gradient라면 $\nabla_w \hat{v}(S', w)$도 계산해야 함

하지만 TD는 ==이 부분을 무시==하고 $\nabla_w \hat{v}(S, w)$만 사용 → ==Semi-gradient==

| 방법 | Gradient | 최소화 대상 |
|:---|:---|:---|
| **MC + FA** | ==True gradient== | MSVE $J(w)$ 직접 최소화 |
| **TD-Linear** | ==Semi-gradient== | [[Projected Bellman Error]] $J_{PBE}(w)$ |

**결과**: MSVE 최소점이 아닌 ==TD Fixed Point== ($w^* = A^{-1}b$)로 수렴
```

<br/><br/>

## Algorithm

Linear FA에서 $\nabla_w \hat{v}(s, w) = \phi(s)$이므로:

```ad-tldr
title: Algorithm - TD-Linear

**입력**: Feature vector $\phi(s)$, 정책 $\pi$, 초기 파라미터 $w_0$, step size $\alpha_t$

**For** 각 에피소드:
- **For** 각 샘플 $(s_t, r_{t+1}, s_{t+1})$ generated by $\pi$:
  - **TD Error 계산**:
    $$\delta_t = \phi^T(s_t)w_t - (r_{t+1} + \gamma \phi^T(s_{t+1})w_t)$$
  - **파라미터 업데이트**:
    $$w_{t+1} = w_t - \alpha_t \delta_t \phi(s_t)$$

**출력**: 학습된 파라미터 $w$
```

```ad-info
title: Note - Function Approximator Selection

| 방법 | 형태 | 특징 |
|:---|:---|:---|
| **Linear** | $\phi^T(s)w$ | Feature vector 수동 설계, ==이론적 수렴 보장== |
| **Neural Network** | $f_\theta(s)$ | 비선형 근사, [[Deep Q-Learning]] 등에서 사용 |
```

## Convergence

### TD Fixed Point

Stochastic TD의 수렴 분석을 위해 ==기댓값을 취한 deterministic algorithm== 분석:

$$w_{t+1} = w_t - \alpha_t \mathbb{E}\left[\delta_t \phi(s_t)\right] = w_t + \alpha_t (b - Aw_t)$$

- $A \doteq \Phi^T D (I - \gamma P_\pi) \Phi \in \mathbb{R}^{m \times m}$
- $b \doteq \Phi^T D r_\pi \in \mathbb{R}^m$
- $D = \text{diag}(d_\pi)$: [[Stationary Distribution]]

수렴 시 ==TD Fixed Point==:

$$w^* = A^{-1}b$$

```ad-important
title: Proof - $\mathbb{E}[\delta_t \phi(s_t)] = Aw_t - b$
collapse: true

**Step 1**: [[Law of Total Expectation]]으로 기댓값을 두 항으로 분리

$$\mathbb{E}[\delta_t \phi(s_t)] = \underbrace{\mathbb{E}\left[\phi(s_t)\phi^T(s_t)\right]}_{\Phi^T D \Phi} w_t - \underbrace{\mathbb{E}\left[r_{t+1}\phi(s_t)\right]}_{\Phi^T D r_\pi} - \gamma \underbrace{\mathbb{E}\left[\phi(s_t)\phi^T(s_{t+1})\right]}_{\Phi^T D P_\pi \Phi} w_t$$

**Step 2**: 정리

$$\mathbb{E}[\delta_t \phi(s_t)] = \Phi^T D (I - \gamma P_\pi) \Phi w_t - \Phi^T D r_\pi = Aw_t - b$$
```

<br/>

### Convergence Guarantee

```ad-important
title: Theorem - Convergence

$A$는 ==positive definite== (역행렬 존재) → [[Stochastic Approximation|RM algorithm]] 조건 하에서 수렴:

$$\sum_t \alpha_t = \infty, \quad \sum_t \alpha_t^2 < \infty$$
```

```ad-important
title: Proof - A is Positive Definite
collapse: true

**전략**: $M \doteq D(I - \gamma P_\pi) \succ 0$이면, $\Phi$가 full column rank이므로 $A = \Phi^T M \Phi \succ 0$

**Step 1**: $M - M^T$는 skew-symmetric이므로 $M \succ 0 \Leftrightarrow M + M^T \succ 0$

**Step 2**: $P_\pi \mathbf{1}_n = \mathbf{1}_n$, $P_\pi^T d_\pi = d_\pi$이므로 $(M + M^T)\mathbf{1}_n = 2(1-\gamma)d_\pi > 0$

**Step 3**: $M$의 대각 성분은 양수, 비대각 성분은 비양수. $(M + M^T)\mathbf{1}_n > 0$이므로 ==strictly diagonally dominant== → ==positive definite== $\square$
```

```ad-important
title: Theorem - $w^*$ Minimizes PBE

TD-Linear는 ==MSVE가 아닌 [[Projected Bellman Error]]를 최소화==:

$$w^* = A^{-1}b = \arg\min_w J_{PBE}(w)$$
```

```ad-important
title: Proof - $w^*$ Minimizes PBE
collapse: true

$J_{PBE}(w) = 0 \Leftrightarrow \hat{v}(w) = M T_\pi(\hat{v}(w))$

Linear FA 대입 ($\hat{v}(w) = \Phi w$, $M = \Phi(\Phi^T D\Phi)^{-1}\Phi^T D$):

$$\Phi w = \Phi (\Phi^T D \Phi)^{-1} \Phi^T D (r_\pi + \gamma P_\pi \Phi w)$$

$\Phi$가 full column rank이므로:

$$w = (\Phi^T D \Phi)^{-1} \Phi^T D (r_\pi + \gamma P_\pi \Phi w) \Leftrightarrow w = A^{-1}b \quad \square$$
```

<br/>

### Error Bound

$$\|\hat{v}(w^*) - v_\pi\|_D \leq \frac{1}{1-\gamma} \min_w \|\hat{v}(w) - v_\pi\|_D$$

- 좌변: TD-Linear 수렴값의 오차
- 우변: ==최적 근사 오차==의 $\frac{1}{1-\gamma}$배
- $\gamma \to 1$일 때 bound가 느슨해짐

```ad-important
title: Proof - Error Bound
collapse: true

**Step 1**: 삼각 부등식과 Bellman operator 적용

$$\|\Phi w^* - v_\pi\|_D \leq \|M T_\pi(\Phi w^*) - M T_\pi(v_\pi)\|_D + \|M v_\pi - v_\pi\|_D$$

**Step 2**: 첫 번째 항 전개

$$M T_\pi(\Phi w^*) - M T_\pi(v_\pi) = \gamma M P_\pi(\Phi w^* - v_\pi)$$

**Step 3**: 부등식 적용 ($\|M\|_D = 1$, $\|P_\pi x\|_D \leq \|x\|_D$)

$$\|\Phi w^* - v_\pi\|_D \leq \gamma \|\Phi w^* - v_\pi\|_D + \|M v_\pi - v_\pi\|_D$$

**Step 4**: 정리

$$(1 - \gamma)\|\Phi w^* - v_\pi\|_D \leq \min_w \|\Phi w - v_\pi\|_D \quad \square$$

---

**Lemma**: $\|M\|_D = 1$, $\|P_\pi x\|_D \leq \|x\|_D$

- $M = \Phi(\Phi^T D\Phi)^{-1}\Phi^T D$는 orthogonal projection → $\|M\|_D = 1$
- $P_\pi$는 stochastic matrix, $d_\pi$는 stationary → Jensen's inequality로 증명
```

```ad-info
title: Note - Tabular Case (No Approximation Error)

$\phi(s) = e_s$ (one-hot)일 때 $\Phi = I$:

$$w^* = A^{-1}b = (I - \gamma P_\pi)^{-1} r_\pi = v_\pi$$

→ ==Tabular TD는 정확히 $v_\pi$로 수렴== (근사 오차 없음)
```
