# Grid Map

**그리드 맵**은 **환경**을 작은 **셀**들로 나누어 표현하는 **지도** 형태로, 각 셀이 **점유**되었는지(장애물이 있는지), **비어 있는지**를 나타냅니다. 마치 모눈종이에 그림을 그리듯이, 각 칸에 색을 칠해 **지형지물**을 표현하는 것과 같다.

- **그리드 맵**은 사전 정의된 랜드마크가 없으므로, 공간의 모든 위치에 대해 정보를 표현해야 한다. 이를 위해 공간을 **셀**로 분할한다.
- 이 구조는 **2차원 히스토그램** 또는 행렬로 볼 수 있으며, 자유로운 공간은 **0**, 장애물은 **1**로 표현된다.[1-37]
- 어두운 픽셀은 장애물을 나타내고, 흰색 픽셀은 해당 위치의 자유 공간을 나타낸다.
- 이 시스템은 큰 규모의 지도에서는 **Compact하지 않**으며, **각 구역의 상태**를 나타내기 위해 많은 변수를 요구한다.
- 계산 비용이 더 높지만, **특징 탐지기 없이** 원시 센서 데이터에서 직접 작업할 수 있는 장점이 있다.
- 그리드 맵에서는 각 그리드 셀의 영역이 **온전히 점유되었거나** 온전히 비어있어야 하며, 중간 상태는 존재하지 않는다.
- 1x1 미터의 셀처럼 셀 크기가 클 경우 **근사 오차**가 커지며, 이를 해결하기 위해 해상도를 조절할 수 있다.

### Occupancy Grid Maps

각 셀마다 이진 확률 변수를 유지하며, 그 상태는 **free** 또는 **occupied**로 나뉘어 있다. 이는 셀의 점유 확률을 추정하기 위함.

**Occupancy grid mapping** 방법은 세 가지 주요 가정을 한다. 

- 첫째, 환경은 **정적**이라고 가정하여, 셀의 점유 상태가 변화하지 않는다고 전제한다.
- 둘째, 모든 셀은 서로 **독립적**이라고 가정한다. 이는 한 셀의 상태를 알더라도 다른 셀의 점유 상태에 영향을 주지 않음을 의미한다.
- 마지막으로, 이러한 기본 가정이 실제 환경과는 맞지 않을 수 있으나, 모델링의 일환으로 이를 인정해야 하며, 모델링 가정은 필요한 경우 다시 검토해야 한다.

![[image.png]]

확률 값이 **0.5**일 경우, 해당 셀이 점유되어 있을 가능성과 비어있을 가능성이 동일하며, 이는 **최대의 불확실성** 상태를 나타낸다.

![[image 1.png]]

- 각 셀의 점유 확률을 계산하기 위해 해당 셀의 확률을 곱하여 전체 확률을 구할 수 있다.
- 격자 맵에서는 개별 셀의 확률 분포가 독립적이라 가정하여 각 셀을 독립적으로 처리할 수 있어 계산이 용이.

![[image 2.png]]

- 센서 데이터를 기반으로 하는 상태 추정에는 **베이지안 필터**를 활용하며, 특히 정적 상태에서는 예측 단계가 필요 없다는 것을 강조한다.[3-3]
- 세 가지 주요 가정 중 하나는 세계가 **정적(static)**이라는 것이며, 따라서 변화가 없어 예측 없이 오직 수정 단계만 필요
- **예측 단계** 없이 오직 두 가지 가능한 상태, 즉 점유(occupied)와 자유(free)로만 이루어진 이진 변수를 고려.

![[image 3.png]]

- 로그 오즈 표기법을 사용하면 곱셈이 덧셈으로 변환되어 계산을 용이하게 하고, 전체 맵을 로그 오즈 표기법으로 추정한 후 각 셀의 확률을 계산하는 것이 더 효율적.

### Log Odds Notation

로그 오즈는 **곱셈 연산을 덧셈으로 바꾸기 위한 표현 방식**으로, **소음이 많은 센서 데이터**에서도 안정적인 계산이 가능하게 도와줌.

![[image 4.png]]

- $p(m_i|z_{1:t},x_{1:t})$ : 시간 $t$까지의 센서 정보 $z$, 위치 정보 $x$를 바탕으로 해당 맵 셀  $m_i$가 어떤 상태일 확률

![[image 5.png]]

- 여기서 $p(x)$는 어떤 사건이 일어날 확률.
- $\frac{p(x)}{1 - p(x)}$는 **오즈 (odds)** 라고 부르며, "일어날 확률 / 안 일어날 확률".
- 여기에 로그를 씌우면 log odds (로그 오즈).

**확률 복원 (From Log Odds)**

log odds에서 다시 확률을 얻으려면 아래와 같은 시그모이드 형태의 수식을 사용.

$$
p(x)=\frac1{1+exp(−l(x))}
$$

$l(x) = 0$일 때 → $p(x) = 0.5$ : 최대 불확실성 상태 의미.

**로그 오즈를 이용한 맵 업데이트**

점유 확률 $p(m_i \mid z_{1:t}, x_{1:t})$의 로그 오즈는 다음과 같이 센서 정보 기반으로 업데이트:

$$
l(m_i∣z_{1:t},x_{1:t})=l(m_i∣z_{1:t−1},x_{1:t−1})+l(m_i∣z_t,x_t)−l_0
$$

- $l_0 = \log\left(\frac{p(m_i)}{1 - p(m_i)}\right)$: 초기 prior log odds
- 새로운 센서 측정 ztz_tzt에 기반해 이전 log odds에 누적 업데이트.
- **곱셈 대신 덧셈**을 통해 계산 복잡도를 줄이고 수치 안정성을 높임.
